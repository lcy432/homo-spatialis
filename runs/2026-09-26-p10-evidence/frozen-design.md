## 一、三个总体

| | 是什么 | 用在哪 |

| **P** | 原 Dirichlet 生成总体，α = (1.5, 0.5×6)，闭式矩已知 | 生成参照；人口口径报告的**还原目标**；数学 fixture |

## 五、矩的定义（**ddof = 0**）

```
m_S    = (1/N) Σ_i w_i
C_w,S  = (1/N) Σ_i (w_i − m_S)(w_i − m_S)'
C_a,S  = (1/N) Σ_i (a_i − ā)(a_i − ā)',   a_i,k = log(w_i,k / w_i,b)
```

三套矩分开命名、分开保存：**注入实现矩** / **拟合分布的权重空间矩** /
**个体后验均值的经验矩**。P 的理论矩另列。

- 群体协方差的**分子不得**换成个体后验均值的样本协方差。
- 只报**逐维方差比 + 整体 Frobenius**，**不逐元素相除**（`Σ1 = 0` 保证有近零元素）。
- 均值漂移 `m̂_w − m_S` **单独报**，正式区间由联合流程传播，**不称纯 LLM 效应**。
- bootstrap 每个 replicate 按**自己那份名单**重算分母。

## 六、`t` 路径：方案 A

```
C_a(t) = (1−t)·C_a,S + t·C_a,matched
对每个 t 只校准位置 μ_a(t)：E[S_b(μ_a(t) + L_t ξ)] = c
```

| 项 | 值 |
|---|---|
| 协议名 | `scheme_a_shared_weight_centre_v1`（进 run 与 floor 签名） |
| 旧协议 | `joint_mean_covariance_interpolation_experimental`，**正式入口拒绝** |
| `c` | 匹配拟合分布的 `E[S_b(a)]`，**不是** `S_b(E[a])`，也不是个体后验均值的平均 |
| 共享几何 | `c`/`d`/`u` 一次分析构造一份，各臂各 t 按 persona ID 共用；bootstrap 每 replicate 重建一份 |
| 求解 draws | 80,000（20,000 时独立点残差 2.3e−3，80,000 时 1.8e−4） |
| 检查 draws | 200,000，**独立**积分点 |
| 容差 | `MEAN_TOL = 2e-3`（跑前配置）。检查自身 MC 噪声大到分辨不了时标 `tolerance_below_noise_floor` |
| 失败处置 | 标 `invalid`，**不发 λ/r**，保留产物，不裁剪/归一化 |
| 沿 t 固定 | 地板选择数据、外生 σ、共享几何。指定先验后算条件后验，**不重拟总体** |

`t=0` 用**实现的注入 ALR 协方差**，不是 P 的闭式解；这不意味着知道精确真值
先验，也不保证匹配真值 ALR 均值。`t` 无须单调，端点不声称严格识别上下界。

## 七、σ 的来源

外生 σ 由**真实重复子集**按分歧率二分标定（`DECISIONS/0003`，硬规则 25），
保存目标口径与标定不确定性。**绝不从匹配臂的 `σ̂ = 1/γ_0` 反查。**
标定关系是校准启发式，**不是**重复分歧与 logit σ 的恒等式。σ 敏感性曲线保留。

## 八、数值精度状态

本轮已跑（固定参数，`integration-precision.json`，新增拟合数 **0**）。
**三个 R 分开判**，因为实测结果就是分开的：

| 量 | R=200 | 状态 |
|---|---|---|
| `R_moment`（总体权重均值/协方差） | M1 1.7e−5、M2 4.3e−4，容差 2e−3 / 1e−2 | **established** |
| `R_post`（个体后验，max 口径） | M3 **0.187**，容差 5e−3 | **not_established** |
| `R_fit`（拟合参数） | — | **本检查不验证** |

**个体后验的误差不是几个离群点，是全体。** 逐人分布：

| R | 中位 | p90 | p99 | max | 超容差人数 |
|---|---|---|---|---|---|
| 200 | 3.3e−2 | 6.8e−2 | 1.3e−1 | 2.7e−1 | **1000 / 1000** |
| 3200 | 6.0e−3 | 1.4e−2 | 3.0e−2 | 5.4e−2 | 625 / 1000 |

M3 随 R 约按 `1/√R` 下降（0.43 → 0.28 → 0.187 → 0.148 → 0.101 → 0.080 → 0.052），
外推到 5e−3 需要 R ≈ 3×10⁵。**容差与口径都是事先定死的，本轮不改。**

**后果要写进解释**：`d_i` 由个体后验构造，`proj` 与 `r` 都建在 `d_i` 上。
R=200 下个体后验的积分误差中位数 3.3e−2，而 `d` 本身的量级是 O(0.3)——即
约一成。这不是"估计器有偏"，是**积分精度**，两者要分开报。

`R_fit` 的充分性要在更高 R 上**重估参数**再比（方案乙，6–10 单核小时，未运行）。
换基恒等、优化 `converged`、相近 loglik **都不能**替代积分精度检查。

## 九、门二

```
W_h(t) = s_shuffled,h − λ_h(t)
r_h(t) = (s_matched,h − λ_h(t)) / W_h(t)
```

**不回退分母 `1−λ`；不夹 `r` 到 [0,1]；不把无效窗口设成 0。**

| 判据 | 规则 |
|---|---|
| 2a | `s_shuffled > 0` 时 `λ/s_shuffled ≤ 0.8`；否则不先除零再宣告通过 |
| 2b | `W > 0` 且 `W / SE_boot(W) ≥ 1.96` |
| 2c | `s_shuffled ≥ 0.5` |

`SE_boot(W)` 取**同一 replicate 内** `s_shuffled − λ` 的变化，**不按独立相加**
（合成算例里独立假设高估 2.56 倍）。0.8 / 1.96 / 0.5 都是**设计规则**，不用
"ALR 权重矩发散"为其背书。有效 replicate < 200 → `pending_computation`。
报告要说明覆盖的是单点还是同时带。

## 十、门三的报告分支

**条件方向曲线 `r_h(t)` 是默认输出。** 单一 `r` **不因**门三不显著就升级为
主结果。`h` 由 `z` 定义，**不冒称等频 `d` 分箱**，并显示各层实际 `d` 范围。
检出依赖时标明需要对应的条件噪声/地板处理。某层数据不足 → 显式无法判定，
**不造条件参数**。恢复单一 `r` 的规则留作独立后续设计。
