# E1-7 文献启发与设计共识

记录日期：2026-10-12。本文保存所有者与架构讨论者围绕 Agentopia、AgentSociety、AgentSociety 2 的理解，供 E1-7 及后续阶段查阅。文献事实与本项目选择分别列出；设计共识不表示代码已经实现。工程状态以 PLAN、有效 ADR 与运行证据为准。

## 三篇文献分别提供什么

| 文献 | 可核对的做法 | 本项目借鉴与边界 |
|---|---|---|
| [Agentopia](https://arxiv.org/html/2606.07513v1)；[官方代码](https://github.com/Neph0s/Agentopia) | 按抽象周组织计划、联系、活动、回顾，并保留跨阶段记忆；部分活动结果由环境 LLM 判断。 | 借鉴计划、事实反馈和连续记忆。生活金额、资源、疾病和评分继续由本项目代码执行；V1 不引入联系与迁移。不能把该论文概括成全部结果都由确定性数学环境裁定。 |
| [AgentSociety](https://arxiv.org/html/2502.08691v2)；[官方代码](https://github.com/tsinghua-fib-lab/AgentSociety) | 将需求、计划、行为和环境反馈连接；记忆区分画像、状态与经历。 | 角色陈述、当前约束与经历共同影响年度选择。[1.x NeedsBlock 文档](https://agentsociety.readthedocs.io/en/v1.3.7/apidocs/agentsociety/agentsociety.cityagent.blocks.needs_block.html)中部分主观满足状态由 LLM 更新；本项目保持独立的代码评分。 |
| [AgentSociety 2](https://arxiv.org/html/2607.11895v2)；[官方介绍](https://agentsociety2.fiblab.net/) | 将模拟参与者与组织研究流程的 AI 助手连接，支持从假设、实验到分析的工作流程。 | E1-7 借鉴信息组织、环境接口和记录；E3 借鉴资料语义说明；E4 借鉴假设、配置、证据与结论的关联。研究助手可以设计实验，城市分身只在既定环境里选择。 |

官方文档与代码会继续变化。具体移植前固定版本并重新核对；论文描述不能直接当作当前库的行为。[AgentSociety 2 当前 skills 文档](https://agentsociety2.readthedocs.io/en/latest/agent_skills.html)已说明其内置能力相对论文发生了调整。

## 所有者确认的生活闭环

角色信息与用户陈述 → 理解当下需求 → 制定年度计划 → 转为环境可执行变量 → 环境按月执行 → 记录实际结果 → 下一年结合事实记忆重新规划。

- 固定的是人的偏好，而不是替他固定消费结果。同一用户在不同城市可以选择不同的消费、住房、岗位和学习安排。
- “需求理解”是代理对用户和当前处境的解释，可记录简短摘要；不覆盖用户的原始点数、硬要求或研究真值，不新增一套心理满足度公式。
- 年度决策、月度结算、固定城市、默认三个行动年保持不变。应急行为使用已经支持的年初声明；发生疾病后不能回到年初重选计划。
- 用户偏好与公开成本足以支持规划。隐藏评分参数、未来事件、研究答案、期末估值最优分支不进入分身观察；患病概率与工作强度的关系默认隐藏。
- 规则说明告诉分身有哪些选择及其约束，不直接给出最优生活策略。若未来提供额外规划辅助，将其作为独立实验条件记录。

## E1-7 的最小实现顺序

**A：离线接线。** 用可控模拟代理实现观察、简短需求与意图记录、结构化年度计划、安全诊断、有限修订、多分身调度、动作重放和中文报告。先把城市可见事实与隐藏评分参数的来源分清楚。合成事实与未来真实资料遵守同一份输入契约。

**B：真实模型。** 复用 A 的入口、规则与日志，接入一个明确版本的模型，按批准预算做少量合成城市试跑。A 的成功不能说明真实 LLM 已经能完成任务。

本次讨论同意的默认方向：每年一次正常规划，最多两次计划修订；事实摘要加上一年的简短理由，不增加独立反思模型；先做可运行入口与中文报告，前端归 E5。具体配置、接口和验收以对应执行 prompt 与 ADR 为准。

## 信息与失败边界

- 余额、物品、能力、病情由环境决定。模型自述不能修改它们；只改理由文字不改变相同行动的生活结果。
- 格式、引用、年初资格及无新事件时的预算问题可以修订。网络重试与计划修订分开统计；达到上限不自动替模型选择便宜方案，也不暗中切换模型。
- 真实生活出局、执行受阻、反馈缺失分别保留。个体预期停止只影响本分身；城市资料、共享配置和未知程序错误按影响范围处理。
- 原名单不因失败缩小。使用 E1-6 的 C/E/M 分类、完整者平均、出局事件链和模拟缺失范围；不补零、不把范围称作置信区间。
- 保存完整可见请求与返回、已接受行动、配置身份和事件来源。重放从初态重新执行已接受行动，不通过重问 LLM 重造轨迹，也不手工恢复内部封存标记。
- 恢复与重放分开说明。年度边界恢复不能重复执行已提交交易；V1 不承诺任意月内恢复。

## 后续阶段的用法

| 阶段 | 保留的启发 |
|---|---|
| E3 | 每份资料保留原始数值、定义、单位、地区范围、年份和转换依据。语义相似不等于统计口径可比。模型辅助映射，不编造数值。 |
| E4 | 实验前固定问题、输入许可、用户组、基线、指标、重试与预算。记录哪些结果来自模型选择，哪些来自环境设定。不能以事后改参数获得的高分证明原假设。 |
| E5/E6 | 用户能从结论查看对应生活事实；交付可重放的配置、行动和结果。 |
| V2 | 更多国家、品牌菜系、打听与迁移增加后，再考虑按功能加载规则和工具。 |
| V3 | 参数目录支持敏感性、模拟校准和外部验证；模拟可运行不等于现实有效。 |
