## 1. 这份目录怎样用

例如，α = 0.10 表示：我们暂时规定“上一年满足感带来的下一年精力加成最多为基础额度的 10%”。它不是已经测得的人体规律。先把它记清楚，可以继续做 V1；以后再研究结论在 α = 0、0.05、0.10 时是否改变，以及什么外部资料能约束它。

这里沿用“超参数”这个总称，但严格说，下面包括模型参数、离散规则、数据映射、中间变量、用户输入、实验条件和数值控制。**登记在一起，不等于全部交给一个训练程序自由调整。**

### 1.1 七类内容

| 类别 | 问的是什么 | 例子 | 以后怎样决定 |
|---|---|---|---|
| 环境规则 W | 在这个世界里，行动会发生什么后果？ | 工作负担、技能门槛、疾病概率 | 合成设定、外部估计或结构比较 |
| 数据映射 M | 原始资料怎样变成模拟可用的量？ | 通勤分钟、面积单位、职业映射、背景指数 | 固定换算、可审计派生或有误差的估计，分开记录 |
| 人的输入 P | 这个人有什么资源、重视什么？ | 现金、年龄、陈述权重、目标 | 用户明确输入或研究抽样，不能为提高拟合擅自修改 |
| 信息与认知 B | 分身得到哪些信息，如何理解它们？ | 不告知疾病映射、风险低估实验 | 控制输入条件；实际信念要通过行为另行验证 |
| 评价规则 E | 怎样评价实际生活？ | 满足感递减、折现、缺失处理 | 理论选择、外部验证与所有者裁决，不能只追求高分 |
| 实验设计 X | 怎样比较与测量？ | 分身数、随机配对、抽样分层、通过门槛 | 按研究问题和预算事先冻结 |
| 数值与工程 N | 怎样可靠地算出来？ | 积分点数、取整、误差容限、摘要长度 | 收敛/边界检查、成本约束；不解释成人体规律 |

一条记录可以有两个标签。例如基础精力既是个人输入，又使用了我们定义的合成负担尺度。

### 1.2 状态、数值与单一来源

- **当前**：对应代码已经执行；不表示真实标定。
- **E1-5/6/7 待实现或待裁决**：是下一步设计，不存在可直接传入的配置开关。
- **V2 候选**：为已讨论的扩展预留概念，不要求 V1 实现。
- **V3 研究**：可能估计或检验这些规则；记录候选不保证数据能够识别它。

表中的“样例”是指定合成配置中的示范值，不是默认现实值。每城价格、每人的点数等完整向量保存在配置/运行快照里；本目录登记其字段家族，不手抄成第二份数据表。**运行行为以对应版本的代码和配置为准；规则效力按 README 分工。**

未实现条目写“未定”，不虚构默认数值、搜索范围或已经存在的 API。固定换算（如分钟除以 60 得小时）、金额守恒、隐藏答案隔离不作为可优化自由度。

### 1.3 新增条目模板与工作规则

每次新增/修改机制，coding agent 在同一轮更新受影响条目；至少记录：

1. 稳定 ID、名称/字段、类别、单位与合法域；
2. 当前值/公式或“未定”、适用协议、阶段、代码与配置位置；
3. 它影响什么、为什么这样定：观测、派生、统计估计、合成设定、用户输入或研究裁决；
4. 谁能看到：代理可见事实、研究条件或内部裁判参数；
5. 省略什么、可能影响哪些人；
6. 验证方法、待比较的替代规则和依赖的锚点；尚无合理搜索范围时明确写未定。

改数值同时记录单位；改规则不伪装成只调参数。新实验保存实际配置、参数/政策内容指纹、数据版本、种子、模型/prompt 和代码版本。现有登记义务从本轮起执行；批量参数导出、搜索器和自动 CI 检查尚未实现，不为这份目录重写所有旧模块。

## 2. 当前生活评分：一座城市怎样贡献满足感

位置：[评分契约](../../src/common/life_scoring_contracts.py)、[评分器](../../src/econ/life_scoring.py)、[评分配置](../../configs/life/)。数值例子主要来自 E1-4B 评分样例（`scoring_e1_4b.yaml`，已删除） 与 E1-3 增补样例（`scoring_e1_3s.yaml`，已删除）。

一般分项先得到生活条件，再转成满足感：

\[
z=b+\sum_j\eta_jx_j,\qquad s=\min\left(c,\frac{z}{z+\tau}\right).
\]

这里 b 像城市自带的起点，η 表示服务怎样改善条件，τ 控制“要多少条件才够好”，c 是上限。z = τ 时，未截顶的分数是 0.5；因此 τ 可以直观地理解为半饱和锚点。不同类型的来源并不一律相加，要遵守下表的替代规则。

| ID / 类型 | 当前字段、规则与例值 | 影响与依据；以后查什么 |

## 6. 分身知道什么、相信什么、重视什么

这三件事必须分开：环境真实风险为 p；给代理的信息是消息 I；代理从 I 和自身常识形成的判断是 q。**p、I、q 不是一个数。** 风险偏好还回答另一个问题：即使两人相信同一个概率，他们是否愿意承担风险？

例如两组代理都生活在同一套疾病规则里，一组只知道已发生的生活事实，另一组得到风险提示。若行为改变，可以研究信息条件的作用；不能同时修改疾病概率后，把差异全部归因于风险感知。

|---|---|---|

## 12. V3 怎样研究这些参数

### 12.1 先找能约束参数的资料

先问“什么现象能区分这些设定”，再选搜索算法。例如时间利用资料可以约束家务小时；实际报价约束支出；外部选择/生活评价资料可能约束部分满足感映射。仅用我们自己公式产生的分数训练回同一个公式，只能检查数值回收，不能证明现实正确。

启发式搜索、网格/随机敏感性或模拟校准都可研究，但本轮不实现优化器，不预定某算法一定能找到真值。每项研究记录目标、可调集合、合理域、固定条件、拟合与验证数据、预算和停止条件。

### 12.2 并非每个参数都能被单独学出来

在一般评分式中，把 b、η、τ 同时乘以一个正数，分数完全不变。它们像地图的厘米和公里：如果比例尺也一起变了，看到的关系不变。必须固定单位与至少必要的锚点，才可能讨论剩余参数。

同样，基础精力与所有负担系数同比缩放可能不改变可行性；景观指标缩放与 β 也可能互相抵消。记录这些共同缩放，不把优化器返回的一组数字说成唯一生理/心理真值。资料不够时报告范围、等价组或未识别。

### 12.3 分开校准世界、研究代理与裁决评价

1. 世界规则尽量用外部资料约束，冻结后再比较代理。
2. 研究风险信息时保持实际风险机制不变；研究实际风险时另开环境条件。
3. 不为提高当前被测 LLM 得分而调整裁判，再称 LLM 更懂用户；学习代理与检验代理使用独立记录和留出评价。
4. 用户陈述不是待优化噪声；固定单位、守恒、答案隔离与预定分母保护不交给优化器取消。
5. 划分拟合和留出资料；有足够资料时检查跨城市、时期和人群的泛化，报告受损群体，避免总体拟合掩盖偏科。
6. 检查参数不确定性是否会改变城市比较和研究结论。若只需粗范围就稳定，不为了每个数字更漂亮阻塞 V1。
