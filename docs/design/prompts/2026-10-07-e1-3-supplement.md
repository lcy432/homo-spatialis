## 1. 已确认原则

1. **固定的是人的偏好，而不是替他固定消费结果。** 同一人的偏好与起点对齐规则跨城不变；价格、机会、历史状态可以改变实际安排。不要称实际选择为 iid，也不要用固定消费份额替 LLM 作决定。
2. V1 年度决策、月度执行，固定城市，默认三年，终态 N+1。城市主结果将由同一用户分身平均产生，但本轮不实现排序。
3. 同一比较组冻结共同粒度、指标含义、单位、作用规则。真实不可得不等于资料未知；不能某城细化、某城填默认值。
4. V1 不增加在线环境 LLM。代码计算后果；数据 LLM 将来只能协助整理，数值需追溯。
5. 平均医疗/住房/教育支出不能当单位价格或作用效率；合成假设、直接观测、确定性派生和统计估计要分清。
6. 省略机制必须登记两列：省略了什么、影响哪些偏好的人。未覆盖不是天然零均值残差。
7. 旧 E1-3 是可保留的探索版本。本轮新增独立版本和样例，不覆盖旧结果，不把探索规则标成现实标定或正式协议。

## 2. 本轮目标与停止范围

本轮做出可执行、可手算的 E1-3 增补演示，包含：

- 持有服务数量直接记录；
- 物质按需求功能计分，保留属性与当地报价扩展；
- 七维范围明确，抽象休闲；
- 自然景观/户外吸引力加分；
- 简化的租金—通勤方案；
- 共同粒度、来源和用户权重覆盖报告；
- 文档、测试与独立运行证据。

本轮不运行随机疾病、不增加培训涨薪、不实现完整时间精力约束与反馈、不做品牌效用、不调用 LLM、不接真实税表、不爬取全套多国资料、不计算三年终值和城市排名。

## 3. 按依赖顺序实施

### A. 新 ADR 与数量收尾

先记录新 ADR，说明以下规则与 ADR0018 的关系，旧规则在哪些协议仍有效。

给 HoldingService 加实际数量，由结算写出，评分读取。新记录不再依赖“旧持有在前、新购在后”猜数量。

保留已有按月寿命、跨年延续、当年/次年生效、到期移除、可配置 N。历史输出不回写。若提供旧记录读取兼容，明确版本、信息来源和不足时行为，不默认为 1。

必须覆盖：旧持有与新购数量不同、同机会跨年续购、记录重排、到期及延期生效。历史输入样例应仍能使用；必要的显式读取迁移单独说明，不能通过改旧期望值掩盖数学变化。

### B. 功能—方案属性—城市供给

利用已有 LifeOpportunity/spec/价格/资格/来源接口，建立最小、可验证的功能声明和属性扩展约定，不为每个品牌造 Python 类型。

V1 物质重点：

- 住房：面积/房间数、独占性、基本设施；购房融资不做。
- 食品：少量鲜食/便利、自做/外购的粗方案；记录准备时间，真正约束留 E1-4。
- 耐用品：通信、工作设备、洗衣等功能。按功能满足与实际服务计分，第二件同功能物品不无条件再加一份满额收益。
- 工作空间：家中空间与外部工位可替代；没有真实依据时不能虚构免费的私人办公室。
- 少量便利服务：功能和时间事实分清，不另赠送一份重复的省时幸福。
- 其他未支持需求明确列出。

替代规则优先复用 any/max/sum；容量型功能只有明确数量语义时才相加。不要所有功能一刀切只能有一件，也不要便宜无用物品可以按件刷分。

功能分类不等于可以自动拆分偏好。若把原 durables 拆成通信/工作设备/洗衣等评分叶子，新样例须明确提供各叶子点数，禁止把旧权重自动均分或按价格分配。也可保留原评分叶子、仅按功能去重；新 ADR 明确聚合和容量规则。

未来属性例子：BYD/Tesla、小米/苹果、中餐/意大利餐、大众/高端、外卖/自做、有机蔬菜/烤鸡/冰淇淋。V1 只存可扩展属性并演示粗方案；V2 才启用品牌/菜系/档次匹配。未启用属性要报告“未评价”，不能根据高价格推断高品质偏好。

不要写死品牌×国家价格规则。中国或美国哪一款更便宜，需要同版本、年份、税费及报价；当前例子只表达愿景。

### C. 来源、共同粒度与覆盖

以最小改动扩展 SourceRecord 或等价的已有机制，表达 observed / 可审计派生 / 统计估计 / synthetic。名称可以按项目风格定，但每个派生结果必须能追到输入和规则，不能有 URL 就当实测。

给比较组明确声明：地理粒度、时间基准、行动类型、规格/单位、评分版本。写检查和报告，拒绝缺资料城市补默认值的做法；真正不可得仍可合法表达，不要求每城机会数量完全相同。

覆盖算到偏好叶子：
- 非物质：a=w_k；
- 物质细项：a=w_material×m_j；
- C_i 为全部候选城市共同支持的叶子权重之和。

报告支持、估计/情景、未知及受影响的用户需求；背景资料有了不代表行动效果也建模了。只有 synthetic 输入时明确“合成契约覆盖”，不能说真实覆盖率 100%。

本轮不新增万能百分比阈值；50% 不解锁完整总分。保持正权重未知时完整总分为空、不补零、不按城重加权；只新增报告。必要账务资料和硬要求单独检查，不被覆盖百分比豁免。有限区间/最终排名属于 E1-6，不在本轮实现。

### D. 自然景观与户外环境加分

所有者已明确选择：自然景观/户外环境吸引力进入环境；购物、历史古迹等旅游吸引力不混入这一项。

采用指南中的有界探索规则，或在 ADR 说明严格等价的最小实现：

S_env = min(c_env, S_physical + beta × A_nature)。

- A_nature 为共同定义的 0–1 指标，须有来源或显式合成说明。
- beta 在比较组共用、非负、配置化；演示可用 0.1，同时验证 beta=0 对照。
- 不根据城市名、游客数或收入猜自然环境；缺失不当零。
- S_physical 本轮仍为显式合成基础环境，不能声称已接真实空气/气候；其本身未知时，不被景观加分补成已知。
- 不把已含在基础环境中的同一景观重复加分。
- 输出基础、景观贡献、截顶和来源。
- beta>0 且正权重环境所需的景观数据未知，保持不完整；beta=0 时未启用项不阻断。

可在生活评分中作局部映射或小幅推广既有分项结构，选最小清晰方案。不建立通用公式解释器。旧配置继续走原规则，新公式带新版本。

### E. 简化的住房—通勤组合

不做地图。提供少量显式方案，住房条件、月租、每工作日往返分钟作为同一方案的事实。允许长通勤换低租金，不要求所有真实城市存在统一负斜率。

合成演示可用：相同住房条件，近处月租 1400/往返30分钟；远处1000/70分钟。数字必须标为合成，且符合最低生活目录检查。

- 从实际执行住房/兜底读取对应通勤，不从原计划理由读。
- 不能拿远处低租金配近处短通勤。
- 实际降级、服务月份和通勤一起变更。
- 还须核对当月实际线下工作，不能把住房服务月自动当作通勤月。本轮最小演示限定明确固定的线下工作安排；无工作、远程、多岗位等未定义组合显式报方案级评分不支持/信息不足，不擅自给最高分或照扣通勤分。新 ADR 写清适用范围，并补负例。
- 住房不自动改善安全或室外环境。
- 资料统一到背景级的比较组就全部使用背景级；只有全组通过方式/方案级检查才开启相应选择。

新探索通勤分建议为 S_commute(T)=tau_T/(tau_T+T)，T 是往返分钟，tau_T>0 所有城市共用。演示可取 tau_T=60；长通勤必须降分。新规则是对实际条件的映射，不是把分钟作为正改善叠在旧城市分上。

实际占用小时=往返分钟×工作日数/60 的接线、工作日和远程比例的进一步细化、时间精力预算留 E1-4；本轮记录事实、适用范围与单位，不宣称完整生活可行。

### F. 其他维度与未来任务登记

- 安全：统一城市背景；不造“房租买安全”系数。
- 医疗：本轮背景与场景设计。E1-5 用年龄和工作相对精力强度设计 none/minor/major 随机情景；明确时间单位、历史窗口、初始条件、病程/费用/工作中断及恢复规则，参数标情景假设。同分身同时间共用随机数，各城概率因实际负荷不同可以不同；不强制结果相同。避免当期循环。当前不创建未使用的完整疾病执行器。
- 职业：按 ILO 和指南中论文核查，E1-5 实现参与培训→完成→资格→岗位申请/获得→收入与工时；资格不暗含保证录用或必然涨薪。
- 休闲：V1 抽象易得性/可购买性与实际使用；不按爱好地理加分。E1-4 管时间；V2 再做爱好占比和城市匹配。
- V2：品牌/菜系/档次/更细商品；多国真实资料；爱好—地理；更细寿命、维修、故障、替换、二手与真实折旧。已有物品月度寿命必须保留；E1-6 的期末现金/物品评价仍按原阶段推进，不推迟到 V2。

这些后续政策只登记职责和最小数据需求，不悄悄开启。不必为了“留接口”新增一堆没有调用方的执行类型。

- 研究真值/评分规格/参数/内部得分不能进入观察。新增属性、通勤等事实只能经许可投影进入。
- 产品只用明确陈述数值，不从消费占比或文字补权重。
- 同样的实际功能条件，不因价格更高直接得分更高。
- 货币保持当地基年口径，不混币、不重复空间平减。
- 旧 E1-1/2/3 输入和历史证据保留；新配置、新协议、新输出目录。历史目录存在时拒绝覆盖。
- 不因新生活协议而重跑 P8/P9/P10。以后用新轨迹估偏好需另做适用性验证。

## 5. 验收与预算

先跑相关生活测试和格式检查，再跑一次适当的全量回归；不做昂贵拟合、大规模 bootstrap、真实 LLM 或付费资料调用。

至少给这些有生活含义的证据：

1. 数量直接记录；新旧持有、续购、跨年与重排不改变应有结果。
2. 单件与无用途重复购买：后者不会靠件数刷功能满足感；容量型例外遵守声明。
3. 相同实际条件只改标价：直接分项得分不变；预算变化另由结算产生。
4. 同一组稳定偏好面对不同价格/方案，有不同可行安排；别声称本轮已证明 LLM 会作出这些选择。
5. 自然景观贡献有界、来源明确、可关闭；缺失与重复来源被检查。
6. 租金—通勤组合不拆配；降级、月份、方向和手算正确；未定义的非工作/远程/多岗位安排不会被误算为实际通勤。
7. 共同粒度不一致被拒，真实不可得与未知不混淆。
8. 物质细项权重覆盖正确；不把只有一部分可算误写成整体通过。
9. 评分侧新对象继续被隔离，事实反馈不含答案。
10. 旧样例可运行，旧数学与历史产物不变。
11. 通过新建输出目录离线演示，保存配置、源码指纹、实际命令/argv、协议、结果、手算核对与检查结果；不得复写旧 runs。
12. 对数量推断、重复功能、缺失当零、通勤方向这几类关键错误做针对性反例或变异检查，不凑测试数量。
