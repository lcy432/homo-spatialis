三、成长满足感：本轮确定的最小政策
3.1 使用已有维度和数学形式
使用现有 `opportunity` 维度及其用户权重，不新增第八维，不另造一份“成长偏好”。
产品评分读取用户明确陈述的权重；研究路径读取研究内部偏好。继续使用原来的隔离规则，不互借数据。
在新的评分版本中：

```
z_m = b_opportunity + eta_growth × g_m
s_opportunity,m = min(cap, z_m / (z_m + tau))
月度总分仍由原有七维加权函数计算
```

复用现有饱和函数、上限与加权机制。不要把旧 M2 的对数效用直接接入生活评分。
`b_opportunity` 表示城市的发展条件；新增项表示这个人在该月实际发生的成长。两者含义分开登记。当前背景不是根据本人的培训结果计算的，不能再把同一成长结果回填背景。
3.2 怎样计算实际成长
采用“当月新增能力进度”，暂不建立持续成就感、遗忘或心理适应机制。
对固定能力词表中的每项能力 a：

* 年初已经拥有的能力，其进度视为 1。
* 未拥有的能力，用明确授予它的课程的实际累计参加月数／课程要求月数表示进度。
* 多门课程授予同一能力时，取最高进度，不把两门半学完的课拼成一个完成资格。
* 进度范围为 0–1。
* 月度推进只能使用本月及此前已经实际参加的记录，不能提前读到年底成果。

定义：

```
g_m = Σ_a [p_a,m − p_a,m−1]
```

要求：

* 进度依据来自同一次真实结算，不读行动理由，不根据学费、工资或课程名称猜测。
* 未参加、未付成学费、被拒绝的课程不增长。
* 同一能力已完成后，重复学习不再产生这一能力的新增成长分。
* 暂停月份无新增成长分；恢复后只计真实新增进度。
* 能力仍按原规则从下一行动年起满足岗位要求。
* 当月可以有成长满足感，不等于当月可以提前使用尚未生效的资格。
* 出局月及之后继续沿用现有月度评分状态，不借此补分。

一门课程明确授予多个不同能力时，按固定词表中的不同能力计算。记录“能力拆分粒度会影响成长量”这一假设；能力词表由环境配置决定，代理不能自创能力或成果。
3.3 参数与生活含义
新合成演示可取 `eta_growth = 12`，并提供 `eta_growth = 0` 对照。
例如一门 12 个月课程，每月新增进度 1/12：

```
b=2，tau=2，cap=0.9
不学习：2/(2+2)=0.5
实际学习当月：(2+12×1/12)/(2+12×1/12+2)=0.6
```

若用户发展权重为 0.2，其他结果固定，该月总分差为 0.02。
12 是探索参数，不是现实心理规律或固定单位换算。与能力粒度、成长持续期政策一起登记到 CA-06 及相关目录条目。
本轮成长奖励只随当月实际进步出现。完成后能力继续保留，但证书本身不会永久自动加分。涨薪也不直接加分；钱仍通过实际生活服务产生效用。
当前用学习形成的能力进步代表可测的职业成长。不凭换岗、职位名称或涨薪自动推断额外成就感，注明此限制。
四、广义交通评分
4.1 含义与公式
保持内部维度键 `commute`，在人类说明中明确其含义是“交通便捷程度及出行对生活的影响”。上班通勤是其中最常见的组成部分。
本轮使用一个明确的合成近似：

```
k_m = rho + (1 − rho) × D_m / D_ref
T_equivalent,m = k_m × T_m
s_transport,m = tau_T / (tau_T + T_equivalent,m)
```

其中：

* `T_m`：本月实际所住住房绑定的往返分钟；降级后读取实际住房。
* `D_m`：本月实际累计到岗次数，多岗位相加。
* `D_ref`：参考到岗次数，演示为 20 次/月。
* `rho`：不因上班消失的交通影响，演示为 0.25。
* `tau_T`：沿用交通映射锚点，演示为 60 分钟。

用结构化岗位安排及实际执行／资源记录读取到岗次数，不仅根据 `onsite/remote` 字符串猜测，更不能只数岗位数量。不要另写一套与资源账不同的到岗统计。
4.2 必须支持的情况

* 无工作、纯远程：D=0，系数为 rho。
* 混合办公、兼职：按实际到岗次数连续变化。
* 多岗位：累计到岗次数；仍沿用各岗位分别往返的资源假设。
* 一份到岗20次：系数1。
* 两份各到岗10次：系数1。
* 两份各到岗20次：系数1.75。
* 未执行的岗位不得进入累计次数。
* 实际记录或住房分钟缺失仍报未知，不能补0。
* 生活出局月仍依照现有评分边界单列，不因交通公式扩展而补成完整月份。

4.3 不改变时间账的含义
`T_equivalent` 是评分中间量，不是真实出行分钟。
原来的工作通勤时间仍为：

```
Σ（实际住房往返分钟 × 各岗位实际到岗次数）/60
```

不乘 rho 或 k，不重复扣时间、精力。
本轮没有细化非工作出行时间。明确登记这个省略，不能声称它已经在资源账里核算，也不能无依据声称已经从时间预算中扣除。
用住房的工作往返分钟代理广义出行条件，也是一项合成映射假设。它不能完整反映购物、社交、就医及公共交通可及性。未来有共同粒度资料时可以替换，当前不新增 GIS 或出行网络模型。
4.4 参数登记
rho=0.25、D_ref=20、tau_T=60 均写清性质、单位和取值依据；不得标成已由真实数据估计。
提供 rho=0、0.25、0.5 的小型对照。组内所有城市使用同一规则，不能按城市是否缺数据临时选择口径。

六、边界文档订正
不实现额外功能，只把现状写准确：

* 跨年度暂停学习、保留进度、恢复后不重复收学费已经支持。
* 同一年中同一课程拆成多段不连续时间，目前不支持。
* 当前课程长度仍是12个有效参加月的整数倍，不支持短课程。
* 当前培训代表主动的额外成长投入，不包含正常履职或普通入职培训；不能把岗位正常工时重复当作额外学习。
* 当前职业信息公开策略保留。
* `qualification_missing` 保持可识别的问题代码；在 E1-7 登记为可修改、可重试的计划拒绝，区别于资料损坏、程序错误和生活出局。

七、最低验收
必须覆盖：

1. 相同生活事实，仅有实际成长不同，发展分按手算变化。
2. 发展权重为0时，总分不因成长变化；权重不同的影响与原加权机制一致。
3. 没付成学费、没参加、理由自称学会，都不产生进度或成长分。
4. 重复课程、同能力多来源、已拥有能力不重复刷成长分。
5. 年底才发生的学习不改变年初月份评分。
6. 暂停月不新增成长分，跨年恢复只计新增进度。
7. 资格下一年生效规则不变。
8. 交通0、10、20、40次及两份各10次，结果可手算。
9. 远程、混合、无工作、多岗位在资料齐全时不再仅因安排类型缺交通分。
10. 住房降级、实际未执行岗位、资料未知的处理正确。
11. 新交通评分不改变原工作通勤小时和负担。
12. 新规则关闭的对照、旧协议复现、政策指纹与跨试算防混用成立。
13. 覆盖报告和评分器一致，新增内部参数无法进入可见输入。

金额、进度与资源边界按现有精确口径检查，不放宽阈值。评分用可手算例子和确定性重放验证，不以扩大容差掩盖错误。
