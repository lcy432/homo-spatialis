# E5 双语与双模式视觉要求

记录日期：2026-10-22；2026-10-24 更新已确认方向。本文记录前端美术与交互要求，不代表页面已经实现。工程状态仍以 [项目索引](../INDEX.md) 为准。真实资料与业务接口由 E3 会话推进，本文不改共享契约。完整实施范围见 [本轮工程 prompt](prompts/2026-10-24-e5-bilingual-dual-mode-service.md)，接口缺口见 [E5 → E3 交接单](../handoffs/e5-bilingual-map-service-requests.md)。

## 1. 中英文双语

界面支持中文和英文，覆盖输入表单、导航、地图标签与图例、图表、表格、错误与进度说明、结果解读以及 agent 生活汇报。

切换语言保留用户的填写内容、已选国家与城市、运行和结果。用户原始陈述保留原文，不因界面语言变化而改写。E3 返回的动态业务说明需要统一的双语支持，不能只翻译按钮而遗漏确认、限制和错误含义。

## 2. 稿纸铅笔模式

整体呈现旧式算术稿纸上的简单铅笔画质感。输入页面、结果页面、图表、表格与 agent 生活汇报使用一致的视觉语言，保持简单、清楚。纸纹、格线和铅笔笔触不能妨碍文字、数值与图表的辨认。

### 输入

- 展示简笔绘画风格的世界地图。
- 当前支持的国家涂色，其余国家仅显示轮廓。
- 用户可选择点亮的国家，进入该国支持的城市选择。
- 提供独立的城市列表或搜索入口，用户可以手动增减城市，不必在地图上操作。
- 地图与列表同步反映同一份选择；新草稿初始城市读取服务端选择，点击国家只展开或筛选城市，不隐式全选。

### 输出

- 展示简笔绘画风格的国家地图，并标出本轮评价覆盖的城市。
- 涉及多个国家时，支持多个国家地图并列；窄屏布局保留全部国家的访问入口。
- 用不同颜色表达城市本轮评价的差异，配清楚的图例。
- 地图之外，提供适合数据含义的图表、表格和文字解读，以及 agent 生活汇报。
- 简笔风格不能改变国家轮廓、地理关系或城市位置。地图以可靠地理边界和坐标为基础，再增加笔触效果；不凭想象绘制地理。

## 3. 写实地球模式

输入和输出都提供可进入的另一种模式：写实风格的地球，搭配现代技术风格的面板。

- 输入时，用户可以在地球上选择具体城市。
- 用户可以拖动鼠标转动地球；提供合理缩放、触屏操作与重置视角，不自动持续旋转。
- 输出时，用户点击本轮覆盖的具体城市，查看该城市的分析结果。
- 地球上的选择与城市列表同步，列表仍可完成同样的操作。
- 地球和面板的风格统一；具体纹理、光照、配色和动效程度在后续设计中确定。

## 4. 两种模式共用的产品含义

以下约束沿用已有 E5 产品语义，作为落实本轮美术要求的边界：

- 两种模式共用同一份画像、国家与城市选择、运行和结果；切换模式不清空填答、不重新提交模拟，也不更改结果。
- 国家点亮与城市可选范围取自 E3 提供的支持能力；不能因为地图上存在某个国家或城市就使它可运行。
- 本轮地图默认使用 E3 返回的完整者平均 J；E3 AB 与 C 已确认当前有效值域为 [0,1]，同一结果内使用固定尺度，图例明确对应指标。它不意味着不同用户或不同轮次可比；正式显示元数据仍待实现，前端不另造综合分数或排名。
- 地图不能仅以颜色表达含义；城市详情与表格同时提供指标、C/E/M、均值分母、缺失和限制。
- 无评价、C=0、未运行或模拟缺失有明确的独立显示，不能用最低分颜色替代；生活出局与模拟问题继续区分。
- 多国地图使用一致的指标与图例口径，不能各自缩放色阶后暗示可以直接比较。
- 合成城市不冒用真实城市坐标，演示数据继续标明样例性质。
- agent 生活汇报在两种风格下均区分实际环境记录与模型解释，不因叙事或插画把计划写成已经发生的事实。
- 地图、地球、装饰字体与动效不妨碍手机和键盘使用；城市列表始终提供等价操作。

## 5. 本轮确认与实施余地

所有者已确认稿纸模式默认、地球模式可切换且可鼠标拖转。输入与结果都交付中英文和两种视觉模式，接同一套 E3C 业务接口。结果按“城市比较 → 单城详情 → 分身年度生活汇报”展开，具体要求见工程 prompt。

中英字体、纸张色温、笔触、两套配色、地图投影、图例位置、详情抽屉或路由、年度卡片排版等交给 coding agent 在准确、简单、易读的边界内决定。本文更新仅记录设计与实施范围，没有实现前端或部署。
