## 3. 展示时要守的口径

* 物质点数是相对重要程度，不是开支比例；兴趣不是“必须买”的指令。
* 买到、在用、实际参加是三件事：吉他在用不等于练了琴（样例 45）。
* 没成交的购买没有扣款；没能进行的活动没有收费、没有小时。
* “没认出”的兴趣原文与品牌只留存、本版不评分，也不交给分身；要原样显示给用户，不能写成“已支持”。
* 未答与明确选择通用评价是两回事：显示时用 `scope_zh` 的原话，不要都写成“已个性化”或“没有偏好”。
* `valuation_scope` 里“参考模板没有考虑它的用途”说的是估值范围，不是“装备没有价值”；不要把它显示成扣分或缺失。
* 匹配系数是公开登记的模型假设，不是对用户的测量；不显示任何评分参数。

## 4. 旧确认怎样处理

旧版本（v2）的确认画像不能补 0 或重新分配后沿用：结构版本不同，直接拒绝。界面应引导用户重新回答物质四项与兴趣、口味，重新审阅并确认（`tests/product/test_interests.py` 有这条检查）。

## 5. v3 在独立复核前的修订

2026-10-22 收尾修复（独立审核 R1–R9）在 v3 里加了上表最后几行的字段与 49、50 两份样例，`LifeItemVerdict.status` 多了 `unavailable`；界面层还没有开始读 v3，所以没有另开 v4。网页草稿测试仍然跳过，等界面层改读 v3。

## 6. 没有做的

真实资料里的食品方案与活动还不能编进 E1（缺做饭时间、新鲜餐数、活动参与时间；活动带日期与年龄限制）；编译检查现在只有受控样例，没有接 intake-02 的真实导出。期末参考生活只覆盖音乐练习这一种装备活动。E5 页面本轮没有改。
