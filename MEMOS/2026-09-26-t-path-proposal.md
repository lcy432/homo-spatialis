# `Σ_w(t)` 敏感性路径：两个候选，推荐 A

**这是评审稿。本轮不替换正式实现。** `DECISIONS/0013` 第六节那套"均值与协方差
一起线性插值"的实现原样保留、标为实验性；本文不批准任何一个候选，也不删除
已有证据。

---

## 一、先分开两件被混在一起的事

**共享几何**（`d`、`u`）与**固定先验参数**（`μ_a(t)`、`C_a(t)`）是两回事。
现在的实现把它们放在同一段代码里，读起来像一件事。

### 中心 `c` 取谁

```
c = E[w]  在匹配臂拟合出的分布下，权重空间实算
```

**不能用 `softmax(μ_a)` 代替。** softmax 是非线性的，由 Jensen，
`E[softmax(a)] ≠ softmax(E[a])`。这与"个体后验必须是 `E[w(a)|choices]` 而不是
`softmax(E[a|choices])`"是同一条，本仓库已经在个体那一侧守住了，总体这一侧
要守同一条。`alr.population_moments` 给的就是权重空间的抽样矩，用它。

**差距不是二阶小量。** 在注入分布自己的闭式参数上量一次（`μ_a = −2·1`、
`C_a = (π²−4)I`，20 万点）：

```
E[softmax(a)]    material = 0.2452      ← 正确的 c
softmax(E[a])    material = 0.5519      ← 用错的话
真值 E[w₁]                = 0.3333
```

用 `softmax(μ_a)` 会把中心放到 0.55，比真值高出六成还多，而且方向与真实偏差
相反。`d_i = ‖w_i − c‖` 全体跟着错，`proj` 与 `r` 一起废掉。


### `d` / `u` 构造几次

**一次分析里构造一次**，由 `c` 得出，各臂、各 `t` 按 persona ID 共用同一份
（硬规则 24）。**bootstrap 内每个 replicate 重估 `c` 后重新构造一次**，再在该
replicate 内共享——replicate 是一次完整的分析，几何跟着它走。

**共用几何不自动证明三臂有同一个衰减因子。** 硬规则 23 的消去依赖
`b = 1 − Cov(⟨δ,u⟩,d)/Var(d)` 在三臂相同，而那要求 δ 与 `(d,u)` 的联合结构
在三臂相同。共用 `(d,u)` 是**必要条件**，不是充分条件。任意模型下都成立的
版本不存在；报告里不能把"我们共用了几何"说成"衰减因子已消掉"。

## 二、两个候选

两者共用同一条 ALR 协方差路径：

```
C_a(t) = (1−t)·C_a,injected + t·C_a,matched
```

### A（推荐）：固定权重均值 `m* = c`

对每个 `t`，只校准六维 `μ_a(t)`，使

```
E[ softmax_b( μ_a(t) + L_t ξ ) ] = m*,    L_t L_tᵀ = C_a(t)
```

**它固定的是 `E[w]`，不是 `μ_a`**，也**不是**原来那种"权重空间协方差线性插值"。
六个未知数、六个方程（第七维由和为一决定），固定积分点 + 沿 `t` 温启动，
数值上是个小求根问题。

每点报告：目标 `m*`、**实际达到的** `E[w]`、残差、以及**实际的权重协方差**
（不是目标 `C_a(t)`——后者是 ALR 空间的，前者才是要解释的那个）。

### B：固定 `μ_a = μ_a,matched`

沿同一条 `C_a(t)` 插值，不解方程。更简单，但 `E[w]` 会随 `t` 漂移，因为
softmax 的期望依赖协方差。**必须报告诱导出的 `E[w]` 变化，不得命名为"权重均值
不变"。**

### 为什么推荐 A

`λ(t)` 要回答的是"先验离散度变化如何影响个体后验的收缩"。B 里 `E[w]` 跟着动，
`λ` 的变化混了两个来源（离散度 + 位置），解释不干净。A 把位置钉住，`t` 上只有
离散度在变。代价是每点一个小求根，以及"`E[w]` 精确命中 `m*`"只能到数值容差。

## 三、闭式起点（原 Dirichlet）

对 Dirichlet(α)，`k, l ≠ b`：

```
μ_a,k  = ψ(α_k) − ψ(α_b)
C_a,kl = 1{k=l}·ψ₁(α_k) + ψ₁(α_b)
```

α = (1.5, 0.5×6)、**material 为基准**（`α_b = 1.5`）时：

```
μ_a,k       = ψ(0.5) − ψ(1.5) = −2            对全部 k ≥ 2
对角 C_a,kk = ψ₁(0.5) + ψ₁(1.5) = π²/2 + (π²/2 − 4) = π² − 4 ≈ 5.8696
非对角      = ψ₁(1.5) = π²/2 − 4 ≈ 0.9348
```

（用 `ψ(1.5) = 2 − γ − 2ln2`、`ψ(0.5) = −γ − 2ln2`，差恰为 `−2`；
`ψ₁(0.5) = π²/2`、`ψ₁(1.5) = π²/2 − 4`。）

**但这组闭式矩是原 Dirichlet 总体的。** 若拟合对象是过采样后的实验人群
（`DECISIONS/0014` 第四节的 `ESTIMAND_GAP`），不能直接把它当作那个人群的真值。
当前默认按比例分配、权重恒为 1，两者一致；改成非比例分配就不一致了。

## 四、`t = 0` 到底匹配了什么

A 与 B 的 `t = 0` 一般**只**用到注入的 ALR 协方差。

- 除非均值也对上，**不能说"匹配了真值 ALR 分布的前两阶矩"**；
- 更**不是**精确的 Dirichlet 先验——logistic-normal 与 Dirichlet 是两个族，
  对齐两阶矩不等于同分布。

A 里 `t=0` 的均值被钉在 `m* = c`（匹配臂的），**不是**注入均值，所以 A 的 `t=0`
连均值都不是注入分布的。这不是缺陷，是设计：路径的两端是"注入的离散度"与
"拟合到的离散度"，位置始终由 `c` 固定。**但必须写明**，否则 `t=0` 会被误读成
"真值先验"。

## 五、沿路径固定什么

- 地板臂的选择数据：**固定**，不随 `t` 重生成
- 共享几何 `(c, d, u)`：**固定**，构造一次
- 外生 `σ`（由重复子集标定）：**固定**
- `(μ_a(t), C_a(t))`：由目标**钉死**，在这组固定参数上算条件后验
  （`alr_posterior_at`），**不重新拟合总体**——重估会把指定的路径覆盖掉

`t` **无须单调**：方向取决于 `C_a,matched` 与 `C_a,injected` 的大小关系。
它**不天然给出严格的识别上下界**，报完整曲线，不挑端点（硬规则 20）。

## 六、均值漂移作为补充指标

```
Δ = μ̂_w,matched − μ_w,target
```

可以报，但要带三条限定：**模型依赖**（依赖 logistic-normal 设定）、**抽样目标
依赖**（`ESTIMAND_GAP`）、**含回收基线偏差**（估计器自身在合成地板上就有偏）。

**不得称它是"完全可识别的纯 LLM 效应"**，也不得说它与坍缩统计量独立——两者
共用同一次拟合。正式区间留待整条流水线的 bootstrap。

## 七、不要加的一条断言

**不要在生产代码里硬断言 `μ̂_shuffled ≈ μ̂_matched`。**

可以测的：**离线完整置换**下，被置换的集合与其均值不变——那是纯组合恒等式。

不能当断言的：实际打乱后重跑两条臂再比均值。那只是一个**带不确定性的诊断**，
且只在同一目标人群、同一设计、可交换性成立时有意义。用 `allclose` 去卡它，
等于把一个统计问题写成一个会随机失败的相等判断。
