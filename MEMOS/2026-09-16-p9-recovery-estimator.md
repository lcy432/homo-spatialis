## 1. 差分法：最初的设定与它为什么会产生非法权重

### 1.1 数学【当时的判断】

`Σw = 1` ⟹ `1'Σ1 = 0`，而任何非零对角阵满足 `1'Σ1 > 0`。所以"在七维权重空间
用对角协方差"是一个**不可能**的设定，与"秩最多 6"直接矛盾（README §11.7.1）。
修法是取第 `b` 维作基准，代入 `w_b = 1 − Σ_{k≠b} w_k`：

```
η_itc = x_itcb + Σ_{k≠b} w_ik·(x_itck − x_itcb)
V_itc = γ_0·x_itcb + Σ_{k≠b} γ_ik·(x_itck − x_itcb)
γ_0   = 1/σ                （固定但**要估**的总体系数）
γ_ik  = w_ik/σ             （人设层随机系数，六维）
```

`γ_0` 必须固定：若它也随机，`w_k = γ_k/γ_0` 就是两个正态之比，分布不再可控。
设成固定等价于假设尺度 σ 在个体间相同——标准假设，但必须写明。

反解与七维协方差回构：

```
σ̂    = 1/γ̂_0            ŵ_k = γ̂_k/γ̂_0 (k≠b)     ŵ_b = 1 − Σ ŵ_k
Σ_q  = Σ_γ/γ_0²          Σ_w = B_b·Σ_q·B_bᵀ
```

`B_b` 是 7×6 的线性映射（非基准维取单位向量，基准维那一行是 `−1ᵀ`）。由
`Bᵀ1 = 0` 得 `Σ_w·1 = 0` 与 `rank(Σ_w) ≤ 6` **构造上恒成立**，不需要事后裁剪。

### 1.2 为什么会出负权重，以及为什么不裁剪【当时的判断】

差分法保证 `Σŵ = 1`（这是代数恒等式），但随机系数取**正态**时不保证
`0 ≤ ŵ_k ≤ 1`：`γ_k` 可以是负数，`w_k = γ_k/γ_0` 随之为负。

**不用裁剪、投影、取绝对值、重归一化、丢弃越界个体、缩小方差中的任何一种。**
理由不是洁癖：这六种做法每一种都改变估计量本身及其抽样性质，而 P8 要测的正是
估计量的偏差。一个被裁剪过的估计量，它的地板不再是原估计量的地板。所以差分
分支**如实报告**越界比例与最大幅度，有一条测试盯着这件事
（`test_difference_normal_still_reports_illegal_weights_without_fixing_them`）。

【新增证据】150 人设 × 6 次 × 7 城、真值 σ=0.08 的一次性对照里，差分分支的个体
后验均值越界比例是 **32.0%（对角）与 58.7%（完全）**。这不是边角情形。

## 2. 估计后端：为什么手写似然

### 2.1 xlogit 的能力边界【当时的判断，**版本限定**】

**以下结论对应 `xlogit==0.2.7`，不是永久事实。** 换版本必须重测——
`tests/eval/test_recovery_xlogit.py` 把这三条写成了会失败的断言。

| 需要的能力 | 0.2.7 | 依据 |
|---|---|---|
| 一个估计的固定系数 `γ_0` | 支持 | 不在 `randvars` 里的列即固定系数 |
| 六个随机系数 | 支持 | `randvars={col:'n'}` |
| 面板似然（按人设聚合） | 支持 | 源码 `_prob_product_across_panels` |
| 完全协方差 | **不支持** | `fit` 签名无 correlation 参数 |
| 个体条件后验均值 | **不支持** | 只有 `predict` |

后两项是硬需求，所以主后端是手写的模拟似然；xlogit 降为**对角规格的交叉验证**。
实测两者在同一批数据上 `γ_0` 差 0.6%、`μ` 差 5.6%、`sd` 差 7.8%。

### 2.2 一个结构性便利：梯度里的权重就是后验权重【当时的判断】

```
q_i^{(r)} = L_i(γ^{(r)}) / Σ_r L_i(γ^{(r)})     ← 后验权重
∂LL/∂θ    = Σ_i Σ_r q_i^{(r)} · ∂ℓ_i^{(r)}/∂θ   ← 梯度
```

个体后验用的权重**就是**梯度里那个权重。分两套代码去算同一个量才是重复造轮子，
而且两套代码迟早会用上不同的 draws。所以个体后验与似然**共用同一批 draws**，
这是实现上的硬约束，不是优化。

解析梯度对 ρ、μ_a、对角 L、完全 L 四类参数分别做过有限差分核验（多个非零参数
点、多个 seed，误差 ≤ 1e-3，即有限差分自身的精度量级）。

bootstrap 按人设重抽、重复抽中的人设发独立面板 ID、每个 replicate 完整重拟合、
下游指标走 callback——这些在 P9 阶段就已实现，本次只加了一个可选的 `fit_fn`
钩子，让 P8 的 replicate 走与点估计**同一套**多起点流程。

## 3. ALR / logistic-normal 分支

### 3.1 规格【当时的判断】

```
a_{i,k} = log(w_{i,k}/w_{i,b})     k ≠ b，基准维坐标恒为 0
a_i     = μ_a + L·ξ_i              ξ ~ N(0, I₆)，Σ_a = LLᵀ
w_i     = softmax(a_{i,1}, …, 0_b, …, a_{i,6})   ⟹ 0 < w < 1 且 Σw = 1
ρ       = log γ_0 ，γ_0 = exp(ρ) = 1/σ > 0
η_itc   = γ_0 · Σ_{k=1..7} w_{i,k}·x_itck        ← 原始形式，不差分
```

Cholesky 对角线走 log-diagonal，**不取绝对值**。

**总体矩在权重空间实算**（固定 seed 的抽样点），不用 delta 近似——要报的正是
`Σ_w` 有多大，用一个"假定它很小"的近似去估它是循环的。

**个体后验必须是 `E[w(a)|choices] = Σ_r q_r·w(a^{(r)})`，不是
`softmax(E[a|choices])`。** softmax 非线性，后者由 Jensen 不等式系统性偏向单纯形
的某一侧，而那个偏移会被读成坍缩。有测试把两者的差异钉住。

### 3.2 为什么保留差分分支，为什么当时没切默认【当时的判断】

差分分支有全套 xlogit 交叉验证、快 3–5 倍，且它的数学是 README §11.7.1.1 的
正文规格。**换默认估计器是一次科学裁决，不是一次实现选择**，所以 `DECISIONS/0011`
把它列为待裁决，两个分支并存、默认不变。

### 3.3 为什么现在选完全协方差【新增证据 + 现在的裁决】

**关键证据是诊断三**（1000 人设 × 12 个不同选择集 × 12 城，σ=0.05，三个种子，
四个起点按似然选解）。完整七维数据见附件
`runs/2026-09-16-p9-evidence/logs/diag3-three-specs.log`；下表只摘 material 一列
与整体误差，**不用平均值掩盖弱维度**——全部七维在附件里。

| 规格 | material 方差比（三种子） | Σ_w 相对 Frobenius |
|---|---|---|
| ① 对角 base=material | **0.629 / 0.664 / 0.628** | 0.372 / 0.335 / 0.355 |
| ② 对角 base=safety | 1.425 / 1.336 / 1.327 | 0.478 / 0.447 / 0.416 |
| ③ 完全 base=material | **0.970 / 0.968 / 0.983** | **0.170 / 0.162 / 0.184** |

规格 ② 里被低估的换成了 safety：**0.359 / 0.324 / 0.376**。也就是说
**低估随基准维转移**——它是设定的性质，不是 material 的性质。

个体精度三个规格并列（七维平均相关 ① 0.830/0.839/0.823，② 0.825/0.833/0.817，
③ 0.829/0.834/0.824），而 ③ 的 material 个体 RMSE 反而更好（.0943/.0945/.1003
对 ① 的 .1011/.1019/.1054）。σ̂：① 0.0503/0.0518/0.0513，② 0.0529/0.0531/0.0535
（系统性偏高约 6%），③ 0.0504/0.0512/0.0515。

**机制有代数依据，但"基准维必然被低估"不是已证明的一般定理。** 有依据的部分：
换基准维是 ALR 坐标上的可逆线性映射，正态族在其下封闭，所以**完全协方差的
logistic-normal 是基准维不变的**，而对角约束不是（对角性不被这个线性映射保持）。
把估计完全排除的矩匹配模拟也重现了这个不对称。**没有依据的部分**：为什么对角下
基准维恰好是相对最小的那一维，只有定性论证（基准维坐标被钉在 0，其权重方差只能
由其余六维诱导），没有推导。

**矩匹配核验匹配的是哪种矩必须写清楚**：那次模拟在 **ALR 坐标 `a` 空间**做矩
匹配（取 `a` 的样本均值与协方差），然后看诱导出的**权重空间**方差。它把非基准维
方差抬到 2.2–3.5 倍，而实际 MLE 给出 0.75–1.30——**MLE 不是在做矩匹配**。
所以那次近似只支持"对角族依赖基准维"这个机制，**不能据它证明某个分布族绝无
表达能力**。

**现在的裁决**：主规格 = ALR logistic-normal + 完全协方差 + material 基准 +
四个固定起点按似然选解。详见 `DECISIONS/0013`。**默认 `RecoveryConfig()` 不动**，
通过命名 profile 选规格。

## 4. commute：压缩链路与长通勤臂

### 4.1 原始压缩【当时的判断，已被证据细化】

`A(t) = 1 − t/480`，`t ∈ [15, 45]` 分钟（美国都会区经验区间）。链路：

```
raw 单程分钟 18.6–29.7 (sd 3.38)
→ A = 1 − raw/480 ∈ [0.938, 0.961] (sd 0.0070)
→ ln A (sd 0.0074)
→ 组内中心化 sd 0.0093
```

`ln A` 在整个支撑集上的跨度是 **0.0667**，因此**任何**选择集的标准差上界是
**0.0334**，而其余五维中位 0.2088。选世界、重试都够不着这个上界。

### 4.2 长通勤臂【现在的实现】

`DECISIONS/0012`：12 城中 3 城取 60/90/120 分钟单程，**默认关闭**，显式启用。
指派按 `z_commute` 的**世界内排序**（最低的拿最长的一档），所以分钟数仍是同一
隐变量的非增函数，因子结构保留（`corr(分钟, 其余五维均值)` 由 −0.249 变 −0.219）；
规则只读世界自己的隐变量，**与真值权重无关**。

效果：组内 sd 0.0089 → 0.0760，`unique rel` 0.039 → 0.312。

**这是人为设定的长通勤情境，不是现实城市频率校准。** 60 分钟接近美国都会区
现实上沿，90 与 120 已经超出。口径没变（仍是城市层面代表性单程分钟，不是个人
通勤），变的是取值范围。**没有建模同一城市的日际通勤尾部风险**，也没有引入
风险厌恶效用项。本次不再扩大范围。

### 4.3 仍未解决【新增证据】

`commute` 的回收相关仍只有 0.087–0.122（σ=0.05）与 −0.006–0.113（σ=0.10）。
**"损害可控"不等于"可识别"。** ALR 把该维压到 0.000 而不是甩到 0.410，σ̂ 从
0.0318 回到 0.0530，但它没有把 commute 测出来。这一区别有专门的测试钉住。

## 5. `quantile_ln_sd` 与识别诊断的两个坑

### 5.1 它作用在标度函数【已确认的事实】

`quantile_ln_sd` 在 `worlds.attributes.scale_amenity` 里，把隐变量映成 `A`。
**不能把调整它描述成"只改变城市生成"**——同一个隐变量抽样下，改它就改了 M2
给出的分数。四个分位维本轮维持 0.22，未同时调整。

### 5.2 相对诊断掩盖"多维共同缩小"【新增证据，本次修过一次实现】

原来的切空间谱按七维组内标准差的中位数归一，对"所有维度一起变小"是瞎的——
分母跟着一起变。实测它甚至**反向**：

| σ_q | 相对最小奇异值 | 绝对最小（ln V） | 旗标 | 六维平均回收相关 |
|---|---|---|---|---|
| 0.02 | 0.453（看起来最健康） | **0.0096** | （无） | **0.210** |
| 0.22 | 0.255 | 0.0511 | commute | 0.705 |
| 0.855 | 0.086（看起来最差） | 0.0656 | commute | 0.734 |

因此新增 `tangent_singular_values_absolute`（ln V 单位，只除 √n）。

**但"绝对最小奇异值超过 σ"不是可识别性定理。** 它是一个有量纲的、可以和噪声
尺度比较的诊断量，必须与**概率、噪声与样本量**一起看——同样的谱在每人 3 次与
每人 12 次下给出完全不同的回收（见第 6 节）。同理，`flagged()` 的 0.10 是
**建议阈值、report_only**，不是判据。

## 6. 从 150×3 到 1000×6/8/12 的证据

### 6.1 leisure 异常及其订正【当时的判断 → 新增证据】

【当时的判断】150 人设 × 每人 3 个选择集下，leisure 的回收相关只有 0.034，而
真值先验下的数值参照是 0.542。当时归因于"优化器边界塌缩"。

【新增证据】四个离散度起点（sd0 ∈ {0.1, 0.5, 1.0, 2.0}）在对角规格下 logL 极差
只有 **0.0055**，参数几乎相同——**不是起点问题，也不是收敛失败**。真正的原因是
似然在 leisure 的方差方向上近乎平坦：固定其余参数扫该维潜空间 sd，在
[0.05, 0.40] 上似然差 ≤0.05。

【新增证据】**这个异常在正式规模下不复现。** 1000 人设 × 每人 6 个选择集时
leisure 相关是 0.766 / 0.780 / 0.798（三种子），与其余五维齐平。

**不能断言"人数少与题数少必须同时发生"**：两项诊断之间这两个量同时变了
（150→1000、3→6），没有跑 2×2，无法分离。这是一个**未确定项**。

### 6.2 题数【新增证据】

每人不同选择集数 6 / 8 / 12（同一套 12 次记录取前缀），1000 人设、三种子：

| 选择集数 | commute 相关（三种子） | 七维平均相关 |
|---|---|---|
| 6 | 0.420 / 0.532 / 0.394 | 0.798–0.828 那一列见附件 |
| 8 | 0.494 / 0.559 / 0.448 | 同上 |
| 12 | 0.587 / 0.631 / 0.546 | 同上 |

三个种子、七个维度上 6→8→12 全部单调改善，无反例。完整逐维表在
`runs/2026-09-16-p9-evidence/logs/diag2-task-counts-TRUNCATED.log`。

**相关性不是信息百分比。** 不能把 `1 − corr` 读成"损失了多少信息"，也不能把
两个 corr 相减读成"某个来源占多少比例"。

**"12 个不同选择集"与"同情境重复 12 次"是两件事。** 后者是 §11.8 的重复子集
（150 人 × 3 次），两条预算线互不替代。

## 7. 诊断三的核心对照【新增证据】

## 8. 三处历史叙述的订正

**订正一：单维扫描是似然切片，不是完整剖面似然。** 第 6.1 节那次"固定其余参数
扫 leisure 的 sd"是 likelihood **slice**，不是 profile likelihood（后者要对其余
参数重新优化）。因此**不能据 1.92 宣布正式的 95% 区间**——弱识别与边界附近，
χ² 近似本身也未必成立。当时写的"真值落在置信区间内、没被似然拒绝"应改成：
**在该切片上，真值对应的位置似然罚很小，似然对该方向几乎不提供信息**。

**订正二：oracle 是数值近似，不是有限样本相关性的绝对上界。** 那个"真值先验 +
真值 σ 的精确后验"靠重要性抽样，ESS 在每人 12 次时中位只有 **521/40000**、
p05 165。它本身带误差，**不能当作上界**，更不能用 `1 − corr` 把差距说成损失
百分比。

**订正三：起点日志自相矛盾，按原始记录订正。** 早期报告写"8100 对角/material
四起点重合"（logL 极差 0.0075），后期报告写"`sd0=0.1` 在全部九块都明显差"。
按原始日志（`runs/2026-09-16-p9-evidence/logs/diag3-three-specs.log`）：

| 块 | logL 极差 | `sd0=0.1` 是否明显更差 |
|---|---|---|
| 8100 对角/material | 0.0075 | **否**，四个起点重合 |
| 8200 对角/material | 33.80 | 是 |
| 8300 对角/material | 25.29 | 是 |
| 8100/8200/8300 对角/safety | 25.69 / 47.93 / 29.25 | 是 |
| 8100/8200/8300 完全/material | 138.72 / 63.48 / 67.94 | 是 |

所以正确的说法是：**九块里有八块 `sd0=0.1` 明显更差，8100 的对角/material 那一块
是例外。** 早期那句"四起点重合"只对那一块成立，被错误地推广了。**因此不能据此
删掉任何起点**——恰恰相反，它证明多起点是必要的。

**订正四：27.7 的跨基准似然差不能全归因于优化。** 完全协方差族是基准维不变的
（代数），所以理论上两个基准维应当收敛到同一个分布。但**"正态族理论不变"推不出
"200-draw 的数值目标完全相同"**：有限模拟误差本身依赖坐标。本次最小核查就是为了
分离这两者，结论见第 9 节。

**订正五：ALR 的权重有界，不能照搬差分的"矩不存在"论证。** 差分分支里
`ŵ = γ_k/γ_0` 是比值估计量，`γ_0 → 0` 时矩不存在。ALR 分支的 `ŵ ∈ (0,1)` 恒有界，
**所有矩都存在**。`γ_0` 趋零在 ALR 下的后果是选择趋于随机、信息趋零，不是矩发散。
两者是不同的失败模式，不要混用论证。

## 9. 最小数值核查（2026-09-16，种子 8100）

脚本 `scripts/diagnostics/check_base_change.py`，原始日志与机器可读结果见
`runs/2026-09-16-p9-evidence/`。**代价说明**：诊断三只打印了摘要、未保存参数
向量，所以这次必须重建种子 8100 上的两次完全协方差拟合（各四起点，合计
881s + 944s）。本次已把拟合参数写进 JSON，以后不必再重算。

### 9.1 换坐标恒等性：全部通过

对**同一批** latent draws 直接做 `a' = T·a`（不是在新坐标里重抽一批然后声称
"同 seed 即同样本"）。`T` 是对合，`T² = I`。

| 量 | 最大差值 | 容差 |
|---|---|---|
| 七维权重（逐点） | 3.3e−16 | 1e−10 |
| 面板对数似然（逐人逐 draw） | 2.8e−13 | 1e−06 |
| 总对数似然（相对） | 0.0 | 1e−12 |
| 个体后验均值 | 3.4e−15 | 1e−10 |
| 同批样本总体均值 / 协方差 | 1.4e−17 / 6.9e−18 | 1e−10 |
| `mean(a')` 对 `T·mean(a)`（同批样本） | 3.3e−14 | 1e−10 |
| `cov(a')` 对 `T·cov(a)·Tᵀ`（同批样本） | 1.0e−14 | 1e−10 |
| `T²=I`（参数层面） | 0.0 | 1e−14 |
| `T` 对 `alr_from_weights` 交叉验证（参数层面） | 8.9e−16 | 1e−12 |
| `Σ'=TΣTᵀ` 仍可分解（参数层面） | 4.4e−16 | 1e−14 |
| 样本矩对总体参数：均值 / 协方差（**抽样收敛**） | 1.0e−04 / 6.9e−04 | 5e−03 |

**订正六（本次核查自身的一处测试设计错误）。** 第一版把最后两行写成"样本矩对
总体参数"却声明了 1e-12 的双精度容差，于是报了两项"超容差"。那是**测试写错了**，
不是实现错了：样本矩与总体参数之间隔着蒙特卡洛抽样误差（随机抽样下均值的标准误
约 `1/√200000 ≈ 2e-3`），不可能匹配到双精度；观测到的 1e-4/7e-4 正是这个量级。
正确的双精度恒等式是**线性性**（同一批点下 `mean(a') = T·mean(a)`），它与参数层面
的代数分开，抽样收敛那两行按抽样误差定容差。

**订正七（同一处，又错了一次，值得单独记）。** 订正六新加的"参数层面代数"两行写的是
`|Tμ − Tμ|` 与 `|TΣTᵀ − TΣTᵀ|`——**把一个量和它自己比**。它们恒等于 0，无论实现
对错都"通过"，所以上一版表里那个漂亮的 `0.0 / 0.0` 不是证据，是占位符。
第二次修的时候把后者换成 `|LLᵀ − Σ|`，看着像个检查，其实 `sigma_alr` 在
`msl_alr.py` 里就是 `chol @ chol.T` 构造出来的，同样恒为 0，只是多绕一层。

现在换成三行**能失败**的量，并逐条做了变异测试：把 `T[0,0]` 改 1.0、把某行符号
反转、把 `TΣTᵀ` 误写成 `TΣT`，分别给出 6.13、10.9、非 PSD 抛错，而正确实现是
8.9e−16。其中"`T` 对 `alr_from_weights` 交叉验证"是**唯一**真正验证了"`T` 就是那个
换基映射"的一行——两条独立实现的路径算同一件事——而前两版完全没验过这一点。

**教训不是"手滑"**：三次里有两次，我写出的是形状对、读起来像证据、但不可能失败的
断言。判断标准应该是**能不能说出一个让这一行失败的 bug**；说不出来，这一行就不该
进表。这与本备忘录第 2 节记的"源码文本测试匹配到自己的 docstring"是同一类错误。

### 9.2 跨基准似然差：不同评价设置下观察到多少

> **订正八（本节曾把观察值写成误差分解）。** 上一版这里叫"三段分解"，给了一张把
> 27.7 拆成"坐标实现 6.8 / 有限模拟误差 4.0 / 优化落点 16.9"的表。**那三个数是
> 相减出来的差值，不是被识别出来的误差成分。** 原始数值一个没改，改的是它们能
> 支持什么结论。

两个解都搬到 **material 坐标、同一套 draws** 下评估：

| 评估点 | material 解 | safety 解（搬过来） | 差 |
|---|---|---|---|
| 200 draws（历史基线） | −22404.8890 | −22425.7917 | **20.90** |
| 800 draws（高精度） | −22371.9659 | −22388.8350 | **16.87** |

追加一次拟合（以搬过来的 safety 解为起点、material 基准下重新优化）：
**−22404.8948**，距 material 最优只差 **0.0058**，用时 93s。

这些观察值支持的结论**只有一条**，但它是本节要的那条：

> **safety 那次拟合落在一个更差的解上，不是不同的模型。** 依据是重优化——从等价
> 转换的参数出发，它回到 material 的最优（差 0.0058）。

**下面这些是它不支持的：**

- **"有限模拟误差约 4.0"不成立。** 20.90 与 16.87 之差只说明"差值随 draws 数变
  了 4.03"。换 draws 数同时移动了两条曲线（9.3：绝对水平移动约 33 个单位），两条
  各移多少、其中多少属于模拟误差、多少属于这两个解对 draws 数的不同敏感性，本设计
  没有把它们分开识别。要分离得另做设计（例如同一解在多个 draws 数上的重复评估，
  以及独立重抽 draws 的方差估计），本轮没做。
- **"坐标实现约 6.8"不成立。** 27.7 是**旧口径**（两个解各自在自己的坐标下）的数，
  20.90 是新口径的数，两者的差混着口径变化与实现差异，单靠相减分不开。
- 27.7 这个数本身保留为历史记录，**不再作为"某个误差成分等于 6.8"的依据**。

### 9.3 一个必须写明的副产品：似然的绝对水平依赖 draws 数

同一组参数下，对数似然从 200 draws 的 −22404.89 移到 800 draws 的 −22371.97，
差 **约 33 个单位**。这是模拟似然的偏差，随 draws 增加而减小。

后果：**同一批 draws 下的似然比较是公平的**（公共随机数，起点选择与规格对照都
满足这一条），**跨 draws 数的似然水平不可比**。因此 200 draws 不足以支撑似然的
**绝对值**。这一条写进 `DECISIONS/0013` 第四节作为配置要求。

> **订正九：9.1 证明不了 200 draws 的积分精度够用。** 上一版这里接着写"它对权重
> 空间的矩与个体后验够用——那两项在 9.1 里是机器精度级别的恒等"。**这个推理是错
> 的。** 9.1 比的是**同一批抽样点**在两套坐标下的结果，`a' = T·a` 是逐点的线性
> 变换，所以那些恒等式对**任意** draws 数都成立，包括 R=1。它验证的是坐标实现
> 无误，与"200 个点够不够积出那个期望"**完全无关**——把 200 换成 20，9.1 照样
> 全绿，而积分精度显然更差。
>
> **200 draws 对矩与个体后验是否够用，本仓库尚未验证。** 要验证得另做：同一份
> 数据在 R ∈ {200, 800, 3200} 上比较权重空间的矩与个体后验，或用独立重抽的
> draws 估计这些输出量的模拟标准误。**列入待后续实验。** 在那之前，200 draws 是
> 一个**沿用的配置选择**，不是一个已验证的精度结论。

**订正十：`bias_table` 的矩用的是 `np.cov` 默认 ddof=1。**

> **订正十一（2026-09-28，撤回上一句的完成声明）。** 上一版这里写的是"本轮统一
> 为 ddof=0"。**那句是假的**：我写了 `moments.py` 用 ddof=0，也写了这段订正，
> 但 `bias.py` 与 `runner.py` 两个调用点**一个都没改**。代码审核查出了这处，

>

> 没动。** 判断标准不能是"我实现了吗"，要是"入口用上了吗"。

N=1000 时差一个 `N/(N−1) ≈ 1.001`（**这个倍数只适用于这个样本量**；N=10 时是
11.1%）。量级微小，但它会让"注入矩"与"按同一名单另算的矩"对不上，而那种对不上
最难查，因为两个数看起来都对。

**ddof=0 的适用范围限定在有限名单的真值矩**。bootstrap 重抽的样本标准差保持
ddof=1，那是从重抽分布里抽样，不是描述一份有限名单；**不做全项目机械替换**。

**`t` 路径定为方案 A**（共享权重中心，只校准位置）。旧的共同插值降为带标签的
历史协议，正式入口拒绝。

**一个方法学发现，值得单独记：求解器自己那批点上的残差说明不了任何事。**

方案 A 的位置校准是凸问题，驻点的定义就是"在求解器那批点上模拟均值命中目标"。
所以 in-sample 残差**必然**是机器精度——实测 **6.5e-11**。若只看它，会宣布
"校准完美"。真正的误差是用 `n_draws` 个点解出的 `μ̂` 与无穷点解之差，它只在
**独立**积分点上显形，而且随**求解**点数下降，**不随检查点数下降**：

| 求解 draws | 独立点残差（检查用 200k） |
|---|---|
| 20,000 | 2.3e−3 |
| 80,000 | 1.8e−4 |

第一次跑的时候五个 t 点全部报 `mean_residual_above_tolerance`（2.2–2.6e-3），
我一度以为是校准失败；查下来是求解点数不够。默认因此定为 80,000。
这与第 9 节订正六（拿样本矩比总体参数却声明双精度容差）是同一类错误的两个
方向：**一次是容差比噪声紧，一次是检查本身测不到要测的东西。**

另加 `tolerance_below_noise_floor` 状态：当检查自身的蒙特卡洛标准误大到分辨
不了声明的容差时，这是**检查设计**的问题，与校准好坏无关，单独报。

**固定参数的积分精度已实测**（`runs/2026-09-26-p10-evidence/`）。它只支持
`R_post` / `R_moment`；**`R_fit = 200` 的充分性仍未验证**，那要在更高 R 上重估
参数再比（方案乙，6–10 单核小时，未运行）。
