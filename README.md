# 重生模拟器 / Homo Spatialis

仓库名：`homo-spatialis`

> 一个可计算的空间福利模型。给定一个人是谁，算出他在哪座城市过得最好；并用这套模型作为标尺，把大语言模型的偏好理解误差换算成美元，回答两个问题：它伤害了谁，以及它是否已经够好。

> **版本 v0.9。** 相对 v0.5 的完整改动说明见 `PLAN.md` 的补丁清单与 `MIGRATION_v0.5_to_v0.9.md`。本文档不携带评审标记。
>
> **v0.9 的改动全部集中在评估层与实验设计（第 10、11 章与 §1.2），M2 的数学一行未动。** 这一轮解决的是一个识别问题：`proj_i` 被发现只能部分识别，因此它从主证据降为方向证据，协方差比升为坍缩的主证据。理由完整写在 §1.2.3 与 §11.7.3，请不要只读结论就改代码。

## 前言

远渡重洋的航班抑或是通往异乡的轨道，故事在这些章节走向晦涩的间章抑或崭新的开始。前进到下一页的人会想：我当初是不是能有更好的选择？尚未翻开新页的人会说：向左或向右，如何在事件尚未发生之时找到正确的通道？

面对信息的有限性与变量的庞大数量和复杂联系，普通人在面对这些事件时常常深陷迷茫。如今，我们尝试用人工智能去解读万事万物，却又如何能容许在此等重要决定上徒留彷徨。因此，我尝试用一个多智能体框架来尝试解答这个问题。对于你或者我，哪里才是应许之地，乌有之邦？

### 关于名字

每个代理都是用户的一个分身。它这一世在这座城市生活，下一世在别处；三年之后各自结算，回头去看哪一世过得更好。如果重活一世，结果会不会不同？这就是"重生模拟器"。

`homo-spatialis` 是一次明确的致敬与定位。Horton、Filippas 与 Manning (2023/2026) 提出 *homo silicus*，主张大语言模型因其训练方式而成为人类的隐式计算模型，可以像经济学家使用 *homo economicus* 那样使用它；而 *homo economicus* 本身是这条谱系的起点。本项目研究的是这个"硅基人"在**空间**中的行为，故名 *homo spatialis*。这个名字既是双关，也是一次学术站位声明。

## 1. 这个项目做什么

**主线是产品模式。** 用户描述自己是谁，系统给出他在各候选城市的福利排序、分维剖面、以及这个结论有多可靠。本文档第 2 至第 9 章讲的都是这条主线。

**第 11 章讲研究模式。** 它把同一套代码反过来用：先注入一批已知的偏好，再看语言模型能否从行为中把它们读回来，并把读错的代价换算成美元。

### 1.1 两层的相辅相成结构

这不是两个拼在一起的项目，而是同一套装置的两个用途，且每一侧的产出都是另一侧需要的输入。

| **方向** | **给出什么** |
|---|---|
| **产品层 → 研究层** | **真值（福利模型）、货币化度量（等价变差）、真实的选择集与属性分布、以及一条现实存在的基准线（现有生活成本计算器，见 9.1.1 的 `L_rep`）。真实偏好分布是可选的第五项，按 5.1 目前只进对照臂** |
| **研究层 → 产品层** | **适用边界（在什么样的选择集上模型的建议可信）、区间校准（三年模拟的置信区间该多宽）、自由文本通道的调整幅度上限** |

两者共用同一份 M2。这个结构回答了"为什么不干脆只做其中一个"。

### 1.2 三个研究问题

**问题一（主问题）：大模型的偏科在福利上伤害了谁？**

已有文献回答的是"坍缩存不存在、有多严重"，没有回答"坍缩伤害了谁"。若模型把所有人往某个众数偏好向量上压，则对偏好本就接近众数的人几乎无害，对偏好离众数远的人造成系统性错误建议。

定义两个量：

```
d_i    = ‖w_i − ŵ_center‖                                   距离（协变量）
proj_i = ⟨ ŵ_i − w_i , (ŵ_center − w_i)/‖ŵ_center − w_i‖ ⟩   向中心的位移（主指标）
```

其中 `ŵ_center` 由混合 logit 估出（见 11.7），`ŵ_i` 为该人设的个体回收权重。

**主指标是 `proj_i`，不是"福利损失对 `d_i` 的回归"。** 理由是一个识别问题，必须写在最前面：

福利损失的可取值范围本身随 `d_i` 上升。由 6.3.1，`d_i` 大意味着权重离中心远，也就意味着权重熵低，而低熵权重产生大的城市间福利间隔。于是 `d_i` 大的人，任何一次错误的代价都更高。**一个错误方向完全随机、与 `w_i` 无关的模型，也会产出随 `d_i` 单调上升的福利损失。** 若只报这条上升曲线，赌注大小与坍缩方向被合并进了同一个自变量，什么都没有被证明。

`proj_i` 把赌注剥掉：它度量的是回收误差**指向中心的那个分量**。这是"往中心压"这件事的直接度量。

**但 `proj_i` 的零点不是 0。** 这一条是 v0.8 相对 v0.7 的核心修正，必须先说清楚，否则整个检验方向是反的。

#### 1.2.1 `proj_i` 需要三点标尺，因为它两端都被钉死

先看取值范围。完美回收（`ŵ_i = w_i`）给出 `proj_i = 0`；完全坍缩（`ŵ_i = ŵ_center`）给出 `proj_i = ‖ŵ_center − w_i‖ = d_i`。所以 `proj_i ∈ [0, d_i]`，0 是地板，`d_i` 是天花板。

**天花板来自打乱人设臂，不是地板。** 打乱之后代理 i 读到的是人设 j 的散文，因此它的选择反映 `w_j`，而 `w_j` 与 `w_i` 独立同分布、均值为 μ。混合 logit 的总体均值 `ŵ_center ≈ μ`，于是

```
E_j[proj_i] = ⟨ E[w_j] − w_i , u_i ⟩ = ⟨ μ − w_i , u_i ⟩ = ‖μ − w_i‖ = d_i
其中 u_i = (ŵ_center − w_i)/d_i
```

打乱臂给出的是 `d_i`。概念上一句话就够：抹掉个体信息之后模型只能退回总体均值，而"退回总体均值"正是坍缩的定义，所以打乱臂在构造上等价于**完全坍缩**，不可能是零假设。

**地板来自估计器自检（10.3），不是 0。** 混合 logit 的个体后验均值 `ŵ_i` 是收缩估计量，按精度加权把个体估计拉向总体均值。每人只有五到八次选择，个体似然很弱，收缩幅度会很大。因此**即使大模型完美回收偏好，`ŵ_i − w_i` 也会有一个系统性指向中心的分量**。写成

```
ŵ_i = w_i + λ·(ŵ_center − w_i) + 噪声      λ 为收缩因子
```

则地板的期望是 `λ·d_i`，天花板的期望是 `1·d_i`。**`E[proj_i] > 0` 是估计量保证的，不是大模型保证的。** 这是 11.7.2 已经识别的那个问题在另一个统计量上的重演：v0.7 抓住了协方差那一半，漏了个体后验均值这一半。

| 量 | 来源 | 含义 | `proj` 对 `d` 的理论斜率 |
|---|---|---|---|
| **地板** | 10.3 自检：直接用真值 `w_i` 经 softmax 生成选择，过同一套估计器 | 纯收缩，无坍缩 | `λ` |
| **天花板** | 打乱人设臂（11.10.1） | 完全坍缩 | `1` |
| **实测** | 匹配臂 | 落在两者之间 | `slope_matched` |

#### 1.2.2 坍缩比例：形式、以及为什么它只能给区间

三条线的期望都正比于 `d_i`，因此**不要在个体层面做差**：`(proj_matched − proj_floor)/(proj_shuffled − proj_floor)` 在 `d_i → 0` 处是 0/0，中心附近的人给出两个小数之比，噪声极大。正确的做法是在每个臂里把 `proj` 对 `d` 回归取斜率：

```
坍缩比例 r = (ŝ_matched − λ̂) / (ŝ_shuffled − λ̂)
```

> ⚠ 本段的公式已被 DECISIONS/0002 推翻并替换，见该记录。原式分母用理论值
> `1`，而 `ŵ_center` 的估计误差把两个实测斜率都按同一个因子 `b` 压低了，
> 理论值没被压——量纲不一致，`r` 有偏且低估坍缩（数值验证：中等误差下低估
> 四成）。改用打乱臂的**实测**斜率作分母，`b` 上下约掉。
>
> **配套的硬约束**：`d_i` 与 `u_i` **只算一次**，用匹配臂的 `ŵ_center`，三个臂
> 原样共用。这不是便利条件而是前提——偏误因子
> `b = 1 − Cov(⟨δ,u⟩, d)/Var(d)` 只依赖 δ、`u`、`d`，三者不随臂变化时它才是
> 三臂共用的乘性因子，才消得掉。各臂各估各的中心就消不掉。

无量纲，可跨难度档比较，且天然除掉了 `d_i`。两条基本限定：

- **不要把它夹到 [0,1]。** 它可以大于 1：若 RLHF 的众数解读与样本均值不重合，模型可能比"一无所知"压得更狠。那是一个结果，不是越界。
- **免费的健全性检查**：打乱臂估出的斜率理论上应当等于 1。若明显不等于 1，说明装置有问题，因为那是纯代数结果。

> ⚠ 本条已被 DECISIONS/0002 推翻，见该记录。有 `ŵ_center` 的估计误差时
> `ŝ_shuffled` **本来就不该等于 1**，它等于衰减因子 `b`。它从判据降为诊断：
> `ŝ_shuffled` 现在是"`d` 被测得有多糟"的度量，并作为门二的第三条判据
> （`ŝ_shuffled ≥ 0.5`）。

**下面这一段是 v0.9 的核心，它解释了为什么 `r` 是区间而不是点估计。不读这一段就照公式实现，做出来的东西是错的。**

##### 为什么 λ 不可能被精确定出来

个体后验均值的收缩权重大致是

```
k_i ≈ V_i / (V_i + Σ_pop)
```

`V_i` 是个体似然的方差（由选择噪声 σ 与每人的选择次数决定），`Σ_pop` 是总体先验的松紧。**两个量都驱动收缩**，所以 λ 不是 σ 的一元函数。

要命的是第二个：**坍缩本身就是把 `Σ_pop` 压小。** 于是

```
坍缩 → Σ_pop 变小 → 先验变紧 → 收缩变强 → proj 变大
```

这条通道是机械的，与"模型有没有把人往中心推"无关。要扣掉它，地板臂就必须在**匹配臂实际呈现的 `Σ_pop`** 上计算；而那个 `Σ_pop` 正是被测量的对象。循环。

**因此 `proj` 被推高有两条通道，而地板只能扣掉第二条在某个假定的 `Σ_pop` 下的部分：**

```
通道一：模型确实把 ŵ_i 往中心推            ← 要测的
通道二：Σ 变小 → 先验变紧 → 收缩变强 → proj 变大   ← 机械后果
```

##### 区间的构造与两端的方向

地板臂的 `Σ_pop` 取两个极端，中间连续插值：

```
Σ(t) = (1 − t)·Σ_injected + t·Σ̂_matched      t ∈ [0, 1]
```

| t | 地板臂拟合于 | `Σ_pop` | 收缩 | λ | 得到的 `r` |
|---|---|---|---|---|---|
| 0 | 注入的 Σ（较大） | 松 | 弱 | 小 | **上界** |
| 1 | `Σ̂_matched`（较小） | 紧 | 强 | 大 | **下界** |

方向的验证：`dr/dλ = (s − 1)/(1 − λ)²`，而匹配臂不会超过天花板故 `s ≤ 1`，所以导数非正，**高估 λ 就低估坍缩**。

**两端都是偏的，没有中立点。** `t=0` 那端地板臂的先验比匹配臂松，低估了匹配臂的收缩，因而高估坍缩；`t=1` 那端把一部分坍缩预先送给了地板。

##### 报告规则：报整条曲线，不挑端点

**必须报 `r(t)` 的完整曲线**（同一批合成数据跑 `t` 的网格，成本近零），以及翻号点 `t*`（若存在）。只报两个端点，读者无法分辨结论是"整个区间都为正"还是"过了六成就变负"。

**判据在跑之前写死，且对两个方向对称：**

```
声明「坍缩显著存在」  ⟺ 整条 r(t) 曲线（含置信带）下沿 > 0
声明「坍缩可忽略」    ⟺ 整条 r(t) 曲线（含置信带）上沿 < 事先定的可忽略阈值
否则                  ⟺ 「在本装置上不可判定」，这是一个诚实且可发表的结果
```

> **不要用"结论是 A 则取 t=1，结论是 B 则取 t=0"这类条件规则。** 它写下来的时刻是事前，执行的时刻是事后（要先看结果才知道落在哪个分支），净效果是无论数据如何都报离零更近的那一端。那不是保守，那是一个系统性朝零假设偏、且偏移幅度依赖数据的估计量，其抽样性质无法计算，置信区间也就无从谈起。上面这条对称判据不制造偏向，因为两个方向的声明都要求**整条**曲线支持它。

**`1 − λ` 是测量窗口。** 若 λ 接近 1，窗口关闭，`r` 不可测。10.3 必须在花任何大模型预算之前把 λ 报出来（门二）。

#### 1.2.3 指标分工：协方差比测"有没有压"，`proj` 测"往哪压"

上一节的循环只影响 `proj`。**协方差比没有这个问题，因此它才是坍缩的主证据。**

理由是它的两端都是已知**输入**：

- 自检时注入已知的 `Σ_true`，估出 `Σ̂`，得到基线压缩比。
- 匹配臂里 `Σ_true` 就是人设分布的协方差。而人设权重按 Dirichlet(α=0.5) 抽样（§11.9 已裁决），**Dirichlet 的协方差有闭式解**，所以它是一个可以写下来的数，不是估计量。

> ⚠ 抽样分布已被 DECISIONS/0006 修改，见该记录：**物质维 α₁ = 1.5，六个
> 舒适度维保持 0.5**。物质维在结构上不同（只有它的指数出现在货币度量的
> 分母上），对称先验下 w₁ 中位数仅 0.076、约两成人设算不出美元福利数。
> 稀疏性未受影响，由 Dirichlet 的中性性质保证（实测舒适度子向量熵不变）。
> **连带**：注入协方差对角线不再是常数；注入均值是 `[1/3, 1/9×6]` 而非 `1/7`。

对 `α_k = α`、`K = 7`、`α₀ = Kα = 3.5`：

```
E[w_k]      = 1/7 ≈ 0.142857
Var(w_k)    = α(α₀ − α) / (α₀²(α₀+1)) = 0.5×3.0 / (12.25×4.5) = 0.0272109
Cov(w_j,w_k)= −α² / (α₀²(α₀+1))       = −0.25 / 55.125      = −0.0045351
SD(w_k)     ≈ 0.16496

核对秩：1'Σ1 = 7×0.0272109 + 42×(−0.0045351) = 0.190476 − 0.190476 = 0  ✓
```

最后一行同时验证了 §11.7.1 的秩 6 结论，**并且可以直接写成一个单元测试**。

而 `proj` 需要知道估计器实际看到的 `Σ_pop`，那是输出不是输入。所以：

| 指标 | 回答什么 | 识别状况 | 地位 |
|---|---|---|---|
| **协方差比** | 有没有压缩、压缩了多少 | 干净，两端都是已知输入 | **主证据** |
| **坍缩比例 `r(t)`**（由 `proj` 得） | 压缩是朝向一个中心，还是各向同性 | 部分识别，只能给区间 | **方向证据** |

**这个分工不是妥协，它让两个指标各自更好解释。** 协方差比小于 1 只说明方差被压了，它区分不了"压向众数"与"整体收窄"；`proj` 恰好补上方向那一半。合起来是一个完整描述。

**同时它取消了一种错误的写法。** 由上一节的通道二，`proj` 被 Σ 的压缩机械地放大，因此 `proj` 与协方差比**不是两次独立测量**。结果部分若把两者当作互相印证的证据，那是重复计数，第二条只是第一条的下游后果。**这一点必须自己在结果里写明**，否则审稿人会指出来，而那时候比自己说难看得多。

`proj` 仍然完整完成它被引入时的那个任务：剥掉"福利损失对 `d_i`"里的赌注混淆（`d_i` 大的人熵低、福利间隔大，任何错误过程都会画出上升曲线）。它只是不该独自承担主结论。

#### 1.2.4 两个口径不得合并：坍缩比例扣地板，美元损失不扣

```
坍缩比例      问「模型是否比一个理想估计器更把人往中心推」   → 扣地板
美元福利损失  问「听这个系统的话，用户少拿多少钱」          → 不扣任何东西
```

**美元损失不扣地板的理由不只是"用户不管原因"，还有一条更硬的：地板是估计器的性质，而估计器不在产品里。** 真实用户拿到的是模型推荐的城市，中间没有混合 logit。收缩是我们为了从行为反推权重才引入的分析装置，它不该出现在福利账上。

这一条要抵挡一个听起来很有道理的反驳，值得把它写出来：

> 反驳：设想一个"完全无偏但极度嘈杂"的模型，它平均而言读对每个人，只是选择接近随机。这种模型没有把任何人往任何地方推，它造成的大 `proj` 不该算坍缩。

前半句成立，后半句在美元账上不成立。注意"平均而言读对每个人"是关于 `E[ŵ_i]` 的陈述，而当选择接近随机时个体似然趋于平坦，`ŵ_i → ŵ_center`，于是这个模型在**每一个个体身上**都输出总体均值。它对偏好离中心远的人造成的美元损失是实打实的。

所以：**统计口径上，噪声导致的向中心位移应当被地板扣掉（它不是系统性偏科）；福利口径上，它一分钱都不扣（用户照样亏钱）。** 两个口径有意不同，结果部分不得合并成一句话。

#### 1.2.5 问题一的报告要求

1. **协方差比**（主证据），扣除 10.3 的基线压缩比后报告。
2. **坍缩比例 `r(t)` 的完整曲线**（方向证据）加翻号点 `t*`，按 1.2.2 的对称判据下结论。三条斜率各报置信区间。
3. **归一化福利损失** `福利损失 / welfare_range` 对 `d_i` 的曲线。除以全距剥掉赌注维度。
4. **原始美元福利损失** 对 `d_i` 的曲线，**不扣任何地板**（1.2.4），与打乱臂的同一条曲线并排。**注意方向**：打乱臂在这条曲线上同样是天花板（它的误差期望是 `μ − w_i`，最大程度指向中心），因此匹配臂应当**低于**打乱臂，结论是匹配臂离天花板还有多远。
5. **明写一句**：`proj` 与协方差比机械耦合，不作独立印证（1.2.3）。

结论形式为：大模型的区位建议对偏好接近中心的用户几乎无损，对偏离中心的用户造成每年 X 美元等价变差的损失；协方差被压缩到注入值的 Q%，且这个压缩是朝向一个中心的（坍缩比例在整个地板设定区间上落在 [a, b]）。

**`ŵ_center` 的两条限定必须写进结果**：

- 它是估计量，其估计误差进入 `d_i`，而 `d_i` 是自变量，因此存在衰减偏误。须报 `ŵ_center` 的置信区间，并对 `d_i` 的构造做敏感性。
- 若模型完全不坍缩，`ŵ_center` 收敛到注入分布的均值，此时 `d_i` 退化成"这个人有多不寻常"，与坍缩无关。

**问题二：它是否已经够好？**

"足够好"必须相对于一个替代方案才有意义。本项目的替代方案不是"完美的模拟器"，而是用户现在实际在用的东西：现有的生活成本计算器。

必须准确刻画那个东西是什么。它做了**两个**独立的近似：用代表性篮子（平均支出份额 `s̄`），并且**根本没有偏好权重维度**，只按实际收入排序，不含任何舒适度项。因此现状工具对应的是 `s = s̄` 且 `w = (1,0,0,0,0,0,0)`。"用代表性篮子"与"假装所有人偏好相同"是两件不同的事，前者是 `s` 的近似，后者是 `w` 的近似，不能混为一谈。

| 方案 | 参数 | 福利损失（美元/年） | 备注 |
|---|---|---|---|
| **现状工具** | `s = s̄`, `w = (1,0,…,0)` | `L_rep` | 零大模型调用，可先算 |
| 只错篮子 | `s = s̄`, `w = w_i` | `L_s` | 分解项 |
| 只丢舒适度 | `s = s_i`, `w = (1,0,…,0)` | `L_amen` | 分解项 |
| **大模型读自述抽权重** | `s = s_i`, `w = ŵ_i` | `L_llm` | |
| 用户自己填量表 | 真值 | 0 | 上界 |

判据是 `L_llm < L_rep` 是否成立。这条基准线的关键性质是它已经坍缩到底了：它对所有人给出同一个答案，是"完全坍缩"这一极端在现实中实际存在的化身。因此问题可以写成：一个部分坍缩的大模型，是否仍然优于一个完全坍缩的现状工具？

`L_s` 与 `L_amen` 的分解是几乎零成本的加法（三次 argmax，无大模型调用），而它本身是一个结果：个人化的价值里有多少来自篮子结构，有多少来自舒适度权重。它直接回答产品该主打哪一半。

**问题三：坍缩大，还是城市差异大？**

这是一个信噪比问题，两个量必须都换算成福利损失才能比较：

```
SNR = Var_across_cities(福利) / Var_from_collapse(福利损失)
```

比值大意味着城市差异淹没了坍缩：即使模型读偏了偏好，用户仍会被推荐到一个不错的城市。比值小意味着坍缩淹没了信号。

关键在于这个比值不是一个数，它随选择集变化。在高度分散的城市集上比值大，在相似的城市集上比值小。于是得到一条可操作的适用边界：

> 在福利离散度高于阈值 τ 的选择集上，大模型的建议优于现状工具；低于 τ 时不是。

这是一个产品规格而非学术观察：系统可以在运行时算出当前选择集的福利离散度，低于阈值时如实告知用户"这几座城市对你而言差别不大，此处的建议不比抛硬币强多少"。

### 1.3 已被占据的位置（诚实声明）

以下三条不是本项目的贡献，必须引用而非声称：

- "从已知偏好参数出发检验大模型的偏好推断"这一框架：Kim、Kovach、Lee、Shin 与 Tzavellas 的 Simulate-Recommend-Evaluate，以及他们用非线性最小二乘做参数恢复的做法。
- "用模拟代理研究经济行为"这一范式的合法性：Horton 等人的 homo silicus。
- "人设条件化下的方差坍缩"及其跨文化维度：Distribution-First / Non-WEIRD 那一支。
- "从选择数据恢复个体异质性"的标准工具：联合分析领域三十年的分层贝叶斯与混合 logit（Lenk、DeSarbo、Green 与 Young 1996 起）。

详见 `RELATED_WORK.md`。本项目的贡献严格限于 1.2 的三个问题，它们的共同前提是一个带货币化福利度量的产品层。

## 2. 为什么这个问题不平凡

### 2.1 空间均衡的悖论

空间均衡理论（Rosen 1979；Roback 1982）给出一个反直觉的结论：在劳动力自由流动的条件下，城市之间的实际工资差异必须被舒适度差异抵消。旧金山名义工资高、房租也高，并非异常，而是均衡条件本身。若空间均衡严格成立，"哪里实际收入最高"对边际劳动者的答案就是"哪里都一样"。

均衡对**特定个体**不成立的原因，正是本项目的建模对象：

- 均衡是对边际迁移者成立的，不是对任意个体。不重视海滩的人在为海滩付费而不消费它。
- 消费篮子异质。你买比亚迪还是特斯拉，一个在中国便宜，一个在美国便宜。个体面对的实际价格水平取决于其支出结构，而非代表性篮子。
- 迁移存在成本与摩擦，因此个体并不处在均衡点上。
- 技能回报在城市间不同，导致按技能的分选。
- 名义税制是累进的，因此高名义工资城市的居民在实际意义上承担了更高的税负。

### 2.2 已有的效应彼此冲突

比"平均值不适用于你"更强的一个论点是：**已有文献给出的几个主要效应指向并不一致，而没有人算过对一个给定个体谁主导。**

- Moretti (2013)：用城市特定价格重算，本地生活成本吃掉了 1980 至 2000 年大学溢价增长的至少 22%。
- Handbury (2021)：城市间实际生活成本的主要差异来自不同市场提供的商品组合差异，而非它们收取的相对价格差异。纯价格指数抓不住这一维。
- Albouy (2009)：名义工资高于平均的城市，其他条件相同的劳动者要多交约 30% 的联邦税。
- Diamond (2016)：高技能劳动者从城市获得的收益更大，导致分选放大不平等。

这是四个不同方向的偏导数。哪一个主导，取决于个体的偏好参数与技能位置。**本项目的功能，正是把这些互相抵消的效应对一个具体的人聚合起来。**

一句话概括：空间均衡在平均意义上成立，可利用的差异全部存在于个体与平均之间的偏离，而这个偏离由几个方向不一致的效应共同决定。

### 2.3 主要挑战

不同国家、不同城市的统计数据在**构造**上不可比，而不只是在格式上不一致。这使得传统空间福利模型难以做跨国的任意城市比较。本项目的处理方式见第 5 章。

## 3. 架构

### 3.1 三层职责

**数据层（离线）。** 把各来源的原始统计数据落成统一结构的城市属性表。含一个数据转化模型，但它只做模式映射，不生成数值。详见第 5 章。

**福利模型，即经济核（真值生成器）。** 一个显式的、确定性的空间福利模型。给定城市属性向量与个体偏好参数，计算该个体在每座城市的效用、补偿性差异与三年轨迹。这一层完全由代码实现，不含任何语言模型调用，因此它的输出是可复现的、可求导的、可作为标尺使用的。详见第 7 章。

**代理层。** 一个由大语言模型驱动的层。它接收对个体的自然语言描述与城市的变量值列，并依赖福利模型返回的结果决定下一步行为。它不接触福利模型的计算过程。

这一分工并非本项目独创。AgentSociety（Piao 等，arXiv 2502.08691，李勇组）第 4.1 节的环境设计原则即为此：若仅依赖语言模型的知识而不建模真实世界的运行规律与约束，模拟结果容易被幻觉污染；因此应当把语言模型无法保证精度的数值计算卸载给环境，让代理只负责主观的行为逻辑。本项目的经济层对应其 economic space，区别在于本项目的环境含有空间维度，而其经济空间中工资不随城市变化。

### 3.1.1 这个分层有文献授权，不只是工程决定

Horton 等人证明的是大模型能在**定性方向上**复现经典行为经济学实验的模式（Charness 与 Rabin 的社会偏好、Kahneman 等人的公平性、Samuelson 与 Zeckhauser 的现状偏误）。这授权把它用作行为模拟器回答方向性问题，但**不授权**用于个体层面的定量预测。

离散选择实验方向的实证给出了同一件事的另一半：在食品选择的 DCE 中，GPT 能正确识别价格、有机认证等关键属性影响的方向，但其选择系统性地过度自信，缺乏真实人类决策中的自然变异性。

方向对、分布错。这正是本项目分层的依据：定量的活全部由经济模型承担，大模型只负责从自述里读方向。本项目的分工严格落在已有文献授权的范围内。

### 3.2 信息边界

真值生成器与"卸载给环境的数值计算"不是两个模型，而是**一个模型的两个接口**。写两份实现会导致税函数漂移，且无法定位错误来源。

边界按对偏好参数的依赖性划分：

| 层 | 内容 | 归属 |
|---|---|---|
| L0 | 城市原始属性（气候、密度、通勤、治安、教育、医疗） | 环境 |
| L1 | 经济原语（职业名义工资、房租、税率、空间价格指数） | 环境 |
| L2 | 会计派生量（税后收入、扣除住房后的可支配、储蓄轨迹） | 环境 |
| L3 | 偏好加权合成量 `A(a; θ)` | **答案** |
| L4 | 效用、补偿性差异、argmax | **答案** |

规则：**凡不依赖个体偏好参数的计算，归环境；凡依赖的，是答案。**

L2 必须归环境，因为累进税与储蓄复利是纯算术。让代理自己算，测到的是它的算术能力而非偏好理解能力，且算术误差会污染下游估计。L3 必须归答案，因为它需要 `θ`；环境一旦替它算了 `A(a; θ)`，题目就没了。

代码上是一份实现、两个出口：

```python
class EconomicCore:
    def observe(self, agent, city) -> Observable:   # L0-L2，代理可见
    def score(self, agent, city) -> GroundTruth:    # L3-L4，代理永不可见
```

两者调用同一批底层函数。`Observable` 与 `GroundTruth` 是两个不同的类型，代理层适配器的签名**只接受 `Observable`**，由类型系统而非记忆来守边界。

### 3.2.1 GroundTruth 的字段要求

`score()` 不能只返回最优城市。1.2 的三个问题全部依赖每座城市的福利值，因此 `GroundTruth` 必须携带：

| **字段** | **内容** | **服务于** |
|---|---|---|
| `features: dict[str, float]` | **`ln V` 的各列，`M5` 直接消费，不自行重算** | **单一真值来源；11.3 与 M5 的特征表示一致** |
| `ev_by_city: dict[CityId, float]` | **每座城市的等价变差（美元）** | **福利损失指标、L_rep 基准线** |
| `welfare_gap: float` | **最优与次优的福利差** | **M3 的难度轴、SNR 的分子** |
| `welfare_dispersion: float` | **全部城市福利值的标准差** | **适用边界阈值 τ、问题三的信噪比分组** |
| `welfare_range: float` | **全部城市福利值的最大减最小** | **1.2 问题一的归一化分母；必须与 `welfare_dispersion` 分开存，两者用途不同** |

`features` 中的物质项必须拆成 `ln_y_net` 与 `ln_p` 两列，而非合并为一列。模型说这两个系数应等值反号；拆开后这个约束变成可检验假设，而 `|coef_Y + coef_P|` 就是货币幻觉的连续度量，直接把 11.3 的第四档从通过/不通过的分类判断升级为带置信区间的连续量。

M5 不得自行重算特征。理由不是浮点漂移（双精度下相对误差约 1e-15，远小于抽样噪声），而是：（一）单一真值来源，两份特征构造实现会语义漂移；（二）11.3 的精确并列求解器与 M5 必须用同一特征表示，否则"精确"在 M5 眼里不精确，11.6 的 σ 无关性失效。

## 5. 数据层

### 5.1 来源

**工资**：美国劳工统计局的 Occupational Employment and Wage Statistics（OEWS），职业与都会区交叉，含 10/25/50/75/90 五个分位。分位用于把个体能力分位映射到工资分位，避免"直接取中位数"隐含的选择性偏误。

**价格水平**：美国经济分析局的 Regional Price Parities（RPP），按都会区发布，区分商品、租金、其他服务三类。

> **必须避免的错误**：城市消费价格指数（CPI）不能跨城市比较。它是各城市内部归一化的时间序列，衡量的是变化率而非水平。跨城市比较需要空间价格指数，在美国即 RPP。

**税制**：联邦累进税率表与各州个人所得税规则。

**消费篮子**：消费者支出调查（CEX）按人口学单元的支出份额。

**舒适度**：日照时长与气候（气象数据）、通勤与公共交通（ACS 通勤时间、交通局数据）、教育与医疗可及性、治安。

**补充源**：ACS 提供都会区层级的中位租金与住房成本负担分布，粒度比 RPP 的租金指数细；BLS 的地区平均价格提供若干具体商品与服务的实际价格水平（不是指数），可作为标志商品的种子。

**迁移流（V2 验证用）**：国税局 SOI 县际迁移数据、ACS。

**真实偏好分布（1.2 问题一"谁"这一半的输入，非阻塞）**：OECD Better Life Index 的用户提交权重数据。截至 2017 年 12 月，约十三万名 OECD 地区用户向 OECD 分享了自己的权重选择，其中约四千人完成了扩展问卷，提供了更广的个人特征与各维度的自评满足度；OECD 在 SDD/DOC(2018)3 中用的正是这份数据。备选：欧洲社会调查的 Schwartz 量表跨三十国分布、WHOQOL 各国常模。

> 这份数据有三个必须先认清的问题，它们共同决定了它是对照臂而不是主臂。

**其一，可得性未证实。** 公开渠道（Kaggle、KAPSARC 等）流传的 OECD BLI 数据集是**国家指标**数据，不是用户权重微观数据。OECD 论文把后者称作独有数据集，目前没有证据表明它可下载。**行动项：直接联系 OECD WISE 申请，这件事本周做，不排在写代码之后。**

**其二，它的抽取口径与 6.3 直接矛盾。** BLI 让用户对每个维度从 0（不重要）到 10（很重要）打分，这正是评分量表。而 6.3 花了一整节论证本项目不用评分量表，理由是尺度使用偏差在跨文化上系统不同（东亚偏中点、北美偏极端）。BLI 的用户池恰好跨 OECD 各国。也就是说，用它作偏好分布，等于把在测量端剔除掉的偏差从分布端请回来，而且在这份样本里它是系统性的而非随机的。

**其三，默认值造成众数堆积。** BLI 的全部维度默认权重为 5，即中点。大量提交者只动了一两个滑块。因此经验分布会在均匀向量附近有一个巨大尖峰，而均匀向量正是最大熵点，正是 6.3.1 论证的"个人化没有收益、福利损失观测不到"的区域。

> 结论：主实验的权重抽样保持 Dirichlet(α=0.5)（见 11.9），真实分布作对照臂。若拿不到，1.2 问题一仍然完整成立——`proj_i` 与归一化福利损失都不依赖它——只是失去人口学解释，说不出"受损的是哪一类人"。

### 5.2 可贸易品与不可贸易品：个人化价格指数

经济学把商品分为两类。**可贸易品**能跨地区运输，套利把价格拉平，一台冰箱在克利夫兰与旧金山差别不大。**不可贸易品**不能运输，因为消费与生产必须发生在同一地点：房租、理发、堂食、托育、看牙。它们的价格由本地工资与土地成本决定，因此城市之间差异巨大。

关键结论：**城市间生活成本的差异，几乎全部来自不可贸易品。**

RPP 已经替本项目做好了这一拆分，只是用了别的名字：

| RPP 分项 | 经济学性质 | 都会区间变异 |
|---|---|---|
| Rents（租金） | 纯不可贸易 | 极大 |
| Other services（其他服务） | 主要不可贸易 | 大 |
| Goods（商品） | 主要可贸易 | 小 |

因此本项目**不使用 `rpp_all`**。用合成指数等于假设所有人的篮子结构相同，而个人化正是本项目的卖点。个人化价格指数取三项按个人支出份额的加权几何平均：

```
P_{i,c} = (rpp_rents,c)^{s_rent,i} · (rpp_goods,c)^{s_goods,i} · (rpp_other,c)^{s_other,i}
```

份额 `s` 来自 CEX 按人口学单元的支出结构，再由用户的行为代理题微调。**这三个指数加上个人份额，就是整个个人化购买力平价的全部实现**，约十行代码。

其机制可以这样直观理解：住房支出占 40% 的人与占 20% 的人，面对同一组城市，得到的价格水平排序可以完全不同，因为租金分项的城市间离散度远大于商品分项。这就是本项目的核心机制。

**可贸易品的跨市场价差在国内可以忽略，在跨国不可忽略。** 同一款工业品在中美的相对价格可以是反号的（关税、本地生产、进口结构所致），这正是 Handbury (2021) 指出的"商品组合差异"那一维。V1 不处理这一层；V2 通过标志商品机制处理，见 6.4。

### 5.2.1 实现约束：全程在对数空间

`_price_index` 返回 `ln_p` 而非 `p`：

```
ln P = Σ_k s_k · ln(rpp_k)
assert abs(sum(s) − 1) < tol
```

理由不只是数值稳定（对数求和比连乘条件更好），而是：真正需要的是 `ln V`，`P` 本身只在展示时需要；代码里的 log 线性结构因此变成显式的，而不是被 `exp` 藏起来。

那条断言是必需的，不是装饰：份额不和为一，`P` 就不是价格的一次齐次函数，它就不是价格指数，后面全错。

口径归一化：RPP 以全美等于 100 发布，原值在 80 到 130 之间，`ln P` 会落在 4.4 到 4.9 附近。请在 ledger 层除以 100 归一到全美等于 1，让 `ln P` 落在 0 附近。这不影响排序，但改善 logit 的数值条件，系数也更好解释。

### 5.2.2 支出份额必须是 Persona 的字段，不是 (Persona, City) 的函数

这是一个会静默毁掉三样东西的陷阱，必须显式防住。

危险的写法：先算该代理在某城市的税后收入 `Y_net`，再据此收入档去 CEX 查支出份额 `s`。由于他在不同城市的实际收入不同，查到的 `s` 会跨城市波动。后果：

- **`P` 不再是价格指数。** 指数数论的基本要求是权重固定；用变动的篮子比较两地价格，得到的不是价格指数，而是价格与篮子变化的混合物（Laspeyres 与 Paasche 之别的根源）。
- **`κ` 跨城波动，等价变差失效。** 而这在排序测试里发现不了，因为排序错了也看起来像"另一个城市更好"。
- **log 线性破缺，11.7 的条件 logit 变成误设定。** `ln V = ln κ(c) + w₁(c)·(…)`，系数随备选项变化，识别前提消失。届时测出的"回收误差"里混着设定误差，且分不开。

更根本的一层：Cobb-Douglas 位似且替代弹性恒为 1，支出份额本就不随价格与收入变化——这是函数形式的数学性质，不是额外假设。让 `s` 随城市变，与所选的函数形式自相矛盾。

因此：`s` 是 `Persona` 的字段，在人设构造时算一次并冻结，之后只读。查表用的收入是城市无关的参照收入：产品模式用用户当前的真实收入，研究模式用人设生成时指定的收入。

架构落点：装配层不得持有 CEX provider 的引用。`_price_index` 只读 `persona.shares`，不查表。这条比一个断言更管用，因为它让错误无法被写出来。

这同时是 7.2 那句"非位似性由份额的跨人变异承载"的准确含义：`s` 在人与人之间变，不在同一个人的城市之间变。

### 5.3 舒适度的基数化与参照总体

> ⚠ 本节的实现已被 DECISIONS/0007 修订，见该记录。此前六维**全部**走分位，
> 一个绝对锚定都没实现，导致 `ln A` 的跨城 sd 被拉伸到 0.855（而 `ln wage`
> 是 0.186、`ln rpp_rent` 是 0.229），舒适度通道压倒物质通道 10.8 倍。现在
> environment 与 commute 走绝对锚定（世卫 PM2.5 指导值、清醒时间占比），
> 其余四维仍走分位但**离散度是显式参数**而非映射副产品。绝对锚定的第二个
> 收益比跨国可比更要紧：它把"多在乎"整个赶进 θ，避免与问卷双重计入。

舒适度变量的单位五花八门（犯罪率、小时数、微克每立方米、分钟数），必须先映射到一个共同标度才能进入效用函数。这组标度函数是自由参数，且直接决定真值 argmax，因此必须显式冻结。

每个变量在台账里带一个 `scaling_method`：

**`absolute`（优先）**：变量存在外生的物理或制度锚点时使用。日照时长有天文上限，PM2.5 有世卫指导值，通勤时长有零下界。用绝对锚定标度的变量**跨国天然可比，不需要参照总体**。能用绝对的就用绝对。

**`quantile`（兜底）**：无锚点的变量，在**参照总体**上算一次经验分位函数，冻结成查表，把原始值映射到 [0,1]。

选分位而非线性或对数的理由：线性会被离群值主导（一座犯罪率极高的城市会把其余所有城市压到一起）；对数要选底，且对有界变量不合适；分位无量纲，能用同一套处理单位完全不同的变量。

代价是丢掉了差距大小的基数信息。因此**主结果报分位映射，附一个 winsorize 后的 min-max 线性映射作稳健性对照**。

#### 参照总体接口

```python
class AmenityScaler:
    reference_id: str  # "US_MSA_2024" / "CN_CITY_2024" / "NA_CN_POOLED_2024"
    scaling_methods: dict  # 变量名 -> "absolute" | "quantile"
    quantile_tables: dict  # 变量名 -> 冻结的经验分位函数
```

V1 中 `reference_id` 恒为 `US_MSA_2024`，但它全程存在、进配置、进日志、进结果元数据。加国家时新增一张表，不改任何调用点。

**参照总体的选择改变数值的含义**，必须理解清楚：

- 用 `US_MSA`：上海的犯罪率会映射到接近 1（比几乎所有美国都会区都安全），而中国城市之间的差异被压成一团。
- 用 `CN_CITY`：上海回到中国内部的位次，但这个值与美国城市的值不可比，量的是不同的尺子。
- 用合并总体 `NA_CN_POOLED`：两国城市在同一把尺子上，代价是每加一个国家，所有旧的映射值都会变。**这会破坏可复现性**，必须用带日期与成员列表的版本号冻结。

> 规则：参照总体必须覆盖本次比较的全部城市。

这与 5.5 的"列等级取集合内最低"是同构的，都是"可比性由比较集合决定"这一原则的实例。

工程上按需构建并缓存：给定城市集合，解析出所需的参照总体 id，若已冻结则查表，否则报错要求先离线构建。**绝不在查询时现算分位**，否则同一座城市在不同比较中会有不同的分位值，真值就不再稳定。

### 5.4 数据转化模型的两条规则

原始数据结构各不相同，需要一个转化环节。它由语言模型辅助，但受两条硬规则约束。

> 规则一：模型可以决定一个数字放在哪里，永远不能决定这个数字是什么。

模式映射交给它（读表头、把分类对到编码、统一单位口径）；数值生成不交给它。最终表中每个值必须可溯源，字段携带 `source_url`、`source_table`、`source_cell`、`retrieved_date`。映射**只跑一次、人工复核、冻结进仓库**，不在查询时调用。

> 规则二：每个字段必须携带它的构造定义与覆盖范围，而不只是数值与单位。构造相同的才能进同一列；构造不同的进不同的列，并显式标注。

规则一管格式，规则二管构造。月薪转年薪是格式，乘十二即可；而"职业×工资"与"行业×工资"不是格式差异，是不同的测量：行业均值在行业内对所有职业取平均，职业均值在行业间聚合，两者的均值、方差与偏差方向都不同，且偏差方向随产业结构而异。

### 5.5 兼容性：离线台账加在线集合解析

可比性不是某个字段的固有属性，而是相对于一个具体的比较集合而言的。

**离线（一次性）**：每城市 × 每字段，记录构造定义、覆盖人群、聚合层级、可得的分布细节。这是一张事实表，不含等级。

**在线（每次比较）**：给定用户选定的城市集合 S，为每个字段解析等级：

| 等级 | 含义 | 用途 |
|---|---|---|
| A | 集合内所有城市同构造、同覆盖、同分布细节 | 直接进入比较 |
| B | 可映射，但偏差已知且已记录 | 进入比较，输出中逐维标注 |
| C | 存在构造不同或覆盖缺失的城市 | 不进入本次比较 |

> 解析规则：一列在本次比较中的等级，等于该列在集合内所有城市中的最低等级。

这条规则处理一个静默失败：**完整性检查不等于可比性检查。** 洛杉矶的工资是职业×都会区，上海的是行业×城市，两者都"有工资"，都能通过存在性检查，然后产出一个静默有偏的比较。构造必须单独检查。

### 5.6 覆盖率检查与无数据支持的维度

丢弃 C 级字段会引入一个维度上的选择偏误：被丢掉的往往正是两地差异最大的那一维，于是比较系统性地**偏向相似**。

修正方式是把可比性重新定义为"数据集 × 用户权重"的联合属性。抽取到权重后：

```
覆盖率 = 用户权重落在保留维度上的质量占比
```

- **覆盖率 ≥ 50%**：执行比较，并明确列出哪些维度在本次比较中无数据支持，及其合计权重占比。
- **覆盖率 < 50%**：停止。用户在意的东西有一半看不见，此时的排序已不是对他的排序。
- **覆盖率始终作为常驻输出显示**，不只在拦截时出现。覆盖率 62% 的结果与 97% 的结果可信度完全不同。

> **措辞规范**：界面写"以下维度在本次比较中无数据支持"，**不写"失效"或"不适用"**。前者会被读成"这一维在这些城市都差不多"，那是给了用户一个他并没有得到的信息。**被丢弃的维度是不知道，不是没差别。**

未来功能：覆盖率不足时给出可行子集建议（"移除上海后覆盖率升至 88%"），让失败变成建设性的而非死路。

### 5.7 国内优先，跨国分级可行

**V1 只做美国国内。** 国内 A 级数据丰富，足以支撑完整验证。

**跨国比较不是全局不可行，而是对特定集合与特定用户可行。** 某些国家组合（如美加之间，统计体系同源，加拿大有职业与人口普查都会区交叉的工资数据）可以整体通过，另一些组合在移除若干城市后也能通过。中美之间只有少量 A 与 B 级字段，多数是 C 级：中国公开工资统计的主干是行业×城市；城镇单位口径系统性排除非正规就业与小微企业；只有均值没有分位；且中国没有官方的次国家空间价格指数。

**同一套思路在国内同样适用，只是程度更轻。** 国内的构造问题：

- OEWS 的都会区定义随年份修订，跨年份拼接会产生构造漂移。
- OEWS 对部分职业与地区做保密抑制，数据缺失非随机。
- RPP 的三类划分与 CEX 的支出分类口径不同，需要一次映射。
- 州所得税结构差异（平税、累进、无税、地方附加）不是一个参数能表达的。
- 部分都会区跨州（如纽约都会区跨 NY/NJ/CT），税制归属需要规则。

### 5.8 三层可比性声明

任何输出都必须落在其中一层并明示：

| 层 | 条件 | 可比的对象 |
|---|---|---|
| 一 | 集合内所有必需维度均为 A 级 | 福利水平直接可比 |
| 二 | 集合含 B 级列 | 福利水平可比，逐维标注等级与覆盖率 |
| 三 | 任意集合，包括数据严重不可比者 | **回收误差始终可比**（研究模式，见 11.7） |

第三层的理由：研究模式的结果变量是回收误差，而**回收误差是无量纲的**。真值层只需在各自国家内部自洽，两个真值不在同一尺度上并无妨碍，因为我们从不比较它们，只比较模型在两国世界中回收权重的误差。

**副产品**：上述机制会自然产出一张**可比性矩阵**，即哪些城市组合在哪些维度上可比。这张表本身可以是一项独立贡献。

实现约束：给货币量打 `numeraire_id` 标签（如 `"USD_2024_US100"`），并让跨 numeraire 的福利水平比较成为类型错误，而无量纲的回收误差永远放行。这样本节不是文档里的一段承诺，而是运行期强制的约束，与 `Observable` / `GroundTruth` 完全同构。

跨年也需要 numeraire：第三年的一美元与第一年的不是同一个东西，而 7.5 的转移核含三个增长率与储蓄复利。决定：全部使用基年不变价，三个增长率一律取实际增长率，`numeraire_id` 全程恒定。不用名义量再逐年平减。这个决定必须在写转移核之前做，事后改要动所有增长率的数据源口径。

## 6. 用户输入

用户输入必须先于代理设计定稿，因为它决定权重向量的形状，而权重向量的形状决定 prompt 模板、`Observable` 的构造、以及评估层设计矩阵的列。

### 6.1 四类输入，四种形式

判据是**这个输入是否关于权衡**。定和量表的全部力量来自强制权衡，用在没有权衡结构的问题上只会制造噪音。

| 形式 | 用于 | 为什么是这个形式 |
|---|---|---|
| **定和量表** | 价值权重（七维） | 唯一需要强制权衡的地方 |
| **选择器** | 职业 | 没有权衡，只有一个事实。带搜索，映射到 SOC 编码 |
| **行为代理题** | 消费结构、可贸易品倾向 | 用户不知道自己的食品支出占比，但知道自己有没有车。问可回答的，推不可回答的 |
| **自由文本**（可选） | 前三类漏掉的东西 | 交语言模型处理，**只能调整、不能覆盖**定和量表的结果 |

**职业不用开放文本**，因为那需要一个分类器，而分类器就是语言模型，会退回到"模型决定数字是什么"的问题。

**设计纪律**：每类输入只用一种形式，混用会让用户反复切换认知模式。全部控制在五分钟内。每多一题掉一截完成率，而人格坍缩的文献又表明维度越多模型侧表现越差。两侧约束指向同一方向：**少维度**。

一条对文献的定位：本项目的主输入是结构化量表，是用户自己的行为，不是任何模型的转述。在"原始材料优于模型转述的叙事"这一发现的框架里，本项目的主通道站在好的那一侧。自由文本只是可选的辅助通道，且受 8.2 的调整幅度上限约束。

### 6.2 价值权重的域结构

需要的是**价值观量表**而非人格测验。MBTI 一类测的是特质（你怎么处理信息）而非价值（你想要什么），且类型化的输出会主动加剧人格坍缩：类型标签正是"最具刻板显著性的属性"，模型会去调用关于该类型的网络文本，而不去读那几个权重。**输出必须是连续权重向量，不是类型。**

| 量表 | 结构 | 优势 | 已知问题 |
|---|---|---|---|
| **WHOQOL-BREF** ✅ 采用 | 26 题四域：生理、心理、社会关系、环境 | 环境域几乎就是城市属性清单；在十五个文化场景同步开发，专为跨文化可比性设计，有验证的中文版 | 面向生活质量测量而非选择；部分题项与城市属性无关。见下文改造 |
| **OECD Better Life Index** | 11 个维度，用户对每维打分转成权重 | 天生是地方层级；十万以上用户提交过权重可作先验；Regional Well-being 覆盖 361 个次国家区域 | 维度选择缺乏严格理论推导 |
| **Schwartz PVQ** | 10 个基本价值排在环形结构上 | 进入欧洲社会调查每一轮，有跨三十国公开分布 | 测抽象价值而非地方属性，需一层映射 |

**不自造量表**，量表验证本身是一个完整的研究项目（因子结构、重测信度、跨文化测量不变性）。相关术语：**测量不变性（measurement invariance）**。

注：OECD BLI 未被采用为域结构。它的用户权重数据可作 5.1 中真实偏好分布的候选来源，但按 5.1 的三条限定，它只进对照臂，不作主实验的抽样分布。域结构用 WHOQOL，两者不冲突，只需一次维度映射。

#### 对 WHOQOL 的改造

它测的是"你对现状的满意度"，不是"你有多看重它"，直接挪用需要说清楚。干净的挪用方式是：**只取其域与 facet 结构做维度清单，不用其题项做问卷；并加一道过滤，只保留随地点变化的 facet。**

更重要的是第二道过滤：**每个物理量只能进入效用函数一次**（见 7.4）。财务资源与居家环境经预算约束进入效用，因此**它们不是舒适度维度**。

| WHOQOL facet | 归属 |
|---|---|
| 财务资源 | 预算约束（并入 w₁） |
| 居家环境 | 房租进价格指数，居住面积进 H（并入 w₁） |
| 人身安全 | 舒适度 |
| 医疗与社会照护可及性 | 舒适度 |
| 获取信息与技能的机会 | 舒适度 |
| 物理环境与休闲（污染、噪音、气候、文体设施） | 舒适度（两 facet 合并） |
| 交通 | 舒适度 |
| 社会关系（重解释为与既有社会网络的邻近性） | 舒适度 |
| 疼痛、睡眠、精力、自尊、身体意象等 | 不随地点变化，滤除 |

结果是**七维**：一维物质（w₁）加六维舒适度（w₂…w₇）。这张映射表须写进仓库，它是本项目区别于随手拟一份清单的地方。

### 6.3 抽取方式：定和量表为主，最优最差法校验

不用评分量表。让用户给每维打 0 到 10 分存在**尺度使用偏差**：有人用满量程，有人挤在中段，且这一倾向在跨文化上系统不同（东亚偏中点、北美偏极端）。

**主方法：定和量表（constant sum）。** 给用户一百分，在七个维度间分配。它与最优最差尺度法共享最关键的性质——强制权衡，因此消灭了"每一项都很重要"，也就不存在尺度使用偏差——但它直接给出**基数比值**，省掉一层估计。

选它的三条理由：本项目需要的就是一个直接的权重向量；问卷预算是五分钟，而最优最差法要十余轮；**七维正是定和量表工作得最好的区间**，其认知负担问题只在十几维时才严重。

| 缺陷 | 表现 | 缓解 |
|---|---|---|
| 整数锚定 | 人给 10、20、30，不给 13、27，粗化权重分布 | 用滑块而非输入框；生成合成人设时不沿用整数偏好 |
| 零值 | 某维给 0，Cobb-Douglas 指数为 0 会让该维消失 | 设下限，每维至少 3 分 |
| 顺序效应 | 首个呈现的维度得分偏高 | 随机化呈现顺序并记录置换 |

**校验模块：六轮最优最差尺度法**，约九十秒，每轮呈现四个维度问最重要与最不重要。两法结果严重不一致则标记该用户。这提供一个**跨方法一致性指标**，且复用 M5 的实现：最优最差法的标准估计方法就是条件 logit。

### 6.3.1 权重熵：一个零成本的产品指标

对权重向量而言，高熵意味着信息量低。

给出 15/15/14/14/14/14/14 的用户，权重接近均匀，归一化香农熵接近 1。他的排序结果会与用代表性篮子算出来的几乎一样，个人化对他没有收益。给出 50/20/10/5/5/5/5 的用户熵很低，排序会显著偏离代表性结果。

```
H_norm(w) = −Σ w_k · ln(w_k) / ln(7)
```

这个量在用户填完量表的瞬间就能算出，零成本，且它有三个用途：

**产品用途**：它预测"个人化对你能带来多少改变"，可以直接呈现给用户，也可以作为是否建议其补填自由文本的触发条件。

**研究用途一**：它给 M3 的难度轴提供了可计算的定义。最优与次优城市的福利差由**权重熵与城市属性离散度共同决定**——低熵权重加分散的城市属性产生大间隔，高熵权重无论城市如何都产生小间隔。这把 11.3 的四档难度从定性描述变成可控参数。

**研究用途二**：权重熵本身可以作为一个实验轴，扫熵看回收误差与福利损失如何随之变化。这一条大概率没人做过，因为它需要一个带福利度量的产品层。

它同时为 11.9 的 Dirichlet(α=0.5) 抽样提供了原则性依据：α=0.5 产生稀疏、有主导维度的低熵权重，而低熵正是个人化有收益、因而福利损失可被观测的区域。

> ⚠ 抽样分布已被 DECISIONS/0006 修改，见该记录：**物质维 α₁ = 1.5，六个
> 舒适度维保持 0.5**。物质维在结构上不同（只有它的指数出现在货币度量的
> 分母上），对称先验下 w₁ 中位数仅 0.076、约两成人设算不出美元福利数。
> 稀疏性未受影响，由 Dirichlet 的中性性质保证（实测舒适度子向量熵不变）。
> **连带**：注入协方差对角线不再是常数；注入均值是 `[1/3, 1/9×6]` 而非 `1/7`。

### 6.4 消费结构与可贸易品

**消费结构**：不直接问支出份额。问行为代理变量（家庭规模、是否有车、外食频率、租房还是自有），据此查 CEX 对应人口学单元的支出份额，再按回答微调，得到 5.2 中所需的三个份额 `s_rent`、`s_goods`、`s_other`。**这三个份额同时供 7.2 的预算参数映射使用，并按 5.2.2 在 `Persona` 构造时一次性冻结。**

可贸易品栏目：现在就建通道，V1 不填内容。

理由是接口稳定性。新增一个用户输入字段意味着问卷、权重向量、城市属性表、prompt 模板、`Observable` 构造、评估层设计矩阵六处同时改。这种横穿整条信息流的改动，做在有测试覆盖之前是一天的事，做在系统跑起来之后是一周加若干静默 bug。

V1 的实现：问卷中三个单选题（常吃菜系、汽车品牌倾向、手机品牌倾向）；城市属性表中三个对应字段，**全美国填同一个值**；定和量表中不给它们独立维度，它们是消费维内部的品种调整参数。

**一个免费的健全性检查**：全美国同值意味着这三列方差为零。若模型的选择与这些零方差列相关，说明估计层在读噪声。

**一个例外**：汽油价格在美国州际差异不小（加州与得州可差三成以上），因此"是否开车"这一题从第一天起就有信息量，并直接进入 `s_goods` 的调整。

**V2 的标志商品机制**：挑十至二十件可单独观察价格、且已知跨市场相对价格发散的具体商品。**正确的做法不是当功能，而是当研究变量**：两种指数都算（纯类别 vs 类别加标志商品），报告排名改变了多少。几乎不变说明该局限无关紧要且你证明了它；改变很大则是一个支持 Handbury (2021) 的结果。

## 7. 福利模型（M2）

真值的唯一来源。本章的每一个选择都直接决定 argmax，因此必须显式写下并冻结。

### 7.1 效用函数

> ⚠ 关于 σ=1 的地位已被 DECISIONS/0009 修订：Cobb-Douglas 对每一对变量强加
> 替代弹性等于一，其中包括"到手的钱"与"公共服务"这一对。该假设从"已裁决、
> 不再讨论"降为**已知边界**，并在 §12 写明它对跨国比较的方向性后果
> （系统性偏向低税低服务的一端）。V1 不改函数形式。

Cobb-Douglas：

```
U_i,c = C_i,c^α_i · H_i,c^β_i · Π_k A_k,c^θ_k,i
        其中 α_i + β_i + Σ_k θ_k,i = 1
```

- `C` 为非住房实际消费，`H` 为住房数量与质量，`A_k` 为第 k 项舒适度的标度值（[0,1]，见 5.3）
- 指数和为 1，即规模报酬不变，使效用在收入的单位变化下有良好行为

### 7.1.1 间接效用：H 被最优化掉，房租只出现一次

直接形式里房租看起来出现两次：一次在价格指数 `P` 里，一次在住房项 `H` 里。但 `H` 不是一个数据列，它是被最优化掉的内生选择。解出来之后它就消失了。

一阶条件（注意分母是 `α+β` 而非 1，因为 `α+β = w₁ < 1`）：

```
C* = [α/(α+β)] · Y / p_C
H* = [β/(α+β)] · Y / p_H
```

代回得间接效用：

```
V_i,c = κ(α_i, β_i) · (Y_net,i,c / P_i,c)^{w₁,i} · Π_k A_k,c^{w_k,i}

取对数：
ln V = ln κ + w₁·(ln Y_net − ln P) + Σ_k w_k · ln A_k
```

其中 `κ` 只依赖个体参数、不随城市变，在同一个人的跨城市比较中会约掉，因此对排序无影响，只在算等价变差时需要带上。代数上可验证 `p_C^α · p_H^β = P^{w₁}`，即 7.2 的两通道映射与 5.2 的价格指数是严丝合缝的同一件事。

这带来四个后果：

**其一，7.4 的单次计入断言变得几乎平凡**，不是因为我们小心，是因为函数形式让它自动成立。房租在整条计算图上只出现一次，就在 `P` 里，指数是 `s_rent`。

**其二，"高租金不保证高质量高面积"已被正确处理**：高 `p_H` 意味着同样的钱买到更少住房服务，所以昂贵城市的居民住得更挤。模型没有假设"贵等于好"。

**其三，解析可逆。** 11.3 第三档要反解属性使效用精确相等，在这个形式下是一次代数变形而非数值求根，且由于 `ln V` 是 log 属性的**线性**函数，它实际是一个线性方程组——可以同时构造多城并列并精确控制并列集合的几何形状。

**其四，也是决定性的：条件 logit 因此是正确设定的。** 条件 logit 假设效用在参数上线性，而真值效用恰好就是 log 属性的线性组合，所以估计量没有设定误差。若改用 CES 嵌套等非 log 线性形式，真值不再线性，条件 logit 变成误设定，届时测出的"回收误差"里会同时包含模型的设定误差与语言模型的失败，而两者无法分开——**那会毁掉整个 11.7。**

这一条把 Cobb-Douglas 从"一个方便的假设"变成"被评估层要求的假设"。

### 7.1.2 住房质量：方案 B

房租、面积、质量在数据上是三个变量，但在模型里扮演三种不同角色：房租是价格 `p_H`，面积乘质量是数量 `H`（被最优化掉），标准化后仍剩的质量差是**价格的测量误差**。真正的问题是第三项归谁。

采方案 B：效用函数保持 7.1 原样不动，全部工作放在 `p_H` 的构造上。数学上 `H = q_c · X`，买 `X` 的单价是 `p_x`，则每单位住房服务的有效价格是 `p_x / q_c`。效用函数一个字不改，变的只是 ledger 层怎么造那个数。

这一点的工程收益是决定性的：按硬规则 3，`src/econ/` 动一次作废所有旧实验，而质量调整方法几乎肯定要迭代几轮。把会变的东西放在不会作废实验的那一层。

- **主结果**：`p_H` = RPP 租金分项原值。它是官方构建的空间价格指数，符合 5.1 那条"绝不用 CPI"的正面要求。
- **稳健性对照**：按卧室数标准化的租金构造质量调整价。候选源为 ACS 的分卧室数中位租金（MSA 层级，另有房龄与结构类型分布可作粗糙 hedonic 的控制变量），以及 HUD 的 Fair Market Rent（按定义是标准质量住房的分卧室数 40 分位租金，天然做了质量筛选）。两套都算，报排名是否翻盘。

一个必须在 M1 核实、不能凭印象的点：BEA 的 RPP 租金分项究竟控制了什么。若它基于 ACS 租金数据、按卧室数分层但不控制房龄、结构类型与户内设施，则"要不要做质量调整"的必要性就取决于此。

明确排除的方案：把面积当 amenity（租金进 `P`、面积进舒适度向量）。它把休斯顿算了两遍——低租金已通过 `P` 变成更高实际收入，再给"宽敞"一个舒适度加分，同一件事记两次分。这正是 7.4 那张表要防的。

### 7.2 权重到参数的两通道映射

**这是本章最容易出错的一处。** 在 Cobb-Douglas 里，`α` 与 `β` 同时是效用指数**和**支出份额，这是函数形式的数学性质。而支出份额由**行为**揭示，不由陈述偏好决定；定和量表问的是"你多在乎"，是**陈述**偏好。**两类参数来自两个不同的信息源，不能混在同一份问卷里抽。**

因此设两个抽取通道：

```
通道一（行为）：行为代理题 → CEX 查表 → s_rent, s_goods, s_other
通道二（陈述）：定和量表     → w_1 … w_7

α_i = w_1 · s_goods+other / (s_rent + s_goods+other)
β_i = w_1 · s_rent        / (s_rent + s_goods+other)
θ_k,i = w_k              (k = 2 … 7)
```

由 Σw = 1 可得 α + β + Σθ = 1，自洽。

用户界面上仍是七个滑块分一百分。数学上第一维扮演的是"物质相对于环境的总权重"，其内部在住房与非住房之间的拆分由行为数据决定而非由用户陈述决定。这一点写进文档即可，不必让用户感知。

方向必须记牢：比值来自行为（CEX 份额定 `α:β`），总量来自陈述（`w₁` 定 `α+β`）。搞反的版本也能跑通、结果也不荒谬，但它推翻 7.2 的全部论证。

关于非位似性：Cobb-Douglas 是位似的（支出份额不随收入变），而恩格尔定律说住房份额随收入下降，Handbury (2021) 的标题就是 Non-Homotheticity。这个张力必须正面处理，否则审稿人一定会问。

本项目的处理：`s` 本就来自 CEX 按人口学单元（含收入档）的查表，因此不同收入的人拿到不同的 `s_rent`，因而不同的 `α/β`。非位似性通过份额向量进来了，只是不体现在同一个人的收入变动上。文档表述为：效用函数位似，非位似性由份额的跨人变异承载；跨期非位似留作 V2 稳健性。Stone-Geary（带生存性住房下限）是教科书解法，但它会让 `β` 从平均份额变成边际份额，而 CEX 给的是平均份额，7.2 的映射就得重做，还要额外估 `h̄`。V1 不值得。

### 7.3 标度函数

见 5.3。要点重述：优先 `absolute`，兜底 `quantile`；参照总体必须覆盖比较集合；分位表离线冻结，绝不在查询时现算。

**在研究模式下，标度函数是否"正确"不影响测试的良定性**，因为真值是我们定义的，任何单调标度都构成一个合法世界；它只影响任务难度。它真正要紧的是在产品模式下，那里它是一个实质性的建模主张。

### 7.4 单次计入规则

> 每个物理量只能进入效用函数一次。

| 物理量 | 唯一归属 | 不得再出现在 |
|---|---|---|
| 房租 | 价格指数 `P` 与预算约束 | 舒适度向量 |
| 住房面积与质量 | `H`（**被最优化掉，不是数据列**） | 舒适度向量 |
| 住房负担比 | **仅作诊断量**（见 9.1） | 效用函数 |
| 收入与储蓄 | 预算约束 | 舒适度向量 |

违反的后果不是数值偏差，而是**识别失效**：若房租既进价格指数又进舒适度，`w_1` 会同时从分子和分母起作用，回收出的隐含权重不再对应注入值。

工程措施：写一个断言，检查每个原始数据列在效用计算图里只被引用一次。**记账数的是"项"不是"读取次数"：预算约束里把 `wage` 读两遍不算重复计入，`wage` 同时进预算和舒适度才算。**

### 7.4.1 四条必须写在数学之前的断言

| **断言** | **内容** | **它保护什么** |
|---|---|---|
| **预算恒等式** | `abs(p_C·C* + p_H·H* − Y) < tol` | **写成 `αY/p_C` 会让 `(1−w₁)·Y` 凭空消失，静默污染 7.5 的储蓄轨迹，而储蓄是 9.1 的诊断量** |
| **两通道方向** | `abs(α + β − w₁) < tol` | **搞反的版本也能跑通，但推翻 7.2 的全部论证** |
| **κ 跨城不变** | **同一 persona 在所有城市的 `κ` 相同** | **排序里 κ 会约掉，所以排序测试发现不了这个错，但它会毁掉等价变差** |
| **log 线性** | **扰动 `w`，验证 `ln V` 的响应是常数斜率** | **保护 11.7 的条件 logit 正确设定，不是形式检查** |

### 7.5 三年转移核

```
wage_{t+1}    = wage_t × (1 + g_occ,msa)      # 实际增长率，基年不变价
rent_{t+1}    = rent_t × (1 + r_msa)          # 实际增长率
tax_t         = f_federal(wage_t) + f_state(wage_t, state)
```

### 7.5.1 享乐适应：V1 不实现

 这一条从 v0.5 撤回，理由是它在当前设定下不可识别。

Agentopia 第 B.10 节的做法不能直接搬：它的满足度是一个 0 到 100 的**存量状态变量**，每周按当前值的固定比例衰减。本项目的 `A_k` 不是存量，是城市属性——一座城市的日照时长不会因为你住久了就变少。

三个选项及其判定：

- **让 `θ_k` 随时间衰减：错的。** θ 之和必须等于 `1 − w₁`，θ 衰减就要重新归一化，而重新归一化会机械地抬高 `w₁`，等于断言"住得越久越在乎钱"。更致命的是时变系数破坏 log 线性，直接违反 7.4.1 第四条断言。
- **相对参照点衰减：`A_k^eff(t) = A_ref,k + (A_k − A_ref,k)·δ^t`。** 城市属性不变，变的是它相对于适应基线的**优势**在衰减。这个形式保留 log 线性。
- V1 不做：采用这一条。

理由是一个识别问题：适应只有相对参照点才被识别。若代理三年不动、也没有来源城市，`A_ref` 无从定义；取任何常数参照点的结果是对所有城市施加同一衰减，在 argmax 里完全抵消。也就是说，在固定投放设定下，享乐适应对城市排序没有任何影响，只是把所有效用等比例缩了一下。

它唯一起作用的场合是代理搬过家，此时 `A_ref` 是原城市的属性，于是产生"新鲜感会褪去"这个真实效应。因此：V1 不实现享乐适应；等打听与迁移机制落地（V2）再加，届时用相对参照点形式，参照点取上一座城市。

见第 9 章。

## 8. 工作流程（产品模式）

### 8.1 阶段零：数据准备（离线，一次性）

```
原始统计数据
    │
    ▼
数据转化模型 ──只做模式映射，不生成数值──▶ 人工复核 ──▶ 冻结
    │
    ▼
city_attributes.parquet  +  字段台账  +  参照总体与分位表
```

不在用户会话中运行。

### 8.2 阶段一：用户会话

1. 用户完成四类输入（6.1）。定和量表给出 `w_1 … w_7`；行为代理题经 CEX 查表给出 `s_rent, s_goods, s_other`，**并在此处一次性冻结进 `Persona`（见 5.2.2）**。
2. 用户可选填一段自由文本。语言模型据此调整权重，**只能调整、不能覆盖**定和量表结果。
3. 经 7.2 的两通道映射得到效用参数 `(α, β, θ)`。**这些参数交给福利模型，不交给代理层。**
4. **集合级兼容性解析**：给定城市集合 S，查台账解析每字段等级（取集合内最低），丢弃 C 级字段。
5. **完整性检查**：剩余字段能否覆盖全部必需维度。允许某些城市在某维信息更丰富，但不允许有城市在该维完全缺失。
6. **参照总体解析**：确认存在覆盖 S 的冻结分位表。
7. **覆盖率检查**：权重落在保留维度上的质量占比。低于 50% 则停止并说明。
8. **适用边界检查**：算出本次选择集的福利离散度，低于阈值 τ 时如实告知用户此处的建议区分度有限（见 1.2 问题三）。
9. 福利模型计算各城市的综合福利分、分维剖面与补偿性差异。
10. 返回排序、剖面、覆盖率、**权重熵**、无数据支持的维度清单及其权重占比、以及抽取不确定性的传播结果（见 9.3）。

### 8.2.1 自由文本通道是产品模式唯一的坍缩暴露面

产品模式的推荐路径是确定性的：定和量表给出 `w`，行为代理题查 CEX 给出 `s`，两者都不经过大模型；`w` 交给福利模型，排序由代码算出。如果用户跳过自由文本，大模型对推荐结果的贡献严格为零，坍缩咬不到这条路径。

但自由文本通道正是坍缩作用的地方：一个偏好离 RLHF 中心远的人写下一段有特点的自述，模型把它拉向众数解读。这就是"越离 RLHF 中心远的用户越受影响"在产品模式里的落点。

缓解措施已内建于 6.1 的"只能调整、不能覆盖"，但那条原则必须变成一个显式参数：

> 自由文本对任一维权重的调整幅度不超过 ±10 分（配置项 `free_text_adjust_cap`，附断言）。

这个上限把坍缩造成的伤害夹在一个已知的界内。

### 8.3 阶段二：三年模拟

**产品模式下，所有代理共用同一组效用参数**，它们是同一个用户的不同分身，被分到不同城市。每座城市可跑多个副本以平均模型噪声（见 8.6）。

每个代理每年一次语言模型调用，一年四步：

1. **环境结算**（纯代码，零调用）。按 7.5 的转移核演进。
2. **构造 Observable**（纯代码）。类型系统保证 `GroundTruth` 不进入。
3. **代理决策**（一次调用）。输入为 `Observable` + 自身画像 + 上一年自己的私有结果 + 打听到的两条消息。输出为结构化 JSON：`{留下或搬往何处, 消费储蓄比例, 一句理由}`。
4. **环境执行**（纯代码）。应用决策，若搬家则扣除迁移成本，写入轨迹。

**年末**：福利模型计算这一年的分维剖面与综合分。代理看不到这个分数。

**三年后**：汇总轨迹，报中位轨迹与离散区间。

### 8.3.1 离散区间可能系统性偏窄

这是产品模式的第二处坍缩暴露，而且比错误的排序更隐蔽。

离散选择实验方向的实证发现，大模型的选择系统性地过度自信，缺乏真实人类决策中的自然变异性。若如此，则本节输出的离散区间会比真实不确定性窄——用户看到一个置信区间，而那个区间是假的窄。排序错了用户可能会怀疑，区间太窄则看起来像精确。

校准方案（无需新装置）：把 11.8 的重复子集从研究模式的基线测量升级为产品模式的区间校准器。用重复子集测出的纯采样噪声，检验产品模式的区间是否系统性偏窄；若是，则显式加宽，或降级为定性表述（"这几座城市的结果差别不大"）而非给出一个假精确的数字区间。

### 8.4 打听机制

每年结算后，每个代理随机收到两条消息：一条来自同国另一城市的代理，一条来自国外城市的代理（跨国模式下）。代理据此决定是否付出迁移成本搬家。

**消息内容必须是无量纲量**：储蓄率、住房负担比、分维福利剖面（标准化到 0 至 100）。**不能是水平量**，"我攒了八万块"不合法，因为接收方需要一次汇率与购买力换算，而那正是我们不允许代理做的数值计算。

这个机制之所以有内容，是因为经济层给了每个代理**私有信息**：它自己实际付的房租、实际攒下的钱、实际的分维剖面。所有代理共用同一个基座模型，若无私有信息，互相打听只是把同一个先验多洗一遍，产生的是回声而非信息扩散。**经济层的存在是这个机制成立的前提。**

顺带一个可对照的基准：Horton 等人复刻了 Samuelson 与 Zeckhauser (1988) 的现状偏误实验。本项目每年都有一个"留下还是搬走"的决定，若代理表现出现状偏误，那是真实的人类行为（人确实有）还是模型的产物？这个对照成本几乎为零，值得作为一个附带观察记录。

### 8.5 信息流

```
[原始数据] ──▶ [转化+复核+冻结] ──▶ [城市属性表 + 台账 + 分位表]
                                              │
[定和量表] ─────────────▶ w_1…w_7 ─┐          │
[行为代理题] ──CEX──▶ s_rent,s_goods,s_other ─┤  ← 在 Persona 处冻结
[自由文本] ──[语言模型，±10 分上限]──▶ 调整量 ┘
                                    │         │
                                    ▼         │
                          [7.2 两通道映射]    │
                                    │         │
                                    ▼         ▼
                              (α, β, θ) ─▶ [福利模型 / 经济核]
                                              │
                                   ┌──────────┴──────────┐
                             observe()               score()
                              L0–L2                   L3–L4
                                   │                     │
                                   ▼                     ▼
                           [Observable]           [GroundTruth]
                                   │              features / ev_by_city
                                   ▼              welfare_gap / dispersion
                             [代理层]                    │
                                   │                     │
                                   ▼                     │
                             [决策 JSON]                 │
                                   │                     │
                                   ▼                     ▼
                           [环境执行] ──────▶ [结果：排序 / 剖面 / 覆盖率 / 熵 / 适用边界]
                                   │
                                   └──▶ [打听：无量纲消息交换]
```

### 8.6 三个方差来源，必须分开记账

这是整个系统里最容易被误读的一处。

| 来源 | 出现在 | 性质 | 处理方式 |
|---|---|---|---|
| **模型采样噪声** | 两个模式 | 干扰项 | 测量并扣除，不作解释 |
| **抽取不确定性** | 产品模式 | 真实 | 显式扰动权重，做敏感性（9.3） |
| **注入的群体异质性** | 仅研究模式 | 刻意 | 就是被回收的对象（11.2） |

**关键澄清**：产品模式下同一座城市跑多个副本，其间的差异**只是解码随机性**，不能被解读成"这个用户可能是什么样的分布"。温度带来的输出抖动是一个实现产物，它没有被校准到任何东西上。同一个 prompt 跑两次得到不同答案，不代表这个人有两种可能，只代表解码是随机的。

因此产品模式下跑副本的正确理由是**把模型噪声平均掉**，报中位轨迹加离散区间，而不是"采样用户的可能形态"。**并按 8.3.1 校准该区间的宽度。**

## 9. 输出

### 9.1 综合福利分与诊断量

主输出是一个**综合福利分**，而不是若干工具性变量的并列。理由：可支配收入、净储蓄、住房负担比都是手段，福利才是目的。工具性变量降级为**诊断量**，用于解释综合分为何是这个值。

综合分的构造要求：

- **维度是绝对量**，在任何两座城市含义相同，不做队列内归一化。
- **不含排名分量**，因而不是零和的。
- **权重来自用户**，不来自设计者。
- **综合分与分维剖面永远一起报告**。综合分用于排序，剖面用于解释与暴露权衡。

等价变差在这个框架中不消失，它是物质那一维的严格度量。

诊断量清单：三年累计实际可支配收入、期末净储蓄、住房负担比、各舒适度维的标度值。

### 9.1.1 福利损失：把误差换算成美元

这是 1.2 三个问题共用的度量，也是本项目区别于纯 benchmark 的核心。

benchmark 报的是"模型 X% 的情况下选错了"，那是一个 0/1 损失。但选错不是均质的：推荐了次优城市而它只差 0.5% 的福利，几乎无害；推荐了差 15% 的城市，是真实的代价。

```
福利损失 = EV(真值最优城市) − EV(模型推荐城市)      单位：美元/年
```

于是"这个模型有多好"的答案从一个百分比变成一句话：听从这个模型的建议，中位用户每年损失多少钱。

这个度量还自动解决了 benchmark 的一个老问题：命中率对难度极其敏感（简单题人人满分，难题人人零分），而福利损失是连续的、在难度之间可比的。

**基准线与分解（1.2 问题二）**

现状工具做了两个独立的近似：平均篮子 `s̄`，以及完全没有舒适度维度（等价于 `w = (1,0,…,0)`，只按实际收入排序）。因此基准线必须两个都施加，并且能分解：

```
定义 argmax_c EV(c | s, w) 为"在参数 (s,w) 下选出的城市"，
    真值最优 c* = argmax_c EV(c | s_i, w_i)。

L_rep  = EV(c*) − EV( argmax_c EV(c | s̄  , w_mat) )   # 现状工具，两个近似都施加
L_s    = EV(c*) − EV( argmax_c EV(c | s̄  , w_i  ) )   # 只错篮子
L_amen = EV(c*) − EV( argmax_c EV(c | s_i , w_mat) )   # 只丢舒适度
L_llm  = EV(c*) − EV( argmax_c EV(c | s_i , ŵ_i  ) )   # 大模型读自述抽权重
L_user = 0                                             # 用户自己填量表，即真值

其中 w_mat = (1,0,0,0,0,0,0)，即全部权重压在物质维。
所有 EV 一律在真值参数 (s_i, w_i) 下评价，只有 argmax 用近似参数。
```

**这一点是全节的要害：损失永远在真值偏好下评价，近似只用于"选哪座城市"。** 若用近似参数同时做选择和评价，算出的是自洽的胡话，不是损失。

> `L_rep`、`L_s`、`L_amen` 全部零大模型调用，只用经济层就能算，且 `L_rep` 同时是"个人化到底值多少钱"这一产品前提的检验。因此这三项应当最早计算，早于 M4。

#### 9.1.1.1 停止阈值必须现在定，而且要从项目内部导出

"若 `L_rep` 很小就重新考虑"不是一条决策规则。事后再定，面对的是一个已经投入几个月的项目，而任何数字都能被论证成"够大"。但随手拍一个数（比如"每年 800 美元"）同样没有依据，只是把任意性提前。**阈值应当由已有机制算出。**

最干净的锚是 9.3 的抽取不确定性：

> **噪声地板** = 按 9.3 对权重做每维 ±5 分扰动（幅度来自问卷粒度，因此有依据）所诱导的 `EV` 变动幅度，取其中位数。

判据分两层，因为 `L_rep` 依赖选择集（三十个相似都会区上它必然小，分散的选择集上它大）：

> **在福利离散度高于 τ 的选择集上（τ 即 1.2 问题三的适用边界），`L_rep` 的中位数是否超过噪声地板。若在任何现实可构造的选择集上都不超过，则判定个人化在本装置上不可测量，产品前提不成立。**

三点说明：这个阈值可复现，写进配置就固定；它接在已有的 τ 机制上，不是一条孤立的红线；它给出的断言是"不可测量"而非"不重要"，后者是更弱也更诚实的说法。

**这一条与 10.3 的 `λ > 0.8` 是两个并列的停止门，都在花任何大模型预算之前判定。**

`L_s` 与 `L_amen` 之和一般不等于 `L_rep`（argmax 不可加），差额本身有信息：它衡量两个近似的交互。三项都报，不做加法。

### 9.2 为什么不直接用 Agentopia 的 life reward

Agentopia（arXiv 2606.07513）第 4.1 节的 life reward 由社会、主观、经济三维 z-score 加权构成（λ_social=0.4、λ_subj=0.4、λ_econ=0.2）。三条性质不适用：

- **社会奖励是排名制的，因而零和。** 该文第 D.2 节指出社会奖励在三个世界中都保持平稳，因为它基于相对排名而非绝对表现，一人所得基本来自他人所失。零和分量无法说明城市 A 好过城市 B。
- **z-score 在同队列内做**，综合分因此相对于这批代理定义，无法跨城市比较。
- **权重由设计者指定**，对一百个代理一视同仁，正是本项目要避免的。

该文自己的案例是最好的反证：第 6 案例中 Jun 的社会奖励连续九年下降，同期心情由 72 升至 97、个人满足度增长 57.6%，论文明言这挑战了"社交广度与福祉正相关"的设计假定；第 D.9 节显示进取型代理存款是安逸型的 1.70 倍，社交满足只有 0.75 倍，惩罚次数是 2.11 倍。综合分会把这些冲突压平，而这些冲突恰是本项目要暴露的东西。

采纳其结构，不采纳其实现。

### 9.3 抽取不确定性的传播

"用户是什么样"确实有真实的不确定性，但它不来自模型温度，来自问卷本身的粗糙：定和量表有整数锚定，CEX 查表有单元内方差，自由文本的解读有歧义。这些是**可量化的**。

做法是在已知粒度范围内扰动权重（例如每维 ±5 分），跑一组，看排序是否翻盘。扰动幅度来自问卷设计，因此有依据；这与温度噪声的区别在于后者的幅度来自解码参数，什么也不代表。

输出中报告：排序在扰动下的稳定性、以及最容易翻盘的城市对。

### 9.4 稳定性

产品模式下，同一个用户的多个副本**应当**高度集中于同一座城市。分散度在这里衡量的是**模型的不稳定性**，越低越好。这与研究模式下的期望方向相反，见 11.6。**并按 8.3.1 检验它是否假的窄。**

## 10. 检验与防护

本章是对产品模式的常规检验。**第 11 章的研究模式是对同一系统的一次极端检验**，两者互补。

### 10.1 单次计入断言

遍历效用计算图，断言每个原始数据列只被引用一次。见 7.4。**记账数的是项而非读取次数。**

验证方式：用一个"故意坏掉的核"检验断言本身。`DoubleCountingCore` 把租金塞进舒适度向量，`DiagnosticInUtilityCore` 把住房负担比塞进去。只见过正确代码的断言等于没有断言。

### 10.2 泄漏防护

- **类型边界**：代理层适配器只接受 `Observable`。**`AgentInput` 构造时递归遍历自身并拒绝任何答案侧对象，包括埋在 dict 与 list 里的；泄漏必须先骗过构造函数，而不是骗过 code review。**
- **排列随机化**：每个代理随机排列城市顺序并记录置换，避免"总选第一个"。
- **标签随机化**：每个世界实例重新分配城市标签，避免批次内学到标签与属性的相关。

#### 10.2.1 泄漏扫描必须是数值比对，不是字符串匹配

 v0.5 与初版实现均基于字符串匹配，这有一个根本缺陷：

浮点数不能这样处理。`0.2` 在二进制里不精确，存的是 `0.200000000000000011…`。若权重是算出来的（例如 `20/100` 再归一化），可能拿到 `0.19999999999999998`，而 `"0.2"` 不是它的子串——字符串搜索直接漏掉，而这恰是最典型的泄漏形态。

正确做法：

1. 用正则从 prompt 抽出所有数字形态的词元（需处理千分位、科学计数法、百分号）
2. 逐个 parse 成 float
3. 对每个真值及其变换，做相对容差比较

```python
for cand in extract_numbers(prompt):
    for mult in (1, 100, 1 / 100, 12, 1 / 12, 1000, 1 / 1000):
        if rel_close(cand, truth * mult, rtol=1e-3):
            flag()
```

这一步同时解决四件事：四舍五入、浮点表示误差、不同渲染、以及单位换算（在枚举的乘子上）。

> 已知局限，写进文档字符串而非隐藏：单位换算只能枚举不能穷尽。可能的变换在原理上无穷（乘 100、除 12、汇率、取对数、转秩次），只能覆盖在意的那几个。类型边界才是第一道防线，扫描是第二道。

误报控制随之从字符串问题变成数值问题，比有效数字地板健壮：白名单为该 `Observable` 中合法出现的所有数值；黑名单为 0、1、2、100 这类普遍值。`min_value_digits` 这个有效数字地板可以删掉——那个"默认阈值让新加的扫描点默认是瞎的"的问题随之自动消失。

#### 10.2.2 权重向量的指纹检查

七个权重是一个和为一的向量，因此可以做一个单值扫描做不到的检查：

> 从 prompt 抽出的数字集合里，是否存在一个大小为七的子集，其和为 1（或 100），且作为多重集与真值权重在容差内匹配。

这能抓到"七个权重被整体倾倒出来"的泄漏，即使每一个单独看都像无害的普通数字。单值扫描会全部放过。

#### 10.2.3 顺序泄漏

就算一个数字都没出现，若人设散文里七个维度按权重降序排列，秩序信息已经泄漏，模型完全可以只利用秩序就答对权衡档。数值扫描对此无能为力。

处理：人设生成时随机化维度的叙述顺序并记录置换，并加一个检验——叙述顺序与权重的秩相关不显著。这与本节已有的城市排列随机化是同一手法，只是作用在人设文本上。

### 10.3 估计器自检：目标是量化偏差，不是确认无偏

在调用任何语言模型之前，先用真值模型生成的合成选择数据跑一遍完整回收流程。跳过这一步，后面将无法区分"模型错了"与"尺子错了"。

**但目标不是"确认估计器无偏"。** 文献表明，最大模拟似然的混合 logit 估计即使在设定正确的情况下也是有偏的，且方差与相关性部分尤甚；标准建议是在依赖 MSL 估计之前先做模拟分析，评估偏差幅度。由于 11.7 的坍缩系数就是估出协方差与注入协方差之比，估计量自身的偏差会被直接读成坍缩。

**因此自检的产出是两条地板加一张偏差表，而不是一个通过/不通过。**

自检数据的构造：**直接用真值权重 `w_i` 经 softmax 生成选择**（不调用任何大模型），过与主实验完全相同的估计器与完全相同的样本规模（1000 人设 × 5–8 次选择）。样本规模必须相同，否则收缩幅度不同，地板不可比。

产出一：**协方差地板。** 在若干组已知的注入协方差上（至少覆盖"注入方差大"与"注入方差小"两端）跑回收，报告 `估出协方差 / 注入协方差`。**这个比值在真值数据上就已经不等于 1，它就是估计量的基线压缩。** 主实验报坍缩系数时扣除它；若它随注入方差变化，则坍缩系数按注入方差分组报。

产出二：**`proj` 地板 λ。** 在同一批合成数据上按 11.7 的定义算 `proj_i`，对 `d_i` 回归取斜率，即 `λ`。这是纯收缩造成的向中心位移，与大模型无关。1.2.2 的坍缩比例以它为分母的一端。

##### 10.3.1 地板臂的 σ 从哪里来：从重复子集标定，不从匹配臂读

生成地板数据需要一个 softmax 的 σ。有三个候选来源，两个是错的，必须说清楚为什么，否则将来会有人"顺手改回去"。

**错误做法一：事先拍一个数。** 若拍小了，λ 偏小，坍缩被高估；拍大了反之。没有依据。

**错误做法二：跑完匹配臂之后读它自己的 `σ̂ = 1/γ_0`，再回来取对应的 λ。** 这个做法很自然，但它把地板变成了处理变量的函数，地板一旦对处理敏感就不再是地板。具体的污染来源是：

`σ̂` 不是"大模型的解码噪声"，它是拟合出来的 logit 为了合理化观测选择所需的**全部残余随机性**，至少混了三样东西：

1. 真正的解码随机性；
2. **设定误差**，即大模型行为偏离 log 线性形式的部分（例如它用了词典序规则、或存在阈值效应）；
3. 同一个人五到八次选择之间的内部不一致（混合 logit 里 `β_i` 在个体内是常数，所以人内矛盾无处可去，只能进 σ）。

**第 2 项是真正的污染。** 设定误差既不是解码噪声也不是收缩相关的随机性，但它照样抬高 `σ̂`，进而抬高 λ、压低坍缩。

> 需要说明的是，第 3 项（人内不一致抬高 σ̂，从而抬高地板）**不是**污染。地板本来就该随数据的信息含量走：噪声大时个体似然确实平坦、收缩确实强、`proj` 确实大，一个按实际噪声索引的地板会正确地说"给定这个噪声，这么大的 `proj` 本就该出现"。把这一项当污染是把噪声和坍缩混为一谈。放弃 `σ̂ = 1/γ_0` 的正当理由只有第 2 项。

**正确做法：从 11.8 的重复子集标定。** 重复子集是同一人设、同一世界、跑多次，因此

- 模型**稳定地**读错某人 → 重复之间答案一致 → 不进噪声估计。**稳定的误读是坍缩，不是噪声，这个分离正是我们要的。**
- 模型读得**不稳** → 重复之间分歧 → 进噪声估计。这也是对的。
- 设定误差是系统性的，在重复之间稳定，因此**不进**噪声估计。这就是它比 `1/γ_0` 干净的原因。

实现：把地板臂生成数据时的 σ 标定到"人内重复一致性与重复子集实测相同"。

> **必须写明的限定**：重复子集测的是**同一人设同一世界跨次运行的分歧**，logit 的 σ 测的是**备选项间的特异误差**，两者相关但不同一。用前者标定后者是一个**校准启发式，不是恒等式**。不要在文档或代码注释里把它写成精确对应。

##### 10.3.2 `λ(σ)` 曲线仍然要报，但它的用途变了

**它不再用于事后查表。** 门二的判据在标定出的 σ 上判定；`λ(σ)` 曲线的作用降为"报告 λ 对 σ 假定的敏感性"，让读者看到标定误差能造成多大影响。

生成方式不变：扫 softmax 的 σ，σ 大（选择接近随机）则个体似然平坦、收缩强、λ 接近 1；σ 小则 λ 小。

**同时提醒：λ 不是 σ 的一元函数**（见 1.2.2 的 `k_i ≈ V_i/(V_i + Σ_pop)`）。同一个 σ 配不同的 `Σ_pop` 会给出不同的 λ，而 `Σ_pop` 正是坍缩直接作用的对象。这就是为什么地板最终只能给区间，而 `λ(σ)` 只是其中一个维度的敏感性。

##### 10.3.3 门二：测量窗口，以及它的分析理由

> **停止条件（与 9.1.1 的 `L_rep` 阈值并列，两者都在花大模型预算之前判定）：`1 − λ` 是问题一的测量窗口。若在标定出的 σ 上 `λ > 0.8`，窗口只剩两成，`proj` 一侧的指标不可测。此时必须先增加每人的选择次数或降低选择噪声，不要直接开跑主实验。**

> ⚠ 本条的判据已被 DECISIONS/0002 扩充为三条，见该记录。新公式下只观测到
> 混着衰减因子的 `λ̂`，`λ ≤ 0.8` 无法直接检验，须先去衰减。门二现为：
> **2a** `λ̂/ŝ_shuffled ≤ 0.8`（原判据，去衰减后）；
> **2b** 窗口 `(ŝ_shuffled − λ̂)` 与其 bootstrap 标准误之比不低于预注册阈值
> （新分母是估计量，趋零时 `r` 的方差爆炸）；
> **2c** `ŝ_shuffled ≥ 0.5`（`d` 本身测得有多糟；2b 守 `r`，2c 守 `r(d)` 的分箱）。

这个阈值不只是经验值，它有一个分析上的对应物。由 §11.7.1.1，`γ_0 = 1/σ`，而个体权重 `ŵ_i = γ_i/γ_0` 是一个比值估计量，**当 `γ_0 → 0` 时比值的矩不存在**。而 `γ_0 → 0` 就是 σ → ∞，也就是选择接近随机。

**所以"λ 逼近 1、测量窗口关闭"与"`γ_0` 逼近 0、比值估计量爆炸"是同一个物理情形的两种表现。** 门二同时守住了这两件事，它不是一个孤立的经验门槛。

##### 10.3.4 人内不一致度对 `d_i` 的回归（门二的一部分）

**这是整份文档里性价比最高的一个检查：零成本，数据本来就要跑，而它检验的是主指标公式的一个前提假设。**

把重复子集的人内不一致度对 `d_i` 回归。若显著为正，说明模型在偏好不寻常的人身上更不稳定，那么 **λ 本身是 `d_i` 的函数**，于是

```
r = (s − λ)/(1 − λ)          ← 单一斜率版本，此时失效
r(d) = (s(d) − λ(d))/(1 − λ(d))   ← 逐点版本，此时才成立
```

**"单一斜率"这个说法整个作废的理由要说清楚**：`s` 原本是 `proj` 对 `d` 的回归斜率，它是把 `proj(d)` 当直线拟合出来的数。若 λ 随 `d` 变，`proj(d)` 本身就不是直线，拟合出的那条斜率没有对应的总体量。

**这个回归必须在门二判定时就跑，不能等主实验之后**，因为它的结果决定 M5 实现哪一套公式，而那是两套代码。等主实验跑完再发现要重写评估层，代价高得多。

**功效不足不能当作"没有依赖"。** 而且这个检验的功效恰好在最需要它的时候最低：若 λ 确实随 `d_i` 上升，那么 `d_i` 大的人收缩更强、个体估计更不稳，回归右端的方差更大，效应的存在本身使它更难被检出。因此采用**两级默认**：

```
主结果：r(d) 曲线，分箱数事前定死（4 或 5 箱，等频不等宽，与 §11.9 的抽样层对齐）
稳健性：单一 r，仅当 λ(d) 的斜率检验在预注册的功效下不显著时可用
若两者结论不一致：以 r(d) 为准，并报差异
```

同时**预注册最小可检测效应**，而不只是显著性水平：写成"本设计在 α=0.05、power=0.8 下能检测到的 λ 斜率是 X"。这个数在跑之前就能算，它只依赖样本量与分箱设计。没有这个数，"不显著"这句话没有内容。

`r(d)` 的代价必须算清楚：分箱后每箱只有总量的几分之一。1000 个人设分五箱是每箱 200 人，估一条局部斜率是紧的。这是 §11.9 采用分层抽样的直接原因。

**单纯形秩检查（新增，阻塞性）。** `Σw = 1`，因此注入的协方差矩阵秩最多为 6。若估计按七个自由随机参数进行，估出的是满秩矩阵，"比值即坍缩系数"这句话在数学上没有定义。自检必须显式验证：注入协方差的数值秩为 6，且估计器在同一个约束空间内工作（见 11.7）。

**条件数检查（保留）。** 检查观测矩阵的条件数：若城市属性高度共线，反解出的权重会不稳定，而这与模型的缺陷无关。

**估计器自检的全部结果写进仓库并随主结果一起报告**，因为读者需要知道尺子本身有多准。

### 10.4 基座模型是处理变量

Agentopia 第 D.11 节显示不同基座在同一世界中产生系统性不同的行为剖面，且需构造 t=0 基线以扣除人设自带偏差。因此所有实验至少在两个基座上运行并分别报告，模型版本用带日期戳的快照并写进每条日志。

Kim 等人的结果独立支持这一条：他们发现不同大模型在偏好参数空间上有系统性不同的"偏科"——GPT 学风险厌恶好过学失望厌恶，Gemini 在高失望厌恶区间最好，Claude 在参数空间上覆盖最广。这把"基座是处理变量"从一个论证变成一个已被验证的经验事实。

**基座选择有理论动机**：一个前沿模型，加一个不同家族、不同来源国的模型。后者不是随机对照——研究问题之一正是模型对中国城市的表现是否更差，把一个中国团队训练的模型放进对照组，直接构成一个有动机的对比。

补充理由：在用社会经济微观数据模仿个体受访者的评测中，Qwen 表现最好。这为选 Qwen 作基座之一提供了文献支持，而不只是"来自不同国家"。但两条限定必须写明：（一）模型排名是任务特定的，"从微观数据模仿受访者"与"从结构化输入抽权重、在多属性备选集上选择"是不同能力，排名不必迁移；（二）这不取消双基座要求，因为单基座结果无法区分"大模型在区位选择上会 X"与"某个特定模型在区位选择上会 X"。

## 11. 研究模式

### 11.1 它问什么


"大模型能否从已知偏好参数中回收偏好"这一问句已由 Kim 等人的 Simulate-Recommend-Evaluate 框架占据（他们用非线性最小二乘做参数恢复，并发现历史选择数据越多效果越好、不同模型在参数空间上偏科不同）。"人设条件化下的方差坍缩"及其跨文化维度亦已被 Distribution-First / Non-WEIRD 那一支覆盖。

因此本章的问题不是"能不能回收"，而是 1.2 的三个：伤害了谁、是否够好、坍缩与城市差异孰大。它们的共同前提是一个带货币化福利度量的产品层，而这正是上述工作在结构上不具备的。

本章仍然会做回收测试，但它的地位变了：从头条声明降级为装置验证——"我们在一个新领域复现了已知的坍缩发现"，这证明装置工作正常。复现已知结果在这里是资产而非劣势，应当主动这样叙述。

### 11.1.1 为什么 benchmark 在结构上问不出这三个问题

| **需要** | **只有产品层能提供** |
|---|---|
| **真实的偏好分布（非均匀）** | **benchmark 用均匀参数网格。若参数均匀取样，"离均值远"的人与"离均值近"的人在样本里等比例，且"远"没有现实含义，只是网格边缘。分配问题需要一个非均匀且有现实对应的分布才存在** |
| **把误差换算成福利损失的度量** | **benchmark 的真值是"最优选项的编号"，无福利含义** |
| **真实的城市与价格数据** | **benchmark 用合成属性，没有"现实"可以对照** |

缺任何一个，问题就退化回一个 benchmark 问题。

### 11.1.2 两条结构性主张（可选，视时间决定是否单独论证）

**主张一：分布保真度不是伤害的充分统计量。** 现有文献的评估单位是统计距离（KL、Wasserstein、覆盖率），而统计距离与福利损失之间没有单调关系，因为福利损失还取决于选择集的几何形状。同样的分布偏离，在"前两名几乎打平"的选择集上不造成损失，在"最优与次优差 15%"的选择集上造成真实代价。本项目有证明这一点所需的全套装置：可精确控制福利间隔的世界生成器（M3）与可货币化的效用模型（M2），因此可以构造两组世界，使分布保真度指标完全相同而福利损失差一个数量级。

**主张二：合成受访者与建议者是两种不同的失效模式。** 现有工作评估的是大模型作为合成受访者（替代问卷样本做市场研究、民调）；本项目评估的是它作为给具体个人提供后果性建议的顾问。两者对坍缩的容忍度相反：做民调要的是总体分布正确，个体误差在加总时部分抵消；做建议时每个用户吃下自己那一份误差，没有任何抵消。**坍缩对建议场景的危害严格大于对民调场景，而现有评估协议全部为后者设计。**

> 优先级：这两条主张已被 1.2 问题三的信噪比框架部分吸收。建议先不单独论证（主张一需要额外构造一组"保真度相同、福利间隔不同"的世界），等前两个问题跑出结果后，若数据自然支持，再作为讨论部分写出。

### 11.2 与产品模式的关键差异

**产品模式：一个权重向量，投到 N 座城市。** 所有代理是同一个人的不同分身。问的是"这个人该去哪"。

**研究模式：N 个不同的权重向量，投进合成世界。** 一千个代理是一千个不同的人。问的是"模型能不能读懂这些人分别是谁"。

**这个差异是硬的，不是风格选择。** 权重回收的含义是"我给了你 `w_i`，你的行为能不能让我读回 `ŵ_i`"。条件 logit 要识别参数，需要选择在个体之间有变异，且该变异由 `w` 的变异驱动。**若所有代理共用同一个 `w`，只有一个参数点，没有任何东西可以拟合，测到的全部是采样噪声。**

同一套代码，两种投放方式；差别写在世界生成器与评估层，不写在福利模型或代理层。

### 11.3 合成世界与四档难度

> ⚠ 世界生成已被 DECISIONS/0007 与 0008 修订：舒适度改为绝对锚定优先、
> 分位维离散度显式化；州税制不再独立随机分配，而是与宜居因子挂钩
> （实测 `corr(税负, 舒适度)` 从 +0.020 升到 +0.293）。后者是第四档能否
> 测到最现实的那种货币幻觉——**只看到手工资、看不见税买了什么**——的前提。

真值模拟器构建若干虚假城市，用中性标签命名（City 1、City 7），属性由生成器按配置抽样。**属性分布从真实 OEWS/RPP 标定，但实例化出的城市是虚构的**，因为若写得像真实城市，测的就是模型对真实城市的记忆而非推理。三年转移核的增长率同样从真实分布抽出、分配给虚构城市：同一份代码，不同的数据来源，M2 无需分叉。

**真实的三十个都会区只服务产品模式。** 在真实城市上跑研究模式是一个值得做的独立实验臂（测"模型在认得出的城市上表现更好还是更差"，即记忆与推断的对照），但属于 V2，且必须分开报告，不能混进主结果。

四档难度：

1. **支配型**：某城市对该类型帕累托占优。健全性检查，过不了即停项目。
2. **权衡型**：无支配关系，正确答案取决于权重。检验隐含权重是否等于注入值。
3. **精确并列型**：**求解属性值使两座城市效用精确相等。** 正确行为是群体在并列集合上均分。检验方差而非众数。
4. **对抗型**：名义工资最高的城市不是实际福利最高的城市。检验货币幻觉。**由于 3.2.1 把物质项拆成 `ln_y_net` 与 `ln_p` 两列，本档的判据从通过/不通过升级为连续量 `|coef_Y + coef_P|`。**

### 11.3.1 难度轴的定量定义：福利离散度

v0.5 的四档是定性的。1.2 问题三（信噪比）与 11.1.2 主张一都要求能够**定量指定**"这一组世界的最优次优福利差是 X%"，因为那是要扫的轴。

由 6.3.1，福利间隔由权重熵与城市属性离散度共同决定。因此世界生成器需要新增一个接口：给定目标福利间隔（或目标福利离散度），求解属性值使之达成。由 7.1.1，`ln V` 是 log 属性的线性函数，所以这是一个线性方程组而非数值求根。

### 11.4 可观测集是一个实验变量

环境本身可以泄漏答案。若 `Observable` 中直接包含三年净储蓄，而储蓄在福利中权重很大，argmax 几乎可以直接读出，对抗档会当场失效。

| 档 | 内容 | 对应现实中的什么 |
|---|---|---|
| O1 | L0 + L1。名义工资、房租、价格指数、税率、舒适度属性 | 原始统计年鉴 |
| O2 | 额外给 L2。税后可支配、三年储蓄轨迹已算好 | 一个会算账的助手 |
| O3 | 额外给用**代表性篮子**平减的实际收入 | 一个做得好的生活成本计算器 |

主问题：**随着环境给得越多，模型的偏好回收改善多少？** 三种结果都有意义：持平说明模型没在用这些数字；O2 处跳跃说明瓶颈是算术而非偏好推断；O1 就回收得好则是强结果。这直接回答了那个大多数语言模型模拟工作回答不了的问题：**模型在这个流程里究竟贡献了什么，除了把数字念一遍。**

**注：O3 与 `L_rep` 基准线的关系要说准确。** 按本节的约束，O3 必须同时保留 L0/L1 的原始属性列，因此 O3 档的模型看到的是**现状计算器的输出，加上全部舒适度属性**。这不是同一个信息条件，是严格更富的。

正因如此它是一个更好的对照，而不是更差的：`L_rep` 是"只有实际收入、机械取 argmax"的表现，O3 档是"给了同样的实际收入，再加上全部舒适度属性和一段自述"的表现。两者之差直接度量**模型在读懂舒适度权衡这件事上贡献了多少**，而这正是 1.2 问题二真正想问的东西。文档与代码中一律称其为"O3 减 L_rep 增量"，不称"同一信息条件"。

**约束**：可观测集必须张成真值参数空间。若注入七个权重而 O2 把若干属性折叠成一个数，设计矩阵秩不足，条件 logit 在数学上就无法恢复那些权重。因此 O2 与 O3 必须**同时保留 L0/L1 的原始属性列**，折叠量是附加而非替代。

### 11.5 人设的字面程度是第二个维度

若人设由真值权重套模板生成，会写出"他对气候的重视程度是 0.4"这类句子，题目退化成阅读理解。人设应当是一段人会写出来的自然语言，权重需从中推断。

字面程度本身有刻度，从"我讨厌开车、受不了冬天、想离父母两小时车程内"（需推断）到"通勤权重高、气候权重高、家庭距离权重高"（直接给出）。它与可观测集正交，两者交叉构成一张 3×3 的实验表。

类型边界的落点：数值权重在 `Persona` 里，散文在 `PersonaBrief` 里。这与 `Observable`/`GroundTruth` 是同等重要的第二组切分。

### 11.6 参考熵与离散度比

**离散度比**回答的问题是：一千个代理面对同一批城市，它们的选择**应该**有多分散？

分散度本身不含信息。全选同一座城市可能完全正确（若那座确实碾压其他），也可能是严重的坍缩（若几座其实打平）。因此需要一个"该有多分散"作分母，那就是**参考熵**：用真值模型算出理论上应有的选择分布，取其熵。

```
离散度比 = H(实际选择分布) / H(真值参考分布)
```

- 比值接近 1：分散程度恰当。
- 比值远小于 1：**坍缩**。模型没有把人设之间的差异传导进选择。
- 比值远大于 1：代理在乱选，没在读城市属性。

**σ 的问题与解决。** 真值的 argmax 是确定性的，熵为 0，比值无定义。所以真值侧需要一个概率化的选择规则 `P(选 j) ∝ exp(U_j / σ)`，而 σ 控制分布有多平，**它没有客观取值**。

**解决方式是绕开它**：第三档按精确并列构造（11.3），此时无论 σ 取多少，softmax 都给均分，参考熵恒为 `log(并列城市数)`。**σ 从主指标里消失。** 第三档因此不问"分散程度对不对"，只问"面对一个真正的平局，它们会不会集体倒向一边"，而这正是坍缩的定义。

这一条已有数值验证：精确并列时参考熵对任意 σ 恒为 log(n)；而近似并列时，σ 从 1e-5 扫到 10，熵在约 0 到 0.693 之间几乎跑满全程。也就是说，若当初选的是"近似无差异"，坍缩判定阈值就会是一个自定的数，而整个本节的结论会挂在那个数上。这是本项目第一个被数值验证过而非仅被论证过的设计决定，应写进论文的方法部分而非附录。

**σ 曲线作稳健性检查**，成本几乎为零：语言模型的选择跑一次就固定，只有分母随 σ 变，可以在不重跑任何调用的情况下解析地扫出整条曲线。最优最差法估出的尺度可作曲线上的一个标记点（注意：它测的是属性重要性的选择而非城市选择，任务不同，尺度不严格可迁移）。真实迁移流校准是最好的锚，但要等 M6。

**方向相反**：研究模式希望离散度比接近 1（模型区分了不同的人）；产品模式希望分散度接近 0（同一个人应当得到稳定答案，见 9.4）。同一个指标，两个模式下期望方向相反，读代码时切勿混淆。

### 11.7 评估指标

**指标之间有主次，不是平列。** 按 §1.2.3：协方差比是坍缩的**主证据**（识别干净），坍缩比例 `r(t)` 是**方向证据**（只能部分识别，报区间），命中率与美元损失回答的是另外的问题。写结果时不要把它们摆成一排互相印证，那会重复计数。

**命中率**：分四档难度报告，附二项分布置信区间。**它是一个一阶矩性质，无法单独用于判断坍缩，因为坍缩保留均值。**

**权重回收，用混合 logit。** 不对每个人设单独跑 logit（那需要每人十余次选择，预算撑不住）。**混合 logit（随机参数 logit）从池化数据中估出权重的分布**，即一个均值向量加一个协方差矩阵，而每个个体只需五到八次选择。个体层面的 `ŵ_i` 取后验均值（条件分布的均值），用于 1.2 问题一的 `proj_i`。

**那个协方差矩阵就是方差压缩的度量，也是坍缩的主证据**：把估出的协方差与注入的协方差比较，扣除 10.3 的基线压缩比之后，比值即坍缩系数。这正是混合 logit 被发明出来解决的问题。它之所以能作主证据，是因为两端都是已知输入（§11.7.3）。

#### 11.7.1 单纯形约束：估计必须在受约束的 6 维空间里做

`w` 落在单纯形上，`Σw = 1`。三个后果：

**其一，注入协方差的秩最多是 6，不是 7。** 若估计按七个自由随机参数进行，估出的是满秩矩阵，拿它去比一个秩亏矩阵，"比值即坍缩系数"没有定义。**实现要求：对 6 个自由维建模（固定一维作基准），或采用加性对数比（additive log-ratio）变换后估计，再变换回来。坍缩系数明确声明是在哪个空间里算的，并在两种做法上都跑一遍作稳健性。**

**其二，尺度参数被钉住了，这是一个真实的优势。** 条件 logit 通常只能识别系数与尺度之比 `w/σ`，尺度不可识别。本设定里 `Σw = 1` 是已知常数，因此尺度被这条约束定住，`w` 本身可识别。这是本项目相对于一般离散选择实验的一个结构性便利，值得在方法部分写明。

**其三，w 空间里的对角协方差是不可能的，不只是难解释。** 由 `Σw = 1` 恒成立可得 `Var(1'w) = 1'Σ1 = 0`；而任何非零对角阵满足 `1'Σ1 = Σ_k σ_kk > 0`。**因此"主设定用对角协方差"这句话与单纯形约束直接矛盾，它不是一个可以采用的设定。** v0.7 在本节先写了秩 6、两段之后又写了 w 空间对角协方差，那是自相矛盾的，v0.8 修正。

#### 11.7.1.1 可直接实现的估计设定：差分法

> ⚠ 本节那句「不要用抽象的 ALR 变换当规格」已被 DECISIONS/0011 修订：ALR 现在
> **有**可执行规格（logistic-normal：a = log(w_k/w_b)、正态、softmax 还原、
> rho = log gamma_0），作为 `alr_logistic_normal` 分支与差分法并存。差分法仍是
> **默认**，本节内容全部有效；ALR 分支是 §11.7.1 要求的第二条做法的落地。


不要用抽象的"ALR 变换"当规格，用下面这个等价且可直接喂给 `xlogit` 的形式。取第 7 维作基准维，由 `w_7 = 1 − Σ_{k=1..6} w_k` 代入：

```
ln V_c = ln κ + Σ_{k=1..7} w_k · x_{k,c}
       = ln κ + x_{7,c} + Σ_{k=1..6} w_k · (x_{k,c} − x_{7,c})

logit 效用（含不可识别尺度 σ）：
U_c/σ = 常数 + (1/σ)·x_{7,c} + Σ_{k=1..6} (w_k/σ)·(x_{k,c} − x_{7,c})
```

于是设计矩阵是 **7 列**：一列基准维原值 `x_7`，六列差分 `x_k − x_7`。

| 列 | 系数 | 规格 |
|---|---|---|
| `x_7`（原值） | `γ_0 = 1/σ` | **固定参数，不设为随机** |
| `x_k − x_7`（k=1…6） | `γ_k = w_k/σ` | 随机参数，**对角协方差，6 个方差项** |

反解：`σ = 1/γ_0`，`w_k = γ_k/γ_0`（k=1…6），`w_7 = 1 − Σ w_k`。

三条要点：

- **这就是 `Σw = 1` 钉住尺度的具体机制。** `x_7` 的系数在真值里恰好是 1，所以它在 logit 里的系数就是 `1/σ`，尺度因此可识别。这不是一个论证，是一个可以在代码里读出来的数。
- **`γ_0` 必须设为固定参数。** 若它也随机，`w_k = γ_k/γ_0` 就是两个正态之比，分布不再可控。设为固定等价于假设尺度 σ 在个体间相同，这是标准假设，但必须写明。
- **简约性落在估计空间里。** 六个随机系数加对角协方差只有 6 个方差参数，配每人五到八次选择是可行的。若在七维 w 空间里估 21 个自由参数，简约性就没了。

#### 11.7.1.2 逐维压缩作为派生量

在 γ 空间估出 `Σ_γ`（6×6 对角）后：

```
Σ_w(6×6) = Σ_γ / γ_0²
扩展到 7×7：Var(w_7) = 1'Σ_w 1 ，  Cov(w_7, w_k) = −Σ_j Σ_w[k,j]
```

得到的 7×7 矩阵秩为 6，带单纯形诱导的负相关，**这是合法的**。取其对角线，与注入协方差的对角线相比，即"每一维被压缩了多少"。解释保住了，而且定义是良好的。

参数计数核对：七维对称阵 28 个自由参数，受 `Σ1 = 0` 的 7 个约束后为 21，等于六维对称阵的维数。

#### 11.7.1.3 基准维的选择是一个自由度，必须做稳健性

差分法（以及任何 ALR 类变换）**不是等距变换**：γ 空间里的"对角"依赖于选哪一维作基准，换一个基准维就是换一个模型。因此至少跑两到三个不同基准维，报结论是否翻盘。建议至少包含物质维 `w₁` 与一个舒适度维，因为二者的方差量级差别最大。

完全协方差（在 γ 空间里估 21 个参数）作稳健性对照。若与对角设定结论不一致，以对角设定为主结果并报告差异。

#### 11.7.2 估计量自身的偏差必须先扣掉，而且它作用在两个地方

见 10.3。MSL 混合 logit 即使设定正确也有偏，方差与相关性部分尤甚。但收缩是**估计器的性质**，因此它同时作用在两个量上，两个都要扣：

| 受影响的量 | 表现 | 地板来源 | 扣除后是否可识别 |
|---|---|---|---|
| 协方差比 | 估出协方差在真值数据上就已经小于注入协方差 | 10.3 的基线压缩比 | **是**（见 11.7.3） |
| 个体后验均值 `ŵ_i`，进而 `proj_i` | `ŵ_i` 被拉向 `ŵ_center`，`proj` 对 `d` 的斜率在真值数据上就已经等于 `λ > 0` | 10.3 的 `λ` | **否，只能部分识别**（见 1.2.2） |

**两条地板由同一批合成数据一次跑出，成本不增加。** 未扣除的原始值一并列出，但不作为结论。

**最后一列是 v0.9 的核心结论**，它决定了 §1.2.3 的指标分工：协方差比扣完地板就干净了，`proj` 扣完地板还剩一个自由度（地板臂该用哪个 `Σ_pop`），所以后者只能给区间。

#### 11.7.3 为什么协方差比识别得干净

自检时注入已知的 `Σ_true`，估出 `Σ̂`，得到基线压缩比 `Σ̂/Σ_true`。匹配臂里 `Σ_true` 是人设分布的协方差，而 §11.9 已裁定人设权重按 Dirichlet(α=0.5) 抽样，**Dirichlet 的协方差有闭式解**（数值见 §1.2.3），因此它是一个可以写下来的常数，不是估计量。两个比值在同一个 `Σ_true` 上直接可比。

**对比 `proj`：它需要知道估计器实际看到的 `Σ_pop`，而那是拟合的输出，不是可以设定的输入。** 这就是全部区别。

> **一条值得记住的教训**：把权重抽样分布从"待定，若 OECD 可得则改用真实分布"改成"Dirichlet(α=0.5) 已裁决"（v0.7→v0.8），直接后果是注入分布的协方差从未知量变成了闭式已知量，而那正是协方差比可以干净识别的全部原因。**裁决会创造识别**，不只是减少不确定性。每次把一个量从"待定"改成"已裁决"，都值得回头检查有哪些原本不可识别的东西因此变得可识别了。

#### 11.7.4 不确定性传播：用 bootstrap，不用 delta 方法

由 §11.7.1.2，`Σ_w = Σ_γ / γ_0²`，`ŵ_i = γ_i/γ_0`。分母含估计量，误差被放大。三条：

**其一，最麻烦的不是 `Σ_w`，是 `ŵ_i = γ_k/γ_0`。** 比值估计量在分母接近零时不存在有限矩，而 `γ_0 = 1/σ` 接近零意味着选择接近随机。这与门二是同一个情形，见 §10.3.3。

**其二，若用 delta 方法，必须带上 `Cov(γ_0, γ_k)`。** 它们是同一次拟合的输出，不独立。对 `f = γ_k/γ_0`：

```
Var(f) ≈ (1/γ_0²)·Var(γ_k) + (γ_k²/γ_0⁴)·Var(γ_0) − 2·(γ_k/γ_0³)·Cov(γ_k, γ_0)
```

第三项常与前两项同量级，漏掉它是常见错误。

**其三，直接上 bootstrap，跳过 delta。** 理由是 `w_7 = 1 − Σ_{k=1..6} w_k` 这一步：七维协方差矩阵里所有涉及第 7 维的元素都是六个比值的线性组合，delta 要再传播一层，代数难以核对。而最终要报的量（坍缩比例、`r(t)` 曲线、逐维压缩比）全是这些量的非线性函数，每一个都得单独推。

```
按人设做块自助（block bootstrap：重抽人设，不重抽个体内的选择），
把整条评估流水线跑 200 到 500 次，所有量的置信区间一次出来，
包括 r(t) 曲线的逐点置信带。
```

**重抽人设而不是重抽选择**，因为个体内的选择不独立（它们共享 `w_i`），重抽选择会低估方差。

这一步零大模型调用，只花 CPU。delta 方法留作一次交叉验证，验 `Σ_w` 那一层就够了。

文献锚点：这在市场营销学里有一个名字——部分效用异质性的恢复（recovery of partworth heterogeneity），Lenk、DeSarbo、Green 与 Young 1996 年发在 Marketing Science。整个联合分析领域三十年就是在做"从选择数据里恢复个体异质性"，标准工具正是分层贝叶斯与混合 logit。这让本节从"我想了个办法"变成"我用了这个领域的标准方法"。

> 待办的文献检索：在写方法部分之前，搜 `LLM conjoint`、`synthetic respondents conjoint`、`LLM discrete choice experiment`，确认"用大模型做联合分析并检验异质性恢复"这个具体位置的占用情况。

**离散度比**：见 11.6。**必须与命中率分开报告**，不得合成单一分数。

**福利损失（主指标）**：`EV(真值最优) − EV(模型推荐)`，美元/年，一律在真值偏好参数下评价（见 9.1.1）。分难度档报分布而非仅报均值，因为 1.2 问题一关心的正是它的分布。**同时报归一化版本 `福利损失 / welfare_range`**，用于剥离赌注差异。

**信噪比（新增）**：`Var_across_cities(福利) / Var_from_collapse(福利损失)`，并按选择集的福利离散度分组报告，以确定适用边界阈值 τ。

**坍缩比例（方向证据，见 §1.2.3 的分工）**：

> ⚠ 本段的公式已被 DECISIONS/0002 推翻并替换，见该记录（§1.2.2 处已有同一条
> 指针，此处补上）。现行式为 `r = (ŝ_matched − λ̂)/(ŝ_shuffled − λ̂)`：分母改用
> **打乱臂的实测斜率**。理论值 `1` 未被 `ŵ_center` 的估计误差衰减，而分子两项
> 被衰减，量纲不一致，旧式在中等测量误差下低估坍缩四成。理论值 `1` 降为诊断。
> 下面这段保留原文，仅作历史对照，**不得照此实现**。

```
d_i    = ‖w_i − ŵ_center‖
proj_i = ⟨ ŵ_i − w_i , (ŵ_center − w_i)/‖ŵ_center − w_i‖ ⟩

坍缩比例 = (slope_matched − λ) / (1 − λ)      ← 已作废，见上方指针
```

其中三条斜率来自 `proj` 对 `d` 的回归：`λ` 来自 10.3 的地板臂（纯收缩），`1` 是打乱臂的理论天花板，`slope_matched` 是实测。完整推导与三点标尺见 1.2.1 与 1.2.2，此处只列实现要点：

- `ŵ_center` 取混合 logit 的均值向量，`ŵ_i` 取个体后验均值。
- **`proj_i` 的零点不是 0**，而是 `λ·d_i`。收缩是估计量的性质，不是模型的性质。
- **它只能部分识别，因此报 `r(t)` 曲线而非点估计**（§1.2.2）。地板臂的 `Σ_pop` 是那个打不开的自由度。
- **地板臂的 σ 从 11.8 的重复子集标定**，不从匹配臂的 `1/γ_0` 读（§10.3.1 解释了为什么后者是错的）。
- **若 §10.3.4 的检验显著，改用 `r(d)` 逐点版本**，单一斜率公式在那种情况下没有对应的总体量。
- **打乱臂是天花板，不是零假设**，在 `proj_i` 与美元福利损失两条曲线上都是。
- 报告在斜率上做，不在个体上做差。
- `1 − λ` 是测量窗口，由 10.3 在花预算之前先测出来。

"谁"的人口学解释依赖 5.1 的真实偏好分布；按 5.1 的三条限定，它现在是对照臂。若拿不到，本项仍完整成立，只能说"偏好偏离中心者受损更大"，说不出那是哪一类人。

### 11.8 重复子集是主指标的载重输入，有四个消费者

离散度比的分子里同时含有"模型对人设差异的响应"与"采样噪声"。两者不分开，比值就无法解释：一个高的离散度可能是模型很好地区分了不同的人，也可能是它在乱选。

**同一人设重复多次得到的选择分散度，就是纯采样噪声的估计。** 有了它才能把总离散度拆成响应与噪声两部分。

**v0.9 起，它有四个消费者，规模因此从 50 个人设扩到 150：**

| 消费者 | 用途 | 出处 |
|---|---|---|
| 离散度比 | 把总离散度拆成响应与噪声 | 本节 |
| 产品模式的区间校准 | 校准三年模拟的离散区间宽度 | §8.3.1 |
| **地板臂的 σ 标定** | 给 10.3 的地板臂提供一个不含设定误差的噪声估计 | §10.3.1 |
| **λ 的 `d` 依赖检验** | 人内不一致度对 `d_i` 回归，决定用 `r` 还是 `r(d)` | §10.3.4 |

**为什么它能干净地隔离噪声**：同一人设同一世界重复多次，模型**稳定地**读错会在重复间保持一致（那是坍缩，不是噪声），模型读得**不稳**才会在重复间分歧。设定误差是系统性的，同样在重复间稳定，因此也不进这个估计。**这正是它比 `σ̂ = 1/γ_0` 干净的原因。**

**为什么要扩到 150**：50 个人设估一个标量勉强够，估一条随 `d_i` 变的曲线不够。而 §10.3.4 的检验若显著，λ 就是 `d_i` 的函数，那时需要在 `d` 的各段上都有足够的重复。成本约增总预算 5%。

**限定（不得省略）**：重复子集测的是同一人设同一世界跨次运行的分歧，logit 的 σ 测的是备选项间的特异误差，两者相关但不同一。用前者标定后者是校准启发式，不是恒等式。

### 11.9 实验规模与预算

> ⚠ 本节的抽样分布已被 DECISIONS/0006 推翻，见该记录：**物质维 α₁ = 1.5，
> 六个舒适度维保持 0.5**，不再是对称的 Dirichlet(α=0.5)。稀疏性由 Dirichlet
> 的中性性质保证不变。连带两处：注入协方差的对角线不再是常数（闭式解在
> `worlds.personas.dirichlet_covariance()`）；注入均值是 `[1/3, 1/9×6]` 而非
> `1/7`，因此 11.9.1 的分层变量须显式传注入均值。


**主实验**：一千个不同人设，各跑一次，混合 logit 估协方差。这直接回答坍缩问题，**不需要任何重复**。

**重复子集**：从中取 **150** 个人设，各多跑 3 次。v0.8 是 50，v0.9 扩容，理由见 11.8：它现在有四个消费者，其中两个（地板臂 σ 标定、λ 的 `d` 依赖检验）是主指标的载重输入。

#### 11.9.1 人设抽样必须分层，且分层变量不能是 `d_i`

> ⚠ 本节推荐的 `‖w_i − 1/7‖` 已被 DECISIONS/0006 修正为 `‖w_i − 注入均值‖`。
> 原理由是"无坍缩时 `ŵ_center` 收敛到 `1/7`"，非对称 Dirichlet 下它收敛到
> `[1/3, 1/9×6]`。约束本身没松动：注入均值是设计选择，跑之前定死，仍然
> 事前可算。


**为什么要分层**：`proj` 对 `d` 的回归，其杠杆点在 `d_i` 的两端。而 Dirichlet(α=0.5) 的几何使这个问题比一般情况更严重：α<1 把质量堆在单纯形的面和棱上，但"离中心远"在 7 维单纯形上是一个薄壳，简单随机抽样落进最外层的比例很低。极端偏好的人太少，回归线就无效。§10.3.4 的 `r(d)` 分箱同理。

**分层变量不能是 `d_i`**，因为 `d_i = ‖w_i − ŵ_center‖` 依赖 `ŵ_center`，而那是跑完才有的。必须用一个**事前可算**的代理量：

```
推荐：到单纯形中心的欧氏距离  ‖w_i − 1/7‖
备选：权重熵 H_norm(w_i)      （P6 已实现）
```

用前者更直接：若模型不坍缩，`ŵ_center` 收敛到分布均值，而 Dirichlet(0.5) 的均值正是均匀向量 `1/7`。

**分层与 `r(d)` 的分箱用同一套层**，这样每箱的样本量由设计保证而不是碰运气。两件事一起定，不要各定各的。

#### 11.9.2 分层之后，报告必须区分加权与不加权

分层抽样改变了样本的边际分布：外层被过采样后，样本里"不寻常的人"的比例不再是 Dirichlet 的真实比例。因此

| 结论类型 | 例子 | 是否加权 |
|---|---|---|
| **人口层面** | "中位用户每年损失 X 美元" | **必须用抽样权重还原** |
| **条件层面** | `proj` 对 `d` 的斜率、`r(d)` 曲线、按 `d` 分组的损失 | **不加权**（本来就是条件量） |

两类结论会在同一份结果里并存，极易搞混。**实现要求：在代码里做成两个显式的报告函数（例如 `report_population()` 与 `report_conditional()`），不要靠调用时传一个 `weighted=True/False` 参数决定。** 参数式的接口在半年后会被误用。

**对 M3 的接口约束**：**人设轴与世界轴必须正交。** 世界生成器要支持"同一批人设投放到多个世界实例"，而不是一次性生成一批（人设, 世界）配对。

**人设权重的抽样分布**：**Dirichlet(α=0.5) 为主实验分布**，依据见 6.3.1：α=0.5 产生稀疏、有主导维度的低熵权重，而低熵正是个人化有收益、因而福利损失可被观测的区域。

**真实偏好分布作对照臂，不作主臂。** 这一条相对 v0.6 反转，理由见 5.1：OECD BLI 的用户权重用 0–10 评分量表抽取（正是 6.3 明确拒绝的形式，且其尺度使用偏差在跨国样本里是系统性的），全部维度默认值为 5，因此经验分布在均匀向量附近有一个巨大尖峰，而均匀向量正是福利损失观测不到的区域。用它作主臂会把主实验的信号压掉。

两臂对比本身仍有信息量：它衡量的正是"用 Dirichlet 评估"与"用真实分布评估"给出的结论差多少。但方向是拿对照臂检验主结论的稳健性，不是反过来。

**若真实分布拿不到**，主实验不受影响，损失的只是问题一的人口学解释层。

**打乱人设臂（按 11.10.1，已升为主实验的一部分）**：取主实验人设与世界，只重排配对，规模为主实验的 30%，即 300 个代理运行。它是问题一的完全坍缩天花板（见 11.10.1），不是可选附表。

**成本量级**：约 1750 个代理运行（1000 主 + 450 重复〔150 人设 × 3 次〕 + 300 打乱）× 4 档 × 2 基座 ≈ 14,000 次运行，每次 2 至 3 次调用，**约 36,000 次调用**。相对 v0.8 的 30,000 次增加约两成，增量全部来自重复子集扩容（11.8）。

**不进这个预算的两项**：10.3 的自检（零大模型调用，只花 CPU）与 11.7.4 的 bootstrap（同上，200 到 500 次重跑评估流水线）。它们省下的是"跑完主实验才发现指标测不出来"的那笔钱。

参照系：Agentopia 单次十年模拟消耗约 137 亿 token、约 56.7 万次调用、约 186 小时墙钟时间，输入 token 占绝对主导，且论文指出记忆增长是长时程模拟的主要计算瓶颈。本项目因此采取无记忆流、无多轮对话、每代理每年常数次调用的设计，量级低三个数量级。

### 11.10 三个对照组，其中一个是主结论的天花板

- **属性置换**：互换两城属性、保持标签，看答案跟属性走还是跟标签走。
- **无人设**：不给人设，测基线选择。
- **打乱人设**：人设与真值权重随机错配。若打乱组与匹配组选出同样的城市，说明人设根本未起作用。

#### 11.10.1 打乱人设臂是完全坍缩的天花板，不是零假设

v0.5 把三个对照组并列为健全性检查；v0.7 误把打乱臂当成问题一的零分布。**v0.8 修正：它是天花板。**

打乱之后代理 i 读到的是人设 j 的散文，因此它的选择反映 `w_j`，而 `w_j` 与 `w_i` 独立同分布、均值为 μ。于是它的误差期望是 `μ − w_i`，**最大程度指向中心**，而不是方向随机。这有两个后果：

- 在 `proj_i` 上，`E[proj_i] = d_i`，即天花板（推导见 1.2.1）。它不是 0。
- 在美元福利损失上，它同样是天花板而不是"方向随机"的基线。指向中心的误差在同等模长下比各向同性的误差代价更大，因为对低熵、有主导维度的人来说，指向中心意味着压低那个主导维，而那正是最伤人的错误。

因此匹配臂在两条曲线上都应当**低于**打乱臂，结论是匹配臂离天花板还有多远。

**地板在 10.3，不在这里。** 三点标尺见 1.2.1。

**规模要求**：打乱臂必须与主实验用**同一批人设、同一批世界**，只重排配对；样本量不得低于主实验的 30%，否则天花板的估计噪声会淹没两条曲线之差。

**实现约束**：打乱是配对层的操作，不重新生成人设也不重新生成世界。记录置换，使打乱臂与匹配臂逐一可配对，从而可以做配对检验而非两独立样本检验。

**不要把打乱臂挪去当协方差比的天花板。** 打乱只重排配对、不改变人设总体，因此各臂的总体离散度是一样的，被破坏的只有 `ŵ_i` 与 `w_i` 的对应关系。混合 logit 估出的**总体协方差在两臂里应当接近**。打乱臂对 `proj_i` 与美元损失是天花板，对 11.7.2 的协方差比什么都不是。这条容易在实现时被顺手复用，写死在这里。

## 12. 已知边界

- **无一般均衡。** 代理在城市内的行为不改变房租与工资，二者按外生路径演化。
- **模拟数据不能识别因果。** 从自生成数据中跑出的任何断点或工具变量结果，恢复的都是写入转移核的假设。因果方法的三个合法位置是：转移核参数的估计（输入端）、与外部估计的对照（验证端）、结论对参数的敏感性（稳健性）。
- **弱交互则弱分化。** Agentopia 第 D.7 节报告基尼系数均下降、未观察到马太效应，原因是代理间无直接经济互动，初始优势没有复利通道。
- **标度函数是自由参数。** 在产品模式下它是一个实质性建模主张，须报告稳健性对照。
- **Cobb-Douglas 断言公共服务与私人消费的替代弹性恒为一。** 这不是一个可以标定的参数，是函数形式本身的推论（DECISIONS/0009）。它的**跨国方向性后果**要写进任何跨国结论：在真实的 σ<1 下，公共服务从"差"到"中等"的效用增益远大于 Cobb-Douglas 给出的增益，所以本模型系统性地低估公共服务水平低的地方的痛苦、同时低估高福利体制的收益，任何跨国排序都偏向低税低服务的一端，偏离幅度随两国公共服务差距扩大。连带两条：`environment` 维没有理想点（气候不是"越暖越好"，人有理想温度，框架表达不了单峰偏好）；`A → 0 ⟹ V → 0`（任一维趋零则整城归零，无论其他维多好）。V1 不改函数形式，改的是它的地位——从"已裁决"移到这里。
- **研究模式固定职业。** 职业在产品模式里是必需的（决定各城市的预期工资，OEWS 的"职业 × 都会区"交叉是 §5.1 的核心数据主张），但在研究模式里是混淆变量：研究问题是能否回收**偏好**，职业带来的工资向量差异与偏好无关，只稀释信号。主臂内职业不变异。若要问"模型对某些职业更差吗"，那是独立实验臂，届时职业是处理变量而非噪声（DECISIONS/0009）。
- **商品可得性维度未覆盖。** 纯价格指数无法捕捉商品品种与组合差异（Handbury 2021）。
- **跨国的福利水平比较是分级可行的**，取决于城市集合的字段等级与用户权重覆盖率（5.5 至 5.8）。
- 被丢弃的维度是不知道，不是没差别。
- **偏好分布是 Dirichlet，不是真实人群。** 主实验的权重从 Dirichlet(α=0.5) 抽样，它有原则性依据（6.3.1）但不是任何真实人群的分布。因此问题一的结论形式是"偏离中心者受损更大"，而"那是哪一类人"需要 5.1 的真实分布，后者的可得性与口径均未证实（见 5.1 三条限定）。
- **坍缩系数受估计量偏差污染，只能扣除不能消除。** MSL 混合 logit 即使设定正确也有偏。10.3 给出基线并扣除，但扣除本身依赖基线估计的准确性，剩余误差无法进一步分离。
- **`ŵ_center` 是估计量。** 它同时出现在 `d_i` 与 `proj_i` 里，其误差在 `d_i` 上表现为自变量测量误差（衰减偏误），在 `proj_i` 上表现为投影方向的抖动。两者都做敏感性，但都不可消除。
- **坍缩比例的两端都是估计出来的。** 地板 λ 来自自检的合成数据，天花板来自打乱臂，两者各有抽样误差，且分母 `1 − λ` 在 λ 接近 1 时放大误差。因此必须报三条斜率各自的置信区间，而不只是比例的点估计。
- **基准维的选择是一个未被真值决定的自由度。** 差分法在 γ 空间里的对角协方差假设依赖于选哪一维作基准（11.7.1.3）。只能靠多基准维稳健性覆盖，不能消除。
- **`proj_i` 只测"指向中心"这一个方向。** 与该方向正交的回收误差不进入这个统计量。若模型的失败模式不是向中心压而是别的（例如系统性高估某一特定维），`proj_i` 抓不到，需要看完整的 `ŵ_i − w_i` 分解。
- **`proj_i` 只是部分识别的，这是本项目最硬的一条边界。** 地板需要知道估计器看到的 `Σ_pop`，而坍缩本身就是压缩 `Σ_pop`，循环无法打开（1.2.2）。只能报 `r(t)` 区间与翻号点，不能报点估计。因此坍缩的主证据是协方差比，`proj` 只作方向证据。
- **`proj` 与协方差比机械耦合，不是两次独立测量。** Σ 被压小会加剧个体估计的收缩从而抬高 `proj`，所以后者部分地重复计入了前者已经说过的话。结果部分必须明写这一条。
- **地板臂的 σ 是标定出来的，不是测出来的。** 重复子集测的是跨次运行的分歧，logit 的 σ 测的是备选项间的特异误差，两者相关但不同一（10.3.1）。这是一个校准启发式，其误差不可消除，只能靠 `λ(σ)` 曲线呈现敏感性。
- **分层抽样使人口层面的陈述依赖于权重还原的正确性。** 若权重算错，"中位用户损失 X 美元"这句话就错，而条件层面的结论不受影响（11.9.2）。
- ** 享乐适应 V1 不实现**，因为在固定投放设定下参照点无从定义，常数参照点在 argmax 里完全抵消，故不可识别。V2 迁移机制落地后再加（见 7.5.1）。
- **标准化之后仍剩余的住房质量差未被覆盖。** 例如"这个都会区里，多少钱都买不到通勤半小时内的独栋"。这与商品可得性是同一类局限：纯价格指数抓不住品种与可得性。V2 的标志户型机制（把"两居 / 1980 年后 / 户内洗衣机 / 通勤 30 分钟内"当作一个标准包跨城市定价）是 6.4 标志商品的住房版。**
- **合成人设与真实用户自述在文本分布上不同。** 有证据表明原始的真实材料作为输入优于模型生成的叙事，而本项目研究模式的人设正是由真值权重生成的自然语言。方向尚不确定（合成人设可能更容易，因措辞规整信息密度高；也可能更难，因缺乏真人特有的具体细节），但无论哪个方向，**研究模式的回收表现是对产品模式的间接证据，不是直接证据**。补救：等有二十个以上真实用户的自述加量表结果，跑一次小规模对照，看同一模型在真实文本与合成人设上的回收误差是否可比。二十个样本不足以做统计，但足以发现方向性的巨大差异。**
- **产品模式的坍缩暴露面有两处**：自由文本通道（受 8.2.1 的 ±10 分上限约束）与三年模拟的离散区间宽度（受 8.3.1 的校准约束）。确定性推荐路径本身不受坍缩影响。**

## 13. 与已有工作的关系

> 完整引文、每篇一句话的内容摘要、以及本项目与其差异，见 `RELATED_WORK.md`。本节只保留对架构有直接影响的三条。

**AgentSociety**（Piao 等）：本项目采纳其环境设计原则、三类干预的术语（模拟前配置、模拟中状态操纵、消息触发），以及 survey 与 interview 的分工。其移动模块中"由语言模型抽取意图、由重力模型完成地点选择"的分层设计，是本项目代理层的直接范式来源：语言模型不逐一比较所有城市，而是输出效用估计，由闭式的 softmax 选择层完成选择。

**Agentopia**（Wang 等）：本项目采纳其硬账本式经济系统、价格参考表机制、以及排序后重标定的评分方法；不采纳其由语言模型充当环境模型裁决数值结果的做法，也不采纳其存量式的享乐适应（见 7.5.1），因为本项目的 `A_k` 是城市属性而非存量。

**Homo Silicus**（Horton、Filippas、Manning）：为"用模拟代理研究经济行为"提供范式合法性，并为本项目 3.1.1 的分层提供文献授权（定性方向可用、个体定量不可用）。项目命名亦源于此。

当前状态：M0 至 M3 已完成（对照 v0.5 规格）。M2 的核心数学与 M3 的世界与人设生成器已落地，harness（类型边界、单次计入记账、泄漏扫描、精确并列与熵的数值验证）已就位。

下一步是 M4（代理层），但在此之前有一批对已完成模块的修补，见 `PLAN.md` 的"v0.7 迁移说明"。其中四项是阻塞性的：

1. **5.2.2 的 CEX 份额内生性**。若 M2 当前按城市查表，这是必须先修的 bug。
2. **3.2.1 的 `GroundTruth` 字段扩展**，含新增的 `welfare_range`。1.2 三个问题全部依赖它。
3. **9.1.1 的三条零调用基准线（`L_rep` / `L_s` / `L_amen`）**。它们不需要 M4，应当在写代理层之前就跑出来：若 `L_rep` 很小，产品前提就弱了，那是必须在投入 M4 预算之前知道的事。
4. **10.3 的两条地板（协方差基线压缩比、`proj` 的 λ 曲线）与单纯形秩检查**。它决定 11.7 的坍缩系数与 1.2 的坍缩比例怎么报，必须早于任何大模型调用。

**两个停止门都在 M4 之前判定，任一不过就停下来重新考虑，不要先开跑再说：**

| 门 | 判据 | 位置 |
|---|---|---|
| 产品前提 | 在任何福利离散度高于 τ 的选择集上，`L_rep` 中位数是否超过 9.3 的噪声地板 | 9.1.1.1 |
| 测量窗口 | 在**从重复子集标定出的** σ 上是否 `λ ≤ 0.8` | 10.3.1、10.3.3 |
| 公式前提 | 人内不一致度对 `d_i` 的回归是否显著；显著则 M5 必须实现 `r(d)` 曲线版本而非单一 `r` | 10.3.4 |

门二与"公式前提"这一条**共用同一批重复子集数据**，因此必须一起跑、一起判。这也意味着**重复子集要先于主实验跑**，而不是跟主实验一起跑：它现在是门的输入，不是主实验的副产品。
