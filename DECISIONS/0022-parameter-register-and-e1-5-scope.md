# ADR0022：参数与假设登记，以及 E1-5 的最小范围

- 日期：2026-10-08。
- 状态：所有者已明确采纳的文档规则与设计范围；E1-5 代码尚未实现。
- 依据：所有者要求整理合成环境、现实数据抽象、代理认知及 V2 预留参数，未来用独立研究确定数值；V1 不追求最大程度还原现实。
- 入口：[README（存档）](../docs/history/pre-readme-split-2026-10-26/README.md#governance)、[PLAN](../PLAN.md)、[参数与假设目录](../docs/design/parameter-assumption-register.md)。

## 1. 一份目录，区分不同性质的参数

使用 `docs/design/parameter-assumption-register.md` 作为长期维护的超参数附录。记录连续数值、离散规则、映射方式、代理得到的信息和必要的中间变量；按环境、数据映射、用户输入、认知条件、评价、实验设计、数值计算区分。

真实价格、税档、用户明确偏好不是可以任意优化的自由参数；单位换算与账目守恒也不能为改善拟合而调整。合成数据值可以用于情景实验，但不能因此被称为现实估计。文档登记不等于配置字段或优化程序已经存在。

今后新增或改变这些内容，必须在同一轮更新目录：稳定 ID、直观含义、单位/范围、当前值或未定状态、代码/配置位置、数值依据、可见性、阶段、受影响人群与验证办法。实际实验保存完整配置和版本；不改写历史 runs。改变规则仍按已有 ADR 与经济代码授权约定处理。

## 2. 疾病规则与代理认知分开

环境内可以用年龄与历史工作相对负担生成疾病情景；默认不主动向分身披露模拟器设定的疾病—工作负担关系，包括定性方向、系数和概率表，也不提前透露实际随机事件。定性风险提示也应作为显式选择的信息条件，不是默认随观察附带。

公开行动所需时间、每小时负担、当前额度和已发生的生活事实，继续沿用 E1-4 的许可规则。知道一份工作很累，不等于知道模拟器用什么概率函数生成疾病。

信息披露程度、风险信念和风险偏好分别登记。将来可设研究条件或由用户显式选择模拟条件；选择改变代理信息/假设时，不自动改变环境真实风险。隐藏字段不能消除 LLM 的已有常识，也不证明它真的相信某种概率。现阶段不建立复杂的心理模型；接口与最小默认条件在 E1-5 风险轮实现。

## 3. 培训、技能与职业必须相关

V1 使用少量明确资格或技能，显式对应岗位要求。会计证不能自动提升无关的软件开发岗位；是否有帮助由具体岗位的任务与要求决定，不按“互联网公司”这样的行业名称一刀切。

培训可授予证书，也可增长具体技能（如一门编程语言、公司特定的人事制度知识）。除声明的费用外，学习必须占用明确的额外时间与负担；同一小时不能既算完成原工作，又当作额外学习。资格来自实际完成，薪酬来自实际取得并执行的岗位；不默认通用技能点、自动涨薪或无限可迁移的公司知识。

## 4. 储蓄不另加“安心分”

删除“有积蓄让我安心”作为独立效用机制的候选。本次没有发现已经实现的对应评分公式，因此不涉及删除生产代码。储蓄通过未来消费/培训、应对冲击和 E1-6 的期末评价发挥作用；不再单设一个可能重复计分的心理奖励。

## 5. E1-6 保留所有者的聚合问题

“完成者平均分不能代表原计划全体”登记为 E1-6 明确待裁决项，所有者将提出处理思路。必须保留原计划人数、完整者、生活出局、缺分/反馈受阻、输入或资料错误、程序错误及未运行者。记录部分轨迹，不擅自给剩余期间补零、剔除、重新归一化或代定最终估计方法。

## 6. V1 与 V3 的分工

E1-5 分小轮推进：相关培训/技能与岗位；储蓄用途；少量疾病与应急情景。此分轮只是实现顺序，不新增正式研究结论，不要求 V1 先完成参数标定、细粒度排班、招聘市场或心理模型。

V3 可以研究启发式搜索、模拟校准等方法；先规定外部目标、可调整参数、固定锚点、留出验证与群体误差报告。不得通过修改裁判参数专门提高被测 LLM 的本项目得分，再把该提高解释为模型更懂用户。无法从数据区分的参数保留范围，不宣称获得唯一真值。

本次只改文档，不修改任何运行代码、配置、测试或历史产物。参数目录是解释与登记入口；当前运行值以对应版本配置/代码为准，正式裁决遵循 README 的文件分工。
