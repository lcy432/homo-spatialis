# 0002 坍缩比例的分母用打乱臂实测斜率，`d` 与 `u` 三臂共用

**状态**：已采纳（v0.9 迁移期，替代 README §1.2.2 的公式形式）
**落点**：`src/eval/`（M5）｜**对应硬规则** 23、24

## 决定

```
r = (ŝ_matched − λ̂) / (ŝ_shuffled − λ̂)        ← 不是 (ŝ_matched − λ̂)/(1 − λ̂)

d_i 与 u_i 只算一次，用匹配臂的 ŵ_center，三个臂原样共用。
```

## 问题

`ŵ_center` 是估计量。它的误差 δ 同时进入自变量 `d_i` 与因变量 `proj_i`
（`u_i` 也是用它算的），把三条实测斜率都往下压。而旧公式

```
r = (s − λ) / (1 − λ)
```

分母里的 `1` 是**理论值，没被压**，分子里两项是**实测值，被压了**。量纲不一致，
`r` 因此有偏，且偏向低估坍缩。

## 数值验证

注入 λ=0.45、s=0.72，真值 r=0.4909，4000 个 Dirichlet(0.5) 人设：

| δ 尺度 | `ŝ_floor` | `ŝ_matched` | `ŝ_shuffled` | 旧公式 | 新公式 |
|---|---|---|---|---|---|
| 0.00 | 0.449 | 0.719 | 1.000 | 0.4899 | 0.4895 |
| 0.03 | 0.436 | 0.698 | 0.969 | 0.4642 | 0.4909 |
| 0.06 | 0.395 | 0.631 | 0.877 | 0.3907 | 0.4901 |
| 0.10 | 0.326 | 0.523 | 0.725 | **0.2914** | 0.4920 |

中等测量误差下旧公式低估四成。

## 为什么它消得掉——理由比"经典变量误差"更强

经典 EIV 只覆盖"回归元被测错"。这里 δ 同时污染自变量与因变量，**不是经典 EIV**。
但结论仍然成立，推导如下。设 `v_i = μ − w_i`（真实偏移），`ṽ_i = v_i + δ`，
则 `d_i = ‖ṽ_i‖`、`u_i = ṽ_i/d_i`。注意

```
⟨v_i, u_i⟩ = ⟨ṽ_i − δ, ṽ_i⟩ / ‖ṽ_i‖ = d_i − ⟨δ, u_i⟩
```

某一臂的位移是 `ŵ_i − w_i = c·v_i + 噪声`（`c` 是该臂真实的"向中心拉"的强度），
于是

```
proj_i = c·( d_i − ⟨δ, u_i⟩ ) + ⟨噪声, u_i⟩

slope  = c · [ 1 − Cov(⟨δ,u⟩, d)/Var(d) ]  ≡  c · b
```

**`b` 只依赖 δ、`u`、`d`。** 三者若不随臂变化，`b` 就是三臂共用的乘性因子：

```
ŝ_matched = b·s ,  λ̂ = b·λ ,  ŝ_shuffled = b·1

(b·s − b·λ) / (b·1 − b·λ) = (s − λ)/(1 − λ)
```

## 因此硬规则 24 不是便利条件，是前提

"`d` 与 `u` 只算一次、三臂共用"是让 `b` 三臂相同的**唯一**办法。各臂各估各的
中心，`b` 就不同，消不掉，新公式和旧公式一样有偏。

语义上也更对：要问的是"匹配臂是否比一个理想估计器更把人往**匹配臂的那个
中心**推"，方向应当由被研究的对象定义一次。

## 连带的三处变化

**其一，λ 本身变得可以去衰减。** `λ̂ = b·λ` 而 `ŝ_shuffled = b`，所以
`λ_去衰减 = λ̂ / ŝ_shuffled`。上表 δ=0.10 那行：0.326/0.725 = 0.450，正是注入值。
门二原判据 `λ ≤ 0.8` 在新公式下本来已经无法直接检验（只观测到混着 `b` 的 `λ̂`），
这个比值把它恢复了。

**其二，门二拆成三条，全部预注册：**

| | 判据 | 守什么 |
|---|---|---|
| 2a | `λ̂/ŝ_shuffled ≤ 0.8` | 原判据，去衰减后 |
| 2b | `(ŝ_shuffled − λ̂) / bootstrap SE ≥ 阈值` | `r` 的方差。新分母是估计量，趋零时 `r` 爆 |
| 2c | `ŝ_shuffled ≥ 下限`（建议 0.5） | `d` 本身测得有多糟 |

2c 在 2b 之外仍需要：即使窗口够宽，`b` 很小意味着 `d_i` 是把坏尺子，而 C7.4 的
`r(d)` 是**按 `d` 分箱**的，箱子本身就错位。2b 守 `r`，2c 守 `r(d)`。

**其三，理论值 1 从判据降为诊断。** `ŝ_shuffled` 现在是 `b` 的估计，也就是 `d` 的
信噪比，进结果表但不再当判据。README §1.2.2 那句"打乱臂斜率理论上应当等于 1，
明显不等于 1 说明装置有问题"随之作废——它在有测量误差时**本来就不该等于 1**。
