# 0045 E5 网页：接 E3C、双语、稿纸与地球

日期：2026-10-24。层：界面层（ui-02）。说明见 [e5-web-ui](../docs/design/e5-web-ui.md)，任务原文见
[工程 prompt](../docs/design/prompts/2026-10-24-e5-bilingual-dual-mode-service.md)。

## 背景

E5-A（[0036](0036-e5a-offline-ui.md)）是读 v2 公共样例的离线原型。E3C 已经提供本地托管服务，共享结构升到 v3.3；所有者确认中英双语、默认稿纸、
可拖动的写实地球，输入与结果共用一份业务状态。

## 决定

1. **网页只接 E3C 的 HTTP 接口。** 删除 E5-A 的样例适配器、场景表、网络模拟与标签页草稿存储；公共样例只用于测试与开发。HTTP 失败不退回样例。
2. **一套业务状态，两种外观。** 外观只换颜色变量与地图渲染器（平面 SVG / react-globe.gl 地球），切换不保存、不提交。
3. **显示语言与模型输入 / 输出语言都是开局可调的选项**（所有者 2026-10-24），不维护按字段的半中半英组合。模型语言现在写进
   `occupation.language`；规划模型的语言需要 E3 新增字段与英文提示模板（交接单第 12 节）。
4. **J 色阶适度放大**（所有者 2026-10-24）：同一结果的所有城市共用一个窗口，宽 = min(1, max(0.02, 2 × (最高 − 最低)))，以两者中点为中心、
   落在 [0, 1] 内；最高、最低的城市落在色阶的 25% 与 75%（差距小于 0.01 时向中间收：差 0.004 落在 40% 与 60%），图例写明两端不代表
   0 分或满分。E3C 设计稿建议固定 [0, 1]；差距小时固定尺度几乎同色，所有者选择适度放大，数值与比较结论照公共值显示，不受色阶影响。
5. **国家底图按显示语言选 Natural Earth 版本**（所有者 2026-10-24 要求用“按各国立场画的版本”）：中文界面用中国立场版，英文界面用默认版
   （实际控制线）。底图只说明国家在哪里，不是模拟范围；城市锚点等 E3 的地理显示清单，不猜坐标。
6. **验证用只含已提交代码的工作树。** 共用工作区里别的会话的半成品不混进界面的测试：`E5_SERVICE_REPO`、`E5_CONTRACTS_DIR` 让服务、页面与契约
   核对说同一个版本。

## 后果

* 英文界面里，E3 还没给英文的业务文字显示中文原文并标明；地图与地球上暂时没有城市点。这些验收保持未完成，等 E3 交付。
* 色阶与 E3C 设计稿不一致的地方写在说明、交付报告与交接单第 12 节第 7 条里；E3C 的显示元数据（`MetricDisplaySpec`）交付后只用来校验
  数值域，除非所有者另行裁定。
