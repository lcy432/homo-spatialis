## 一、P10 的落点与口径

```
z_i = ‖w_i − μ₀‖      分层变量。μ₀ = α/Σα = (1/3, 1/9×6)，**显式传**
d_i = ‖w_i − ĉ‖       分析变量。ĉ 是匹配/参照臂拟合出来的中心
```

`eval.sampling.stratification_variable` **没有默认中心**。默认 `1/7` 正是
`DECISIONS/0006` 修掉的 bug：它给所有人的距离加一个固定偏移，层整体歪掉而
代码照常跑完、结果照常产出。没有默认值，这个错误就写不出来。

**`z` 与 `d` 不得互换。** 层标签在选择数据产生**之前**冻结；不得按拟合后的
`d` 或任何结果重抽人（硬规则 21）。按 `z` 分的层不等于按 `d` 的等频分箱，
`report_conditional` 因此在产出里写明自己用的是哪一个。

**边界与层概率来自独立参照总体**（`ReferencePopulation`：按注入 α 抽一批只用来
定边界的样本，seed 与规模进指纹），不来自本轮的行为结果。

## 二、配额与权重

配额是**设计决定**，本记录不替它预注册。`Allocation` 的默认 `status` 是
`provisional`；测试与示例里的数字不得被读成事前承诺。

权重口径两种，**一次分析只能用一个**，并写进产出：

| 目标 | 层权重 | 公式 |
|---|---|---|
| `superpopulation`（注入 Dirichlet） | 理论 `p_h` | `w_h = p_h / (n_h/N)` |
| `finite_pool`（手上这个候选库） | 库内占比 `M_h/M` | `w_h = (M_h/M) / (n_h/N)` |

**两处都用实际抽到的 `n_h`，不用目标配额。** 尾层被抽干时实际人数低于配额，
拿配额算权重就和实际抽法对不上，人口量直接偏。

**配额等于总体比例时，说明必须是"控制层人数"，不是"过采样尾部"。** 等频层下
`p_h = 1/H`，于是"每层等量"与"按比例"是同一件事，权重恒为 1。把它说成过采样
会让读的人以为人口量需要还原。这句说明由配额与 `p_h` **算出来**
（`describe_allocation`），不按 `kind` 写死。

## 三、两个报告接口，以及它们不覆盖的那一类

`report_population()` 与 `report_conditional()` 是两个函数，不是一个
`weighted=` 参数（README §11.9.2）。

**新增一条边界**：条件量不加权，是因为它**本来就条件在层上**；这**不能**推广成
"所有跨层回归都不用加权"。`proj ~ d` 跨越所有层，样本里各层的比例是设计出来的。
因此 `report_cross_stratum_relationship` 的 `weighted` **没有默认值**——两种口径
都讲得通（设计样本上的关系 vs 目标总体上的关系），藏一个默认值只会让读的人
以为有天然正确答案。

## 四、一个尚未定义的估计对象（**待科学裁决**）

P9 的混合 logit 在实验样本上**未加权**拟合，估的是**被抽到的那群人**的分布。
简单随机抽样下那就是注入总体；**按 `z` 分层并过采样尾层之后，两者不一致**。

**只给最后的报告加权修不了这件事。** `report_population` 还原的是报告里的那个
量，它不回头改变似然，也不改变 `Σ̂_w`。说"拟合矩已按人口校正"是错的。

后果落在**主证据**上：§11.7.3 说协方差比识别得干净，因为分母 `Σ_injected` 有
闭式解——那条论证默认分子估的是同一个总体。过采样之后分子估设计总体、分母估
注入总体，比值混进一个纯抽样设计造成的因子。

实测（本轮小型合成例，尾层配额 100 vs 其余 20，n=200）：`E[w₁]` 真值 1/3，
未加权样本均值 **0.2795**，按设计权重还原后 **0.3174**。未加权那个数就是
未加权 MSL 会去拟合的那个总体。

三个方向，**都未裁决**：

1. **比例分配**（已实现，`Allocation.proportional`）。权重恒为 1，`Σ̂_w` 仍估
   注入总体，闭式分母继续成立。代价是放弃尾部过采样。**当前默认走这个**，
   因为它是唯一不需要新裁决就能用的方案。
2. **加权似然**（把设计权重放进 MSL 的人设项）。改变估计量及其抽样性质，属于
   P9 数学改动，**本轮明确不做**。
3. **改口径**：承认 `Σ̂_w` 估的是设计总体，把分母换成同设计下的 `Σ_design`。
   不改估计器，改分母的定义。

机器可读版本：`eval.sampling.ESTIMAND_GAP`。

## 五、P8 的复用边界

`eval.floors.reuse`。**比设计，不比选择记录。**

比：目标人群、注入 α、分层方案、配额、人数、题数、候选数、世界 profile、
tier、噪声来源、σ、估计配置。不匹配 → `FloorReuseError`，**拒绝，不降级为警告**。

不比：`dataset_digest`、臂来源、各 seed、run id。它们只记录供溯源。地板臂与
匹配臂的选择本来就不同（真值 softmax vs 大模型 vs 打乱配对），要求逐行相同
等于要求两个臂是同一个臂。

**"没分层"要显式说**（`stratification: "simple_random_sampling_no_strata"`），
把它与"忘了记"区分开，否则一条未分层的地板可以安静地复用给一条分层的运行。

**现有 P8 的定位不变**：它是"通用实现 + 参考设计 pilot"，**不是**匹配某个正式
P10 设计的最终校准。旧 pilot 仍可读作历史参考，不同设计的结果分开存放。

## 六、门二理由在 ALR 下的订正

README §10.3.3 旧版论证："`ŵ_i = γ_i/γ_0` 是比值估计量，`γ_0 → 0` 时矩不存在，
所以 λ→1 与比值爆炸是同一件事。"

**那条论证属于差分法分支**（权重是两个自由参数的比值，分母可以过零）。ALR 主
规格下 `w = softmax(a)` 恒在开单纯形内、**逐分量有界于 (0,1)**，任意阶矩都存在。

ALR 下窗口关闭的后果是另外两件事：

1. **信息不足 ⟹ 个体后验退回先验。** 面板似然接近平坦，`E[w_i | choices]` 向
   总体分布靠拢，个体差异被抹平。不是发散，是**收缩**——同样让 `proj` 测不出
   东西，但表现相反。
2. **窗口 `W = ŝ_shuffled − λ̂` 小会放大 `r` 的误差。** `r` 的分母是估计量，
   `W → 0` 时相对误差被 `1/W` 放大。这一条与参数化无关。

**三条判据 2a/2b/2c 全部保留，一字未改。** 改的只是 0.8 的地位：它是**预注册的
设计阈值**，写在 `configs/` 里、跑之前 commit（硬规则 20），不是一条定理的推论。

**2b 的阈值是待预注册的设计决定，不是等着被观测的数。** 现在留空、状态
`pending_input`。填它需要有人裁决一个数，不是跑一轮看看窗口有多大。
**按结果选阈值等于没有阈值。**
