# 0006 物质维用更大的 Dirichlet 参数：α₁ = 1.5，舒适度维保持 0.5

**状态**：已采纳（2026-09-06）｜**落点**：`src/worlds/personas.py`
**推翻**：README §11.9 与 CLAUDE.md 裁决表里"Dirichlet(α=0.5)"的对称写法
**指针已留**：README §11.9（按治理规则，无指针的决策记录不生效）

## 决定

```python
MATERIAL_ALPHA = 1.5  # 物质维
AMENITY_ALPHA = 0.5  # 六个舒适度维，不变
```

## 为什么物质维要单独取值

它在**结构上**与六个舒适度维不同：只有它的指数出现在货币度量的分母上。

```
ln e = (ln V − ln κ) / w₁
```

对称先验把物质维当成可互换的第七维，而它不是。α₁ = 0.5 时后果有两层：

**实质层面**：w₁ 的中位数只有 0.076。"典型的合成人只给经济与居住 7.6% 的
权重"——真实用户在定和量表上给这一维的分数几乎肯定远高于此。

**度量层面**：约 20% 的人设算不出美元福利数（`welfare_gap is None`）。而
§1.2.5 要求报"原始美元福利损失对 `d_i` 的曲线"，缺失的那 20% 不是随机
缺的（低 w₁ 与高 `d_i` 弱相关，`corr(d, ln w₁) ≈ −0.20`）。

## 扫描

600 人设，同一个世界，同一批 seed。判据是"把美元口径缺失压到 2% 以下的
最小 α₁"——取最小，因为每往上加都在削弱物质维的离散度，而离散度正是回收
测试的信息来源。

| α₁ | `welfare_gap is None` | w₁ 中位数 | w₁ p10 | 舒适度子向量熵 |
|---|---|---|---|---|
| 0.5 | 20.3% | 0.076 | 0.0033 | 0.6845 |
| 1.0 | 3.2% | 0.205 | 0.0355 | 0.6827 |
| **1.5** | **0.8%** | **0.325** | 0.0853 | **0.6854** |
| 2.0 | 0.3% | 0.392 | 0.1397 | 0.6852 |
| 3.0 | 0.0% | 0.500 | 0.2363 | 0.6869 |

全管线复核（α₁=1.5，600 人设）：缺失 **1.0%**，w₁ 中位数 0.294，
美元福利间隔中位数 **$5,809**（p10 $636，p90 $17,299）。

## 稀疏性没有改变，这由 Dirichlet 的中性性质保证

**中性性质（Connor–Mosimann）**：对 Dirichlet(α₁,…,α_K)，剩余分量的相对
构成 `(w₂,…,w_K)/(1−w₁)` 与 `w₁` **独立**，且服从 Dirichlet(α₂,…,α_K)。

所以只动 α₁：

- 改变的是 w₁ 的边际分布；
- 舒适度子向量在自己那个单纯形上仍然是 Dirichlet(0.5,…,0.5)，**逐点不变**。

上表最后一列是实测：舒适度子向量的归一化熵在整列上是 0.683–0.687，全部
落在抽样噪声内。选 α=0.5 的原始理由（偏向稀疏、造出有主导维度的人、
区分度高）一分未损。

## 两处连带变化

**其一，注入协方差的对角线不再是常数。**

```
α₀ = α₁ + 6×0.5 = 4.5
Var(w_k)     = α_k(α₀ − α_k) / (α₀²(α₀+1))
Cov(w_j,w_k) = −α_j·α_k     / (α₀²(α₀+1))
```

实测对角线 `[0.040404, 0.017957 × 6]`。秩仍是 6（`1'Σ1 = 6e-18`，浮点零）——
那是单纯形约束的代数后果，与 α 对称与否无关。

**任何把注入方差当成一个标量的代码都要改成按维取。** 闭式解在
`worlds.personas.dirichlet_covariance()`，C8.1 要求的秩检查一并在那里。

**其二，注入均值不再是 `1/7`，而是 `[1/3, 1/9 × 6]`。**

硬规则 21 用 `‖w − 1/7‖` 作分层变量，理由是"无坍缩时 `ŵ_center` 收敛到
`1/7`"。那句理由现在不成立。`distance_from_center` 因此加了可选的
`center` 参数，非对称之后应当显式传注入均值
（`worlds.personas.dirichlet_mean()`）。

**约束本身没有松动**：注入均值是设计选择，跑之前就定死，仍然事前可算。
硬规则 21 禁止的是依赖跑完才有的 `ŵ_center`，不是禁止用常数中心。
