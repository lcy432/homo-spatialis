# 0040 intake-02：真实资料与机会数据库

日期：2026-10-22（按 intake-02 任务说明实现）。技术细节见 [intake-02 技术说明](../docs/design/intake-02-real-data.md)。

## 决定

1. **内部契约，不改公共结构。** 标准化记录、字段、机会、菜单的结构在 `common/intake_contracts.py`，与 E3-A 的公共消息结构分开；真实资料按构建身份引用，不伪装成合成资料包。跨对象检查在 `ledger/intake_data.py`（不依赖 `product`）。
2. **阶段产物按内容身份存放，LangGraph 只排顺序。** 七个阶段是 `product/realdata/build.py` 里的普通函数；`workflows/data_build.py` 把它们串成可恢复的图，checkpoint 只存阶段引用。资料或方法变了身份就变；改了标准化或获取的语义要升对应的版本号。冻结之后流程结束，不重新拟合、不重新抽样。
3. **冻结库只在本机，仓库只放清单与报告。** SQLite 冻结库约 690 MB，由原始文件与代码按复现命令重建；`data/frozen/intake/us-v1/` 记构建身份、各阶段身份、每份原始文件的 SHA-256、计数、覆盖矩阵、映射诊断与菜单索引。
4. **住房以 B 为主、A 补共同覆盖。** B：ACS PUMS 的新租市场代理（空置待租要价 ∪ 12 个月内迁入者）按 WGTP 加权的条件分位数（真实观测值），至少 30 条原始样本，按层回退并记录；候选价位取三等分区间中点，目标权重 = 格权重 ÷ 3。A：每城同一张 108 格网格，由本城 B 表校准；候选密度与目标权重分开。
5. **菜单政策按板块。** 住房、新工作每年抽取接触机会（Efraimidis–Spirakis 加权无放回，种子不含分身编号）；食品、工业品、城市背景完整目录（分页，不删减）；培训、活动按事实日历。抽样只模拟接触，不抽成交或录用。
6. **拿不到的来源照实报告。** 需要密钥、收费或被拒的来源不注册、不付费、不绕过（Census 数据 API 改用批量文件；HUD 被拒、FBI 要密钥，各自记为不可得并给替代或缺失）。
7. **测试样本是真实文件的子集。** `scripts/intake_fixtures.py` 从真实原始文件切出芝加哥子集，按同一缓存键存放，记原文件 SHA-256 与切法；不生成、不复制记录。

## 收尾修复（2026-10-22，独立审核 F1–F6）

8. **原始文件指纹约束后续读取。** 获取阶段记下的请求键与 SHA-256 是后面各阶段读缓存的唯一依据；缓存被刷新或改动（即使元数据合法）就拒绝继续
   （`RawChangedError`），不读新内容冒充旧来源。新资料只能通过新构建进入（获取阶段的身份随之改变）。州列表也取自获取阶段的请求。
9. **E1 表达不了的限制就不导出。** 芝加哥活动的日期与年龄限制照存；E1 的体验没有日期窗口、资格标签不求值，模拟年份与真实日期的对应也没定义，
   所以带日期或年龄限制的活动降为需要适配并阻止导出（现在 0 项可编译），导出函数本身也拒绝。日历菜单写明没有按日历筛选，日历已知与未知分开数。
10. **适用市场。** 全国性的机会只进同一国家的都会区（`applies_to`，目录、菜单、检查器、覆盖统计与查询共用）；只在加拿大销售的家电型号留在资料库
    但不进美国目录；市场未写的标为未知，不当成确定可得或确定不可得。
11. **点估计与标准误成对。** 阶梯中位数配阶梯法的重复权重标准误，插值中位数配插值法的标准误，分别命名、成对报告（`housing_rent_conditional@2`）。
12. **官方顶码。** 用 Census 2024 PUMS 官方州别阈值与替代值识别顶码（`acs_official_topcodes@1`）；替代值不是真实值的下界；分位数只有不高于格内
    顶码记录的最低阈值才可识别；官方表缺的州保留“是否顶码未知”。不按样本最大值猜。
13. **金额事实存进注册表。** 每项机会记下哪个事实是它的金额（`price_fact`），查询与菜单按它显示含义、单位、计价口径与缺失原因；零是有值。
14. **来源分类与编译缺口。** 来源分类增加“派生”（真实记录经确定换算得到，例如全国食材均价换到都会区），不算已采集。编译缺口分资料缺口与 E1
    表达缺口两张表，状态五选一（可编译 / 只缺资料 / 只缺 E1 / 两样都缺 / 参考事实），重叠的原因计数写明分母。

## 不做

不改 `src/econ/`、生活运行器、行动语义、规划器、用户画像与 `web/`；不宣称完整产品链已接真实资料。要接进 E1 需要的扩展只在技术说明第 9 节声明，由所有者另行决定。
