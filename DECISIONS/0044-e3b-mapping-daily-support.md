# 0044 E3B 映射修正：完整 B 分布、A 共同方案族、日常支持与抽象消费篮子

日期：2026-10-23（所有者确认的方案，实施任务 `docs/design/prompts/2026-10-23-e3b-mapping-and-daily-support.md`），实施完成 2026-10-24。技术说明见 [E3B 映射修正](../docs/design/e3b-mapping-and-daily-support.md)，给界面层的迁移说明见 [E3B 映射修正 → E5](../docs/handoffs/e3b-mapping-to-e5.md)。

## 背景

E3B 资料包把 ACS 与 OEWS 的信息压得太狠：住房每格只留 1/6、1/2、5/6 三个价位，岗位只留三个工资档、工时取中位数、就业片区取众数；食品方案只有几种手写组合，外食单价是 CE 支出除以一个随意的餐数；物质生活里通信、日耗品、衣着与个人护理没有对应的东西，享受只有按摩与居家舒适用品。

## 决定

- **B 保留经验分布，候选池与年度菜单分开**：住房目标格（PUMA × 卧室）引用解析格的完整加权经验支持表（同一条记录的毛租金，或标明的插补；删失、厨卫不完整或未知的不进池，质量照报）；岗位 = OEWS p10–p90 的 20 个年薪支持点 × 同一批 PUMS 记录的（每周工时 × 就业片区）联合分布，给定职业后条件独立（登记的假设）；每份年度菜单从完整池加权无放回抽 60 个（不再按卧室每层 3 个）；目录只展开菜单上出现过的、最低住房与参考住房、开局岗位。
- **A 统一结构与零售修正**：每个板块冻结方案族、参数（含义、单位、支持范围、先验、来源）、城市证据与状态；零售修正的对数正态先验 N(0, log(1.5)²) 只用同规格直接报价按供应商去重后更新——现在一条也没有，全部“未发生本地报价更新”。食品是完整 21 餐的共同网格（3 个篮子 × 家里做 {0, 3, 7, 14, 21} 顿 × 堂食 / 外送 / 各半 × 9 个菜系），外食按统一成本代理；爱好补上无器械锻炼，免费方案支配付费方案时如实报告。
- **日常支持与便利**（所有者授权的评分调整，`chores_and_daily_support_v1`）：s = 0.5·S_chore + 0.5·S_support，S_support = 0.9 × 实际获得的个人通信、居家联网、家用日耗品项数 ÷ 3。费用顺序：直接报价 → FCC 同规格大区参照 → FCC 全国参照 → CE 预算代理（标明，不叫观测单价）。不改时间账，不新增出局条件。
- **抽象个人消费篮子**：享受只剩 `personal_consumption`，z = 3 × 实际获得的标准篮子数，s = min(0.9, z/(z + 3))；篮子 = CE 2024 一人消费单位白名单条目的固定构成 × 城市价格系数，档位 u ∈ {0.25, 0.5, 1, 1.5, 2, 3, 4}；独立按摩与居家舒适用品的计分与模板删除。
- **参考住房 v2**：参考岗位片区取完整岗位池与开局岗位的全部就业片区；开车能到达全部参考岗位片区时也绑定用车的参考生活，可行性交给估值期的通勤、现金与硬要求检查（一条过慢的无车路线不再提前禁用它）。期末模板统一补入三项支持，基本档 1 个篮子、较舒适档 2 个。
- **请求紧凑表示**（提示模板 `e3b-product-prompt-v2`）：同类对象的列表写成共同字段 + 行表，可逆、规范（列与键排序），编码时核对 decode(encode(p)) == p；不删字段、不按评分筛选、不缩减菜单。
- **公共结构 v3.3**：年度事实新增日常支持与个人消费篮子；物质两项的含义改了，问卷（v0.3）与词表（v4）一起升版本，旧的确认画像按“版本已变”要求重新审阅确认。

## 后果

- 目录与请求变大：E3B 一城第 1 年的完整可见目录（约 480 项，其中食品方案 327 个）用紧凑表示后仍约 42 万字符、估计约 48 万 token，超过现有上下文上限（Flash / Sonnet 12.8 万、Haiku 7.2 万）。真实模型跑完整 E3B 目录现在不可行；mock 与离线全链不受影响。要不要缩小方案网格或分批呈现，需要所有者另定（不能按评分筛选）。
- 完整经验支持保留了最低端：六城最便宜的可执行住房每月 4–80 美元（ACS 实付毛租金），最低住房因此很低；是否登记一条“最低住房资格”规则待所有者决定。
- 参考岗位片区变成全部就业片区以后，五座城没有不用车就合法的参考住房，参考生活多数要用车；有的分身期末手上的长工时岗位放进固定模板会超过精力额度，估值如实报不完整（M）。
- 所有价格修正都没有发生：执行价是成本模型与预算代理，不是本地观测价；城市差异主要来自工资、RPP 与 FCC 大区。
