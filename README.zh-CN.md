# Homo-Spatialis · LLM：成为我们

[English](README.md) · 简体中文

*让 LLM 扮演许许多多个自己，体验全世界各地的生活。比较不同的城市与国家。*

Homo-Spatialis 希望从一个个具体的人的视角，理解不同城市、国家和地区能够提供怎样的生活。以一个更加有意义的视角丈量世界上不同城市、国家和地区的生活水平，给人们一个了解世界的独特工具。一个人有什么技能、拥有多少资源、重视什么，等等独特的个性，都会改变他眼中的世界。

我们的长期目标，是让上海与纽约、伦敦与巴黎之间的生活水平比较，对具体的人有现实意义：以我的技能、资源和偏好，在这些城市分别能过上怎样的生活？

项目为同一个人建立多个分身，让他们在不同城市生活。语言模型制定计划，经济模型执行并核算结果。三年里，工作、住房、饮食、通勤和学习上的选择，逐渐形成不同的生活轨迹。

“LLM：成为我们”这个名字来自一个朴素的念头：一个人一生改变自己居住地的机会稀少且高昂，我们如何利用有限的成本去满足自己对世界无限的好奇心？

## 研究动机

更高的工资，可能伴随着更高的房租、税负或更长的通勤。城市的吸引力也因人而异：一个很少去海边的人，仍可能通过住房成本为海滨的吸引力付费。

生活成本同样与人有关。人们买的东西不同，技能不同，对时间的重视程度也不同。关于[消费偏好与当地商品选择](https://realestate.wharton.upenn.edu/wp-content/uploads/2022/04/w836.pdf)、[不同收入群体的城市生活水平](https://web.stanford.edu/~diamondr/DiamondMoretti.pdf)的研究，都说明统一的城市价格指数只能反映部分差异。

Homo-Spatialis 尝试把这些因素放进一个人的生活过程，观察当地机会与个人选择如何共同作用，让城市平均数背后的取舍变得具体。

## 模拟如何运行

1. **描述自己。** 选择城市，填写个人条件、资格和偏好。
2. **让分身生活。** 每个分身制定年度计划，环境逐月执行，记录资金、时间、精力、健康与技能的变化。
3. **比较生活结果。** 先看城市汇总，再沿着年度记录了解每个分身的经历。

一门课程会占用今年的钱和闲暇，也可能让明年有机会换一份工作。便宜的住房能留下更多可支配收入，也可能增加通勤时间。这些选择会在模拟中逐步积累。

结果同时展示分数和分数背后的生活。完整评价、无法维持基本生活，以及未完成的模拟分别记录。仓库中的[六城示例](contracts/product/v3/samples/104_service_e3b_result.json)展示了离线规划器生成的结果。

## 研究问题

研究围绕三个问题展开：

- **AI 能理解一个人的偏好到什么程度？** [从选择中学习偏好](https://arxiv.org/abs/2401.07345)的研究引出了一个实际问题：理解并不完美的模型，能否做出足够有用的决策？它犯错时，哪些人承担的代价更大？
- **能否通过校准，让模拟世界更贴近现实？** 模拟规则包含我们对经济与行为关系的假设。我们希望用现实观测改进这些规则与参数，探索参数搜索和机器学习，并用独立数据检验效果。
- **真实资料怎样成为决策环境？** 从统计资料到可选的住房、岗位和消费机会，需要决定保留哪些细节、如何处理不确定性，以及向分身提供什么信息。

## 在本地试用

安装 [uv](https://docs.astral.sh/uv/getting-started/installation/) 后，在仓库根目录运行：

```sh
uv sync
uv run python scripts/run_product_full.py --mock --out runs/first-run
```

这会用离线规划器，在一个小型合成样例上跑完模拟流程，无需 API 密钥。运行摘要保存在 `runs/first-run/summary.json`。每次运行请使用一个新的输出目录。

使用浏览器界面可按照[网页启动指南](web/README.md)操作。网页需要 Node.js 22，并提供使用六城资料包的本地运行方式。环境、输出和检查的详细步骤见[复现说明](docs/REPRODUCING.md)。

## 当前范围

当前资料包覆盖纽约、洛杉矶、旧金山、芝加哥、休斯敦和西雅图，具体地域范围由各地的数据与税务规则确定。模拟对象是依靠工资收入生活的单个成年人，模拟持续三年。

环境由公开资料、推算值和明确的模型假设共同构成。结果展示这些条件下的模拟生活，并按照个人陈述的偏好进行评价。界面支持中英文，模型规划目前使用中文。

## 未来方向

**V1.1：贡献一座城市。** 我们正在搭建统一的城市资料格式和提交流程。贡献者可以提交自己熟悉或感兴趣的城市数据，按共同要求注明来源、日期、单位和地域范围，再经过校验与映射，形成可以参与模拟的城市资料包。目前如何提出资料和映射贡献，见[贡献指南](CONTRIBUTING.zh-CN.md)。

**V2：更细致的日常生活。** 改进通勤、休闲与爱好、日常消费的数学模型和数据映射，更具体地表达人们怎样使用时间和金钱。

**V3：通过访谈了解用户。** 加入访谈式输入，让用户通过经历、优先事项和具体取舍来描述自己。设计将参考[对话式偏好获取](https://aclanthology.org/W19-5941/)以及[利用访谈和问卷构建个人代理](https://arxiv.org/abs/2411.10109v3)的研究。

更长远的目标是让不同国家和地区的城市能够相互比较，把各地的收入、价格、税收、服务与机会放进一致的分析框架。

## 模型与方法

### 从数据到可选机会

**A 方法**从共同方案出发，用可比的本地报价 D 更新价格修正参数 δ。**B 方法**结合属性 x、y 的边缘分布与条件分布，构造联合分布；例如住房的片区与租金：

$$
\begin{aligned}
\text{A:}\quad p(\delta\mid D)&\propto p(D\mid\delta)\,p(\delta),\\
\text{B:}\quad p(x,y)&=p(x)\,p(y\mid x).
\end{aligned}
$$

B 保留已经观测到的属性关系，来源无法联结的部分采用明确的组合假设。当前六城资料尚无合格报价供 A 更新。两种方法的完整说明见[数据映射](docs/DATA.md#mapping-methods)。

### 从选择到生活轨迹

LLM 制定年度计划 a，经济模型 F 根据城市机会 O、当月事件 ε 和规则参数 θ，逐月更新分身的状态 x：

$$
x_{m+1}=F(x_m,a_y,\mathcal O_c,\varepsilon_m;\theta).
$$

下标 y、m、c 分别表示年份、月份和城市。资金、时间和精力限制当下的选择；学习、消费与健康变化又会改变之后的可能性。具体关系见[生活模型](docs/METHODS.md#life-kernel)。

### 从生活条件到个人评价

许多生活分项采用饱和函数，表达额外资源或服务带来的收益逐渐递减：

$$
f(z)=\min\left(c,\frac{z}{z+\tau}\right),
\qquad
B_m=\sum_{k=1}^{6}w_k s_{k,m}.
$$

z 表示实际获得的生活条件或服务量，c 是上限，τ 控制曲线趋于平缓的速度。分项得分汇成六个生活维度 s，再按个人陈述的偏好权重 w 评价。健康单独计入[月度评价](docs/METHODS.md#monthly-scoring)；[跨期评价](docs/METHODS.md#terminal-evaluation)还考虑期末现金、技能和设备能够支持的生活。

完整公式、假设与实现说明集中在[文档索引](docs/INDEX.md)，研究设计与文献依据见[研究方法](docs/RESEARCH.md)和[参考文献](docs/REFERENCES.md)。
